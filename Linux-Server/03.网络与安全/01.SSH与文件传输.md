# SSH 与文件传输

## 一、SSH 概述

SSH（Secure Shell）是一种加密的网络协议，用于安全地远程登录和传输数据。相比 Telnet 明文传输，SSH 所有数据都经过加密。

### SSH vs Telnet

| 特性 | SSH | Telnet |
| :--- | :--- | :--- |
| 安全性 | 加密传输 | 明文传输 |
| 默认端口 | 22 | 23 |
| 默认登录 | 需要密钥或密码 | 直接明文传输 |
| 用途 | 远程管理服务器 | 调试网络设备 |
| 数据包内容 | 加密 | 明文（可被抓包） |

## 二、SSH 客户端命令

### 2.1 ssh — 远程登录

```bash
# 基本语法
ssh [user@]hostname [-p port]

# 示例
ssh root@192.168.1.100                # 以root登录
ssh -p 2222 user01@server.example.com # 指定端口
ssh -i ~/.ssh/id_rsa user01@server   # 使用密钥登录

# 交互式远程执行
ssh user@host "uptime; df -h"
```

### 2.2 scp — 基于 SSH 的文件复制

```bash
# 下载（远程→本地）
scp user@host:/path/remote/file.txt ./local/
scp -r user@host:/data/ /local/      # 递归复制目录

# 上传（本地→远程）
scp ./local/file.txt user@host:/path/
scp -P 2222 file.txt user@host:/data/ # 指定端口（大写P）

# 常用选项
scp -p user@host:/file ./           # 保持文件属性
scp -q user@host:/file ./           # 静默模式（不显示进度）
scp -C user@host:/file ./           # 启用压缩
scp -l 1000 user@host:/file ./      # 限制带宽（Kbit/s）
```

### 2.3 sftp — 安全的 FTP

```bash
# 启动交互式会话
sftp user@host
sftp -P 2222 user@host              # 指定端口

# sftp 交互命令
sftp> help                           # 查看帮助
sftp> ls                             # 列出远程文件
sftp> lls                            # 列出本地文件
sftp> get remote.txt [local.txt]    # 下载文件
sftp> put local.txt [remote.txt]    # 上传文件
sftp> get -r /remote/dir/           # 递归下载目录
sftp> put -r /local/dir/            # 递归上传目录
sftp> mkdir /remote/dir              # 创建远程目录
sftp> lmkdir /local/dir              # 创建本地目录
sftp> rm /remote/file                # 删除远程文件
sftp> pwd                            # 查看远程当前目录
sftp> lpwd                           # 查看本地当前目录
sftp> bye                            # 退出
```

## 三、SSH 密钥认证

### 3.1 密钥生成

```bash
# 生成密钥对（推荐 RSA 4096 或 ED25519）
ssh-keygen -t ed25519 -C "user@hostname"   # 推荐方式
ssh-keygen -t rsa -b 4096 -C "user@hostname"  # 传统方式

# 交互提示：
# Enter file in which to save the key: （直接回车默认路径）
# Enter passphrase: （设置密码保护私钥，建议设置）
# Enter same passphrase again:
```

### 3.2 密钥文件说明

| 文件 | 权限 | 说明 |
| :--- | :--- | :--- |
| `~/.ssh/id_ed25519` | 600 | 私钥（私钥私用，绝对不能泄露） |
| `~/.ssh/id_ed25519.pub` | 644 | 公钥（可以放心复制到服务器） |
| `~/.ssh/known_hosts` | 644 | 已验证的服务器指纹 |
| `~/.ssh/authorized_keys` | 600 | 允许登录的公钥列表 |

### 3.3 密钥分发

```bash
# 方法1：ssh-copy-id（推荐）
ssh-copy-id -i ~/.ssh/id_ed25519.pub user@host

# 方法2：手动复制
# 将公钥内容追加到目标服务器的 ~/.ssh/authorized_keys
cat ~/.ssh/id_ed25519.pub | ssh user@host "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"

# 方法3：免交互分发
sshpass -p 'password' ssh-copy-id -i ~/.ssh/id_rsa.pub user@host
```

### 3.4 密钥认证过程

1. 客户端发送用户名和公钥ID请求连接
2. 服务器查找 `authorized_keys`，找到对应公钥
3. 服务器生成随机数，用公钥加密后发送给客户端
4. 客户端用私钥解密，得到随机数
5. 客户端用随机数计算会话密钥，发送确认
6. 双方使用会话密钥加密后续通信

## 四、SSH 安全配置

### 4.1 服务端配置

```bash
vim /etc/ssh/sshd_config

# 基础配置
Port 22                          # 监听端口
ListenAddress 0.0.0.0           # 监听地址
Protocol 2                      # 使用SSHv2

# 认证配置
PermitRootLogin no               # 禁止root直接登录
PubkeyAuthentication yes         # 启用公钥认证
PasswordAuthentication no        # 禁用密码认证
PermitEmptyPasswords no          # 禁止空密码
ChallengeResponseAuthentication no

# 安全加固
MaxAuthTries 3                  # 最大尝试次数
ClientAliveInterval 300          # 客户端存活检测（秒）
ClientAliveCountMax 2            # 最大未响应次数
LoginGraceTime 60               # 登录宽限期

# 限制用户/组登录
AllowUsers user01 user02@192.168.1.0/24
AllowGroups sshusers
DenyUsers baduser
DenyGroups problemgroup

# 其他
PrintMotd yes                   # 打印/etc/motd
PrintLastLog yes                # 显示上次登录
Subsystem sftp /usr/lib/openssh/sftp-server

# 重启服务
systemctl restart sshd
```

### 4.2 Match 条件块

```bash
# 配置文件中 Match 块用于条件匹配
# 在 Match 块中覆盖前面的全局设置

Match User user01
    ChrootDirectory /data/sftp
    ForceCommand internal-sftp
    AllowTcpForwarding no

Match Address 192.168.1.0/24
    PasswordAuthentication yes
```

### 4.3 fail2ban — SSH 防暴力破解

```bash
# 安装
yum install -y fail2ban

# 配置
vim /etc/fail2ban/jail.local
[sshd]
enabled = true
port = ssh
filter = sshd
logpath = /var/log/secure
maxretry = 5
bantime = 3600                 # 封禁1小时
findtime = 600                # 10分钟内超过5次失败

# 启动
systemctl enable --now fail2ban

# 查看状态
fail2ban-client status sshd
fail2ban-client status sshd --.Level
```

## 五、SSH 进阶用法

### 5.1 跳板机登录

```bash
# 方式1：通过跳板机连接内网主机
ssh -J user@jump_host user@internal_host

# 方式2：配置 ~/.ssh/config
Host internal-host
    HostName 10.0.0.100
    ProxyJump user@jump-server
    User targetuser

Host jump-server
    HostName j.ser.ver.ip
    User jumpuser
    Port 22
```

### 5.2 远程执行命令

```bash
# 执行单条命令
ssh user@host "systemctl restart nginx"

# 执行多条命令
ssh user@host "cd /data && ./deploy.sh && systemctl restart nginx"

# 执行脚本（本地脚本在远程执行）
ssh user@host bash < local_script.sh
```

### 5.3 端口转发 / 隧道

```bash
# 本地端口转发（访问远程内网服务）
ssh -L local_port:remote_host:remote_port user@ssh_server
ssh -L 8080:192.168.1.100:80 user@jump_server

# 远程端口转发（远程访问本地服务）
ssh -R remote_port:local_host:local_port user@ssh_server
ssh -R 8080:localhost:80 user@vpn_server

# 动态端口转发（SOCKS代理）
ssh -D 1080 user@host
# 配置浏览器使用 SOCKS5 代理 127.0.0.1:1080
```

### 5.4 SSHFS — 远程挂载

```bash
# 安装
yum install -y sshfs

# 挂载远程目录
mkdir /mnt/remote
sshfs user@host:/data /mnt/remote

# 卸载
fusermount -u /mnt/remote
```

### 5.5 SSH 配置示例

```bash
vim ~/.ssh/config

# 全局设置
Host *
    ServerAliveInterval 60
    ServerAliveCountMax 3
    Compression yes

# 跳板机
Host bastion
    HostName 123.45.67.89
    User admin
    Port 22
    IdentityFile ~/.ssh/id_ed25519

# 生产服务器
Host prod-*
    HostName 10.0.0.%h
    User deploy
    ProxyJump bastion
    IdentityFile ~/.ssh/prod_key
```
