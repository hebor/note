# Rsync 备份工具

## 一、Rsync 概述

Rsync（Remote Sync）是 Linux/Unix 用于同步文件和目录的工具，支持本地和远程同步。

### 1.1 特点

- **增量同步**：只传输变化的部分
- **压缩传输**：远程传输时压缩数据
- **保留权限**：可保留文件属性
- **排除文件**：支持排除特定文件
- **守护进程**：可作为服务运行

### 1.2 应用场景

- 文件服务器数据同步
- 网站代码部署
- 定时备份
- 异地灾备

## 二、本地同步

```bash
# 基本语法
rsync [选项] 源路径 目标路径

# 示例
rsync -av /src/ /dst/           # 同步目录（-a保留属性，-v显示过程）
rsync -av /src /dst/           # 同步目录本身

# 常用选项
rsync -a               # 归档模式（-rlptgoD）
rsync -v               # 显示详情
rsync -z               # 压缩传输
rsync -h               # 人类可读格式
rsync -n               # 模拟运行（不实际同步）
rsync -P               # 显示进度，--partial（断点续传）
rsync --delete         # 删除目标中多余的文件
rsync --exclude        # 排除文件
rsync --exclude-from   # 从文件读取排除列表
rsync --bwlimit         # 限制带宽（KB/s）
```

---

## 三、远程同步

```bash
# SSH方式（推荐）
rsync -avz /src/ user@host:/dst/
rsync -avz -e "ssh -p 2222" /src/ user@host:/dst/

# Shell方式（rsyncd）
rsync -avz /src/ user@host::module/path/
rsync -avz rsync://user@host/module/path/

# 常用组合
rsync -avzP /src/ user@host:/dst/     # 压缩+进度+断点续传
rsync -avz --delete /src/ user@host:/dst/  # 严格同步
```

## 四、守护进程模式

### 4.1 服务端配置

```bash
# 1. 安装
yum install -y rsync

# 2. 创建配置文件
vim /etc/rsyncd.conf
# 全局配置
uid = nobody
gid = nobody
use chroot = yes
max connections = 10
pid file = /var/run/rsyncd.pid
lock file = /var/run/rsync.lock
log file = /var/log/rsyncd.log

# 模块配置
[backup]
path = /backup
comment = Backup Directory
read only = no
auth users = backup
secrets file = /etc/rsyncd.secrets

[webdata]
path = /data/www
comment = Web Data
read only = no
list = yes
hosts allow = 192.168.1.0/24
```

### 4.2 认证配置

```bash
# 创建密码文件
vim /etc/rsyncd.secrets
backup:password123
user01:pass456

# 设置权限（必须600）
chmod 600 /etc/rsyncd.secrets

# 启动服务
systemctl enable --now rsyncd
```

### 4.3 客户端连接

```bash
# 使用密码文件（免交互）
echo "password123" > ~/.rsyncd.pass
chmod 600 ~/.rsyncd.pass

# 同步
rsync -avz --password-file=~/.rsyncd.pass /src/ backup@server::backup/

# 或设置环境变量
export RSYNC_PASSWORD=password123
rsync -avz /src/ backup@server::backup/
```

## 五、高级选项

### 5.1 排除与包含

```bash
# 排除特定文件
rsync -avz --exclude='*.log' /src/ /dst/
rsync -avz --exclude='temp/' --exclude='*.tmp' /src/ /dst/

# 从文件读取排除列表
vim exclude.txt
*.log
temp/
.cache/

rsync -avz --exclude-from=exclude.txt /src/ /dst/

# 只同步特定文件
rsync -avz --include='*.php' --include='*.html' --exclude='*' /src/ /dst/
```

### 5.2 限速传输

```bash
# 限制带宽 1MB/s
rsync -avz --bwlimit=1024 /src/ /dst/

# 限制带宽 100KB/s
rsync -avz --bwlimit=100 /src/ /dst/
```

### 5.3 模拟与验证

```bash
# 模拟运行（不实际同步）
rsync -avzn /src/ /dst/

# 显示将要传输的文件
rsync -av --itemize-changes /src/ /dst/

# 对比差异
rsync -avnc /src/ /dst/      # -c 用 checksum 比较
```

## 六、备份脚本案例

### 6.1 增量备份脚本

```bash
#!/bin/bash
# 增量备份脚本

SRC="/data"
DST="user@backup-server::backup"
PASSFILE="/root/.rsyncd.pass"
LOG="/var/log/backup.log"

DATE=$(date +%Y%m%d)
LINK="--link-dest=/backup/$DATE-1"

# 记录日志
echo "[$(date)] 开始备份 $SRC" >> $LOG

# 执行备份
rsync -avz \
  --password-file=$PASSFILE \
  --delete \
  --bwlimit=5120 \
  --exclude='*.tmp' \
  --exclude='*.log' \
  $LINK \
  $SRC/ \
  $DST/$DATE >> $LOG 2>&1

# 检查结果
if [ $? -eq 0 ]; then
  echo "[$(date)] 备份成功" >> $LOG
else
  echo "[$(date)] 备份失败" >> $LOG
fi
```

### 6.2 定时备份配置

```bash
# 添加到 crontab
crontab -e

# 每天凌晨2点执行
0 2 * * * /usr/local/bin/backup.sh >/dev/null 2>&1
```

## 七、常见问题

| 问题 | 解决 |
| :--- | :--- |
| 权限不足 | 使用 `--numeric-ids` 或配置 `uid/gid` |
| 传输中断 | 使用 `-P`（`--partial --progress`）断点续传 |
| 同步太慢 | 使用 `-z` 压缩或 `--bwlimit` 限速 |
| 符号链接问题 | 使用 `-l` 保留符号链接 |
| 时间不同步 | 目标端时间不一致导致 --delete 误删，先同步再启用删除 |
