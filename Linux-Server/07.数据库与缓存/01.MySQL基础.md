# MySQL 数据库基础

## 一、MySQL 概述

MySQL 是最流行的开源关系型数据库，CentOS 7 默认使用 MariaDB。

### 1.1 安装

```bash
# CentOS 7+ (MariaDB)
yum install -y mariadb mariadb-server
systemctl enable --now mariadb

# MySQL 官方源
yum install -y mysql-community-server
systemctl enable --now mysqld
```

### 1.2 初始安全配置

```bash
mysql_secure_installation
# 设置 root 密码
# 移除匿名用户
# 禁止 root 远程登录
# 删除测试数据库
# 重新加载权限表
```

## 二、基础命令

### 2.1 连接数据库

```bash
# 本地连接
mysql -u root -p
mysql -u root -p password

# 远程连接
mysql -h host -u root -p

# 无密码连接（仅测试）
mysql -u root
```

### 2.2 常用 SQL

```sql
-- 显示数据库
SHOW DATABASES;
SHOW DATABASES LIKE 'test%';

-- 创建数据库
CREATE DATABASE dbname DEFAULT CHARSET utf8mb4;

-- 选择数据库
USE dbname;

-- 显示表
SHOW TABLES;

-- 显示表结构
DESC tbname;
DESCRIBE tbname;
SHOW CREATE TABLE tbname;

-- 显示用户
SELECT user, host FROM mysql.user;
```

### 2.3 用户管理

```sql
-- 创建用户
CREATE USER 'user01'@'localhost' IDENTIFIED BY 'password';
CREATE USER 'user01'@'192.168.1.%' IDENTIFIED BY 'password';

-- 授权
GRANT ALL PRIVILEGES ON dbname.* TO 'user01'@'localhost';
GRANT SELECT, INSERT ON dbname.* TO 'user01'@'%';
GRANT ALL ON *.* TO 'admin'@'%';  -- 所有库

-- 刷新权限
FLUSH PRIVILEGES;

-- 查看权限
SHOW GRANTS FOR 'user01'@'localhost';

-- 撤销权限
REVOKE ALL ON dbname.* FROM 'user01'@'localhost';

-- 删除用户
DROP USER 'user01'@'localhost';
```

## 四、CRUD 操作

### 4.1 插入数据

```sql
INSERT INTO tbname (col1, col2) VALUES ('val1', 'val2');
INSERT INTO tbname VALUES ('val1', 'val2', 'val3');
INSERT INTO tbname (col1, col2) VALUES
  ('a1', 'b1'),
  ('a2', 'b2');
```

### 4.2 查询数据

```sql
-- 基本查询
SELECT * FROM tbname;
SELECT col1, col2 FROM tbname;

-- 条件查询
SELECT * FROM tbname WHERE id = 1;
SELECT * FROM tbname WHERE name LIKE '%test%';
SELECT * FROM tbname WHERE age >= 18 AND age <= 30;

-- 排序
SELECT * FROM tbname ORDER BY id DESC;
SELECT * FROM tbname ORDER BY age ASC, id DESC;

-- 限制
SELECT * FROM tbname LIMIT 10;
SELECT * FROM tbname LIMIT 5, 10;  -- 从第5行开始，取10行

-- 聚合
SELECT COUNT(*) FROM tbname;
SELECT SUM(price) FROM tbname;
SELECT AVG(price) FROM tbname;
SELECT MAX(price), MIN(price) FROM tbname;

-- 分组
SELECT status, COUNT(*) FROM orders GROUP BY status;

-- HAVING（分组后过滤）
SELECT user_id, SUM(amount) FROM orders
  GROUP BY user_id HAVING SUM(amount) > 1000;
```

### 4.3 更新数据

```sql
UPDATE tbname SET col1 = 'value' WHERE id = 1;
UPDATE tbname SET col1 = 'a', col2 = 'b' WHERE id = 1;
```

### 4.4 删除数据

```sql
DELETE FROM tbname WHERE id = 1;
DELETE FROM tbname;  -- 删除全部（慎用）
```

## 五、表操作

### 5.1 创建表

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    email VARCHAR(100),
    age INT DEFAULT 18,
    status TINYINT DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_status (status),
    UNIQUE KEY uk_email (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 5.2 修改表

```sql
-- 添加字段
ALTER TABLE tbname ADD COLUMN phone VARCHAR(20) AFTER email;

-- 修改字段
ALTER TABLE tbname MODIFY COLUMN phone VARCHAR(30);

-- 删除字段
ALTER TABLE tbname DROP COLUMN phone;

-- 添加索引
ALTER TABLE tbname ADD INDEX idx_name (name);
ALTER TABLE tbname ADD UNIQUE KEY uk_name (name);

-- 重命名表
ALTER TABLE old_name RENAME TO new_name;
```

### 5.3 清空表

```sql
-- 清空表（重置自增ID）
TRUNCATE TABLE tbname;
```

## 六、备份与恢复

### 6.1 逻辑备份

```bash
# 备份单个数据库
mysqldump -u root -p dbname > backup.sql

# 备份所有数据库
mysqldump -u root -p --all-databases > all_backup.sql

# 备份特定表
mysqldump -u root -p dbname table1 table2 > tables.sql

# 备份并压缩
mysqldump -u root -p dbname | gzip > backup.sql.gz

# 恢复
mysql -u root -p dbname < backup.sql
```

### 6.2 备份选项

```bash
# --master-data：记录binlog位置（用于主从）
mysqldump -u root -p --master-data=2 dbname > backup.sql

# --single-transaction：InnoDB一致性备份
mysqldump -u root -p --single-transaction dbname > backup.sql

# --hex-blob：二进制数据十六进制存储
# --routines：包含存储过程
# --triggers：包含触发器
# --events：包含事件调度器
```

## 七、主从复制

### 7.1 主库配置

```bash
vim /etc/my.cnf
[mysqld]
server-id = 1
log-bin = mysql-bin
binlog_format = row
binlog_expire_logs_seconds = 604800

systemctl restart mariadb

# 创建从库用户
mysql -u root -p
GRANT REPLICATION SLAVE ON *.* TO 'repl'@'192.168.1.%' IDENTIFIED BY 'password';
FLUSH PRIVILEGES;

# 查看主库状态
SHOW MASTER STATUS;
```

### 7.2 从库配置

```bash
vim /etc/my.cnf
[mysqld]
server-id = 2
relay-log = relay-bin
read_only = ON

systemctl restart mariadb

# 配置主从连接
mysql -u root -p
CHANGE MASTER TO
  MASTER_HOST='192.168.1.100',
  MASTER_USER='repl',
  MASTER_PASSWORD='password',
  MASTER_LOG_FILE='mysql-bin.000001',
  MASTER_LOG_POS=xxx;

START SLAVE;
SHOW SLAVE STATUS\G
```
