# Samba 文件共享

## 一、Samba 概述

Samba 是 Linux/Unix 与 Windows 之间实现文件共享的解决方案，基于 SMB/CIFS 协议。

### 1.1 vs NFS 对比

| 特性 | Samba | NFS |
| :--- | :--- | :--- |
| 跨平台 | 支持Windows/Linux | 主要Linux/Unix |
| 认证 | 支持用户密码 | 依赖系统用户 |
| 复杂环境 | 适合异构网络 | 适合纯Linux环境 |
| 性能 | 较低 | 高 |
| 配置 | 较复杂 | 简单 |

## 二、安装与配置

### 2.1 安装

```bash
yum install -y samba samba-client cifs-utils
systemctl enable --now smb nmb
```

### 2.2 配置文件

```bash
vim /etc/samba/smb.conf

[global]
    workgroup = SAMBA
    server string = Samba Server
    security = user
    passdb backend = tdbsam
    printing = cups
    printcap name = cups
    load printers = yes
    cups options = raw

[homes]
    comment = Home Directories
    browseable = no
    writable = yes
    valid users = %S, %D%w%S

[printers]
    comment = All Printers
    path = /var/tmp
    printable = Yes
    browseable = No

[share]
    comment = Shared Directory
    path = /srv/samba/share
    browseable = yes
    writable = yes
    guest ok = no
    valid users = user01,user02
    create mask = 0664
    directory mask = 0775
```

### 2.3 创建共享目录

```bash
# 创建系统用户
useradd -s /sbin/nologin user01

# 将用户添加到 Samba
smbpasswd -a user01
# 输入密码

# 启用用户
pdbedit -L                         # 列出 Samba 用户
smbpasswd -e user01               # 启用用户
smbpasswd -x user01               # 删除用户

# 创建共享目录
mkdir -p /srv/samba/share
chown user01:user01 /srv/samba/share
chmod 775 /srv/samba/share

# 重启服务
systemctl restart smb nmb
```

## 三、防火墙与 SELinux

```bash
# 防火墙
firewall-cmd --add-service=samba --permanent
firewall-cmd --reload

# SELinux
setsebool -P samba_enable_home_dirs on
setsebool -P samba_export_all_ro on
setsebool -P samba_export_all_rw on
chcon -R -t samba_share_t /srv/samba/share
```

## 四、客户端访问

### 4.1 Linux 客户端

```bash
# 查看共享
smbclient -L //server -U user01

# 交互式访问
smbclient //server/share -U user01

# 挂载为文件系统
mount -t cifs //server/share /mnt -o username=user01,password=pass123

# 开机挂载
vim /etc/fstab
//server/share  /mnt  cifs  username=user01,password=pass123  0  0

# 或使用凭证文件
vim /root/.smbcredentials
username=user01
password=pass123

chmod 600 /root/.smbcredentials

vim /etc/fstab
//server/share  /mnt  cifs  credentials=/root/.smbcredentials  0  0
```

### 4.2 Windows 客户端

```
1. 打开文件资源管理器
2. 地址栏输入：\\server_ip\share
3. 输入用户名密码
4. 右键映射网络驱动器（可选）
```
