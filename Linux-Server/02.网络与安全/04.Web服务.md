# Web 服务

## 一、HTTP 基础

### 1.1 HTTP 协议概述

HTTP（HyperText Transfer Protocol）是浏览器与 Web 服务器之间的通信协议。

### 1.2 用户访问流程

```
用户浏览器
    ↓
DNS 解析（www.example.com → IP）
    ↓
TCP 三次握手（建立连接）
    ↓
HTTP 请求（GET /index.html HTTP/1.1）
    ↓
服务器处理（应用/数据库）
    ↓
HTTP 响应（状态码+内容）
    ↓
浏览器渲染页面
    ↓
TCP 四次挥手（关闭连接）
```

### 1.3 URL 格式

```
http://www.example.com:8080/path/page.html?query=123#section
│      │                    │      │       │          │    │
│      │                    │      │       │          │    └─ 锚点
│      │                    │      │       │          └─────── 查询参数
│      │                    │      │       └────────────────── 路径
│      │                    │      └────────────────────────── 端口
│      │                    └─────────────────────────────── 主机名
└──────┴─────────────────────────────────────────────────────── 协议
```

### 1.4 HTTP 状态码

| 状态码 | 含义 | 说明 |
| :--- | :--- | :--- |
| 200 | OK | 请求成功 |
| 201 | Created | 创建成功 |
| 301 | Moved Permanently | 永久重定向 |
| 302 | Found | 临时重定向 |
| 304 | Not Modified | 缓存未过期 |
| 400 | Bad Request | 请求语法错误 |
| 401 | Unauthorized | 需要认证 |
| 403 | Forbidden | 禁止访问 |
| 404 | Not Found | 资源不存在 |
| 500 | Internal Server Error | 服务器内部错误 |
| 502 | Bad Gateway | 网关错误 |
| 503 | Service Unavailable | 服务不可用 |
| 504 | Gateway Timeout | 网关超时 |

## 二、Apache (httpd)

### 2.1 安装与启动

```bash
yum install -y httpd
systemctl enable --now httpd

# 配置防火墙
firewall-cmd --add-service=http --permanent
firewall-cmd --add-service=https --permanent
firewall-cmd --reload

# 验证
curl http://localhost
```

### 2.2 核心配置

```bash
# 主配置文件
/etc/httpd/conf/httpd.conf

# 虚拟主机配置目录
/etc/httpd/conf.d/

# 默认网站根目录
/var/www/html/

# 日志目录
/var/log/httpd/

# 主配置参数
vim /etc/httpd/conf/httpd.conf
Listen 80                        # 监听端口
ServerName www.example.com:80     # 服务器名
DocumentRoot "/var/www/html"      # 文档根目录
DirectoryIndex index.html        # 目录索引文件
```

### 2.3 访问控制

```bash
# 配置示例 /etc/httpd/conf.d/vhost.conf

<VirtualHost *:80>
    ServerName www.example.com
    DocumentRoot /var/www/example
</VirtualHost>

# 目录权限
<Directory "/var/www">
    Options Indexes FollowSymLinks   # Indexes允许目录浏览
    AllowOverride None
    Require all granted
</Directory>

# 禁止特定IP访问
<Directory "/var/www/private">
    Require ip 192.168.1.0/24
    Require all denied
</Directory>

# 密码认证
<Directory "/var/www/admin">
    AuthType Basic
    AuthName "Restricted"
    AuthUserFile /etc/httpd/.htpasswd
    Require valid-user
</Directory>

# 创建密码文件
htpasswd -c /etc/httpd/.htpasswd admin
htpasswd /etc/httpd/.htpasswd user2
```

### 2.4 虚拟主机

#### 基于域名

```bash
# /etc/httpd/conf.d/vhost1.conf
<VirtualHost *:80>
    ServerName www.site1.com
    DocumentRoot /var/www/site1
</VirtualHost>

# /etc/httpd/conf.d/vhost2.conf
<VirtualHost *:80>
    ServerName www.site2.com
    DocumentRoot /var/www/site2
</VirtualHost>

# 重启
systemctl reload httpd
```

#### 基于端口

```bash
# 修改 /etc/httpd/conf/httpd.conf
Listen 80
Listen 8080

# 创建虚拟主机
<VirtualHost *:8080>
    ServerName www.example.com
    DocumentRoot /var/www/portal
</VirtualHost>
```

## 三、Nginx

### 3.1 安装

```bash
# EPEL 源
yum install -y nginx

# 或编译安装（自定义模块）
yum install -y pcre pcre-devel zlib zlib-devel openssl openssl-devel
./configure --prefix=/usr/local/nginx --with-http_ssl_module
make && make install
```

### 3.2 核心配置

```bash
# 主配置文件
/etc/nginx/nginx.conf
/etc/nginx/conf.d/*.conf

# 网站根目录
/usr/share/nginx/html/

# 默认配置
vim /etc/nginx/conf.d/default.conf

server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm;
    }

    location /admin {
        root   /var/www;
        index  index.html;
    }

    # 反向代理
    location /api {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 3.3 常用配置

```bash
# 负载均衡
upstream backend {
    server 192.168.1.101:80 weight=3;
    server 192.168.1.102:80 weight=2;
    server 192.168.1.103:80;
    server 127.0.0.1:80 backup;  # 热备
}

server {
    listen 80;
    server_name www.example.com;

    location / {
        proxy_pass http://backend;
    }
}

# 静态资源
location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
    root /var/www/static;
    expires 7d;
    add_header Cache-Control "public";
}

# HTTPS
server {
    listen 443 ssl http2;
    server_name www.example.com;

    ssl_certificate /etc/nginx/ssl/server.crt;
    ssl_certificate_key /etc/nginx/ssl/server.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    location / {
        root /var/www/html;
    }
}
```

### 3.4 Nginx vs Apache

| 特性 | Nginx | Apache |
| :--- | :--- | :--- |
| 架构 | 事件驱动（epoll） | 进程/线程模型 |
| 并发 | 高（万级） | 一般（千级） |
| 内存占用 | 低 | 较高 |
| 静态资源 | 强 | 一般 |
| 动态资源 | 需配合后端 | 支持（mod_php等） |
| 配置复杂度 | 简单 | 复杂 |

## 四、FTP 服务（vsftpd）

### 4.1 FTP 原理

```
FTP 主动模式（PORT）：
客户端随机端口 → 服务器21 → 服务器20 → 客户端

FTP 被动模式（PASV）：
客户端随机端口 → 服务器21 → 服务器随机端口 → 客户端
```

### 4.2 部署

```bash
yum install -y vsftpd
systemctl enable --now vsftpd

# 防火墙
firewall-cmd --add-service=ftp --permanent
firewall-cmd --reload

# SELinux
setsebool -P ftp_home_dir on
setsebool -P allow_ftpd_full_access on
```

### 4.3 配置

```bash
vim /etc/vsftpd/vsftpd.conf

# 匿名访问
anonymous_enable=NO

# 本地用户
local_enable=YES
write_enable=YES
local_umask=022

# 限制用户访问目录
chroot_local_user=YES
allow_writeable_chroot=YES

# 用户列表
userlist_enable=YES
userlist_deny=NO
userlist_file=/etc/vsftpd/user_list

# 被动模式
pasv_enable=YES
pasv_min_port=6000
pasv_max_port=6010
pasv_address=公网IP
```
