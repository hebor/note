# 磁盘与文件系统管理

## 一、磁盘分区

### 1.1 查看磁盘信息

```bash
# 查看分区表
fdisk -l                        # 查看所有磁盘分区
fdisk -l /dev/sda              # 查看指定磁盘

# 查看块设备
lsblk
blkid                          # 查看UUID和文件系统类型
partprobe                      # 通知内核分区表变化
```

### 1.2 fdisk 分区工具（MBR）

```bash
fdisk /dev/sdb

# 交互命令：
# n：新建分区
#   p：主分区  e：扩展分区
#   分区号：1-4
#   起始扇区：默认回车
#   结束扇区：+10G
# d：删除分区
# t：修改分区类型（83=Linux, 8e=LVM, 82=Swap）
# w：保存退出
# q：不保存退出
# p：显示分区表

# 完整示例
# n → p → 回车 → 回车 → +50G → n → p → 回车 → 回车 → 回车 → w
```

### 1.3 gdisk 分区工具（GPT）

```bash
gdisk /dev/sdb                 # 用于大于2TB的磁盘

# 交互命令与fdisk类似
# 选择分区类型：L 查看代码，8300=Linux filesystem
```

### 1.4 parted 交互式分区

```bash
parted /dev/sdb

# 交互命令：
# mklabel gpt              # 创建GPT标签
# mkpart primary xfs 0% 100%   # 创建占用全部空间的主分区
# mkpart primary xfs 0 50GB     # 创建50GB分区
# rm 1                      # 删除分区1
# print                     # 显示分区表
# quit                     # 退出

# 非交互式用法
parted /dev/sdb mklabel gpt
parted /dev/sdb mkpart primary xfs 0% 100%
```

## 二、文件系统

### 2.1 常见文件系统

| 文件系统 | 说明 | 最大文件 | 最大分区 |
| :--- | :--- | :--- | :--- |
| ext4 | RHEL/CentOS 7默认 | 16TB | 1EB |
| xfs | RHEL/CentOS 7默认 | 8EB | 16EB |
| ext3 | ext4前身 | 2TB | 16TB |
| btrfs | 新一代，支持快照 | 16EB | 16EB |
| vfat | Windows兼容 | 4GB | 2TB |
| ntfs | Windows NTFS | 无限制 | 无限制 |

### 2.2 创建文件系统

```bash
# 创建xfs文件系统（CentOS 7默认）
mkfs.xfs /dev/sdb1

# 创建ext4文件系统
mkfs.ext4 /dev/sdb1
mkfs -t ext4 /dev/sdb1

# 创建vfat
mkfs.vfat /dev/sdb1

# 查看mkfs.xfs详细选项
mkfs.xfs -f /dev/sdb1          # 强制格式化

# 调整xfs元数据大小（用于日志设备分离场景）
mkfs.xfs -l size=64m /dev/sdb1
```

### 2.3 挂载

Linux 中所有设备、分区必须挂载到某个目录才能访问。挂载点即为空目录。

```bash
# 临时挂载
mount /dev/sdb1 /data

# 查看挂载
mount
df -h
df -i                         # 查看inode使用情况

# 卸载
umount /data
umount /dev/sdb1              # 通过设备卸载
umount -l /data               # 懒卸载（强制）
umount -f /data               # 强制卸载（远程挂载）
```

### 2.4 开机自动挂载

```bash
vim /etc/fstab

# 格式：设备    挂载点   文件系统类型   选项              dump  fsck顺序
UUID=xxx      /data    xfs          defaults,_netdev  0     0
/dev/sdb1     /data2   ext4         defaults          0     2
# 字段说明：
# dump: 0=不备份, 1=备份
# fsck: 0=不检查, 1=根分区, 2=其他分区

# UUID获取方式
blkid
ls -l /dev/disk/by-uuid/

# 验证配置（不实际挂载）
mount -a

# 注意：fstab 配置错误会导致开机失败
# 修复：进入单用户模式，以只读方式重新挂载根分区后修改
# mount -o remount,ro /
```

## 三、交换分区（Swap）

### 3.1 创建 Swap

```bash
# 1. 分区类型改为82（Linux swap）
fdisk /dev/sdb
# t → 分区号 → 82 → w

# 2. 创建交换分区
mkswap /dev/sdb1

# 3. 启用
swapon /dev/sdb1

# 4. 查看
swapon -s
free -m

# 5. 添加到fstab
vim /etc/fstab
/dev/sdb1  swap  swap  defaults  0  0

# 或使用UUID
UUID=xxx  swap  swap  defaults  0  0
```

### 3.2 Swap 文件（不用分区）

```bash
# 创建1GB swap文件
dd if=/dev/zero of=/swapfile bs=1M count=1024
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
vim /etc/fstab
/swapfile  swap  swap  defaults  0  0
```

### 3.3 Swap 管理

```bash
# 启用/禁用
swapon /swapfile
swapoff /swapfile

# 优先级设置
swapon -p 10 /dev/sdb1

# 查看
cat /proc/swaps
free -m
```

## 四、磁盘配额（Quota）

### 4.1 启用磁盘配额

```bash
# 1. 安装 quota
yum install -y quota

# 2. 挂载时启用配额
mount -o usrquota,grpquota /dev/sdb1 /data

# 3. 初始化配额数据库
quotacheck -cumug /data

# 4. 启用配额
quotaon /data

# 永久生效（/etc/fstab）
vim /etc/fstab
/dev/sdb1  /data  xfs  defaults,usrquota,grpquota  0  0
```

### 4.2 设置配额

```bash
# 用户配额
edquota -u user01
Disk quotas for user user01 (uid 1001):
  Filesystem     blocks       soft       hard     inodes     soft     hard
  /dev/sdb1          0      10240      12288         0         0        0

# 软限制：超过后警告，仍可写入直到硬限制
# 硬限制：绝对上限

# 组配额
edquota -g developers

# 复制配额配置给其他用户
edquota -p user01 user02

# 设置宽限期（超过软限制多少天后强制执行）
edquota -t
Grace period before enforcing soft limits for users:
Filesystem        Block grace period      Inode grace period
/dev/sdb1               7days                  7days
```

### 4.3 查看配额

```bash
quota -u user01
quota -g developers
repquota -a                    # 查看所有用户配额
repquota -aug                  # 含组
```

## 五、磁盘工具

### 5.1 磁盘使用分析

```bash
# 查看目录大小
du -sh /var/log
du -ah --max-depth=1 /data
du -sh /data/* | sort -h       # 排序显示

# 查看磁盘总览
df -h
df -hT                         # 显示文件系统类型
df -i                          # 查看inode使用
```

### 5.2 dd — 数据复制

```bash
# 复制磁盘到磁盘
dd if=/dev/sda of=/dev/sdb bs=4M status=progress

# 备份MBR
dd if=/dev/sda of=/backup/mbr.img bs=512 count=1

# 恢复MBR
dd if=/backup/mbr.img of=/dev/sda bs=512 count=1

# 创建大文件（测试用）
dd if=/dev/zero of=/tmp/testfile bs=1M count=1024

# 参数说明
# if=input file  of=output file
# bs=block size  count=块数量
# status=progress 显示进度
# conv=notrunc 不截断输出文件
```

### 5.3 安全擦除磁盘

```bash
# 填充零
dd if=/dev/zero of=/dev/sdb bs=4M status=progress

# 填充随机数据（更安全但慢）
shred -v -n 3 /dev/sdb         # 覆盖3次随机数据

# parted创建空分区表
parted /dev/sdb mklabel msdos
```

## 六、LVM 逻辑卷管理

### 6.1 LVM 概念

```
物理卷(PV) → 卷组(VG) → 逻辑卷(LV) → 文件系统
   磁盘分区        磁盘池      可动态调整的分区
```

### 6.2 创建 LVM

```bash
# 1. 创建物理卷
pvcreate /dev/sdb1 /dev/sdc1

# 2. 创建卷组
vgcreate vgdata /dev/sdb1 /dev/sdc1
vgcreate -s 16M vgdata /dev/sdb1    # 指定PE大小（默认4M）

# 3. 创建逻辑卷
lvcreate -L 50G -n lvdata vgdata    # 创建50G逻辑卷
lvcreate -l 100%VG -n lvdata vgdata # 使用100%卷组空间

# 4. 创建文件系统并挂载
mkfs.xfs /dev/vgdata/lvdata
mount /dev/vgdata/lvdata /data
```

### 6.3 LVM 管理

```bash
# 查看
pvs
pvdisplay
vgs
vgdisplay
lvs
lvdisplay

# 扩容（在线扩容xfs）
lvextend -L +10G /dev/vgdata/lvdata    # 逻辑卷增加10G
lvextend -l +100%FREE /dev/vgdata/lvdata  # 使用所有剩余空间
xfs_growfs /data                         # 扩展xfs文件系统

# ext4扩容
resize2fs /dev/vgdata/lvdata

# 缩容（xfs不支持缩容，先备份）
umount /data
resize2fs /dev/vgdata/lvdata 30G
lvreduce -L 30G /dev/vgdata/lvdata
mount /dev/vgdata/lvdata /data

# 添加新物理卷到卷组
vgextend vgdata /dev/sdd1

# 从卷组移除物理卷（需先将数据迁移）
pvmove /dev/sdb1
vgreduce vgdata /dev/sdb1

# 删除LVM
umount /data
lvremove /dev/vgdata/lvdata
vgremove vgdata
pvremove /dev/sdb1
```
