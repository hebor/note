# RAID 磁盘阵列

## 一、RAID 概述

RAID（Redundant Array of Independent Disks）通过组合多个磁盘来提供数据冗余或性能提升。

### 1.1 RAID 级别

| 级别 | 名称 | 最少盘 | 可用容量 | 容错 | 性能 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| RAID 0 | 条带化 | 2 | N×单盘 | ❌ 无 | ⭐⭐⭐⭐⭐ | 性能优先，无数据安全需求 |
| RAID 1 | 镜像 | 2 | 1×单盘 | ✅ 允许1盘坏 | ⭐⭐ | 数据安全优先 |
| RAID 5 | 分布式奇偶校验 | 3 | (N-1)×单盘 | ✅ 允许1盘坏 | ⭐⭐⭐ | 均衡（常用） |
| RAID 6 | 双重奇偶校验 | 4 | (N-2)×单盘 | ✅ 允许2盘坏 | ⭐⭐ | 高可靠性（大数据） |
| RAID 10 | 镜像+条带 | 4 | N/2×单盘 | ✅ 允许N/2盘坏 | ⭐⭐⭐⭐ | 高性能+高可靠（数据库） |

### 1.2 RAID 对比

```
RAID 0: [磁盘1条带1][磁盘2条带1]  → 高性能，无冗余
         [磁盘1条带2][磁盘2条带2]
         [磁盘1条带3][磁盘2条带3]

RAID 1: [磁盘1数据1] = [磁盘2数据1镜像]
         [磁盘1数据2] = [磁盘2数据2镜像]

RAID 5: [磁盘1数据1][磁盘2数据2][磁盘3校验1]  → 允许坏1块
         [磁盘1校验2][磁盘2数据3][磁盘3数据4]

RAID 10: [磁盘1+2镜像]条带化[磁盘3+4镜像]
```

## 二、软 RAID（mdadm）

### 2.1 创建 RAID

```bash
# 1. 安装 mdadm
yum install -y mdadm

# 2. 创建 RAID5（3块数据盘+1块热备盘）
mdadm --create /dev/md0 --level=5 --raid-devices=3 /dev/sdb1 /dev/sdc1 /dev/sdd1 --spare-devices=1 /dev/sde1

# 3. 创建 RAID10（4块盘）
mdadm --create /dev/md1 --level=10 --raid-devices=4 /dev/sdf1 /dev/sdg1 /dev/sdh1 /dev/sdi1

# 4. 查看 RAID 状态
cat /proc/mdstat
mdadm --detail /dev/md0
```

### 2.2 常用命令

```bash
# 查看详细信息
mdadm --detail /dev/md0

# 监控状态
watch -n 1 cat /proc/mdstat    # 每秒刷新

# 标记磁盘为故障
mdadm /dev/md0 --fail /dev/sdb1

# 移除故障磁盘
mdadm /dev/md0 --remove /dev/sdb1

# 添加新磁盘
mdadm /dev/md0 --add /dev/sdf1

# 停止 RAID
mdadm --stop /dev/md0

# 重新激活
mdadm --assemble /dev/md0
```

### 2.3 创建配置文件

```bash
# 保存 RAID 配置
mdadm --detail --scan > /etc/mdadm.conf

# 编辑配置文件
vim /etc/mdadm.conf
DEVICE /dev/sd[b-f]1
ARRAY /dev/md0 level=raid5 num-devices=3 metadata=1.2 UUID=xxxxx
```

### 2.4 格式化与挂载

```bash
# 创建文件系统
mkfs.xfs /dev/md0

# 挂载
mount /dev/md0 /data

# 开机自动挂载
vim /etc/fstab
/dev/md0  /data  xfs  defaults  0  0
```

## 三、RAID 维护

### 3.1 故障处理

```bash
# 1. 发现故障（查看状态）
cat /proc/mdstat
# 或
mdadm --detail /dev/md0

# 2. 查看系统日志
dmesg | grep md
tail /var/log/messages

# 3. 热备盘自动替换
# RAID5有一块热备盘时，坏盘后自动重构
# 重构过程：cat /proc/mdstat 显示进度

# 4. 手动重建
mdadm /dev/md0 --add /dev/sdg1
mdadm --wait /dev/md0
```

### 3.2 扩容

```bash
# RAID5 增加磁盘
mdadm --grow /dev/md0 --raid-devices=5 --add /dev/sdh1

# 扩展文件系统
# xfs:
xfs_growfs /data

# ext4:
resize2fs /dev/md0
```

### 3.3 模拟故障测试

```bash
# 1. 创建测试 RAID
mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb1 /dev/sdc1

# 2. 模拟故障
mdadm /dev/md0 --fail /dev/sdb1

# 3. 查看状态（应该显示 degraded）
mdadm --detail /dev/md0

# 4. 移除并添加新磁盘
mdadm /dev/md0 --remove /dev/sdb1
mdadm /dev/md0 --add /dev/sdd1

# 5. 查看重建进度
cat /proc/mdstat
```

### 3.4 常见问题

| 问题 | 原因 | 解决 |
| :--- | :--- | :--- |
| RAID 无法启动 | 配置文件丢失 | `mdadm --assemble --scan` |
| 磁盘标记为 spare | 已有坏盘被替换 | 正常现象 |
| 重建失败 | 新磁盘容量不足 | 更换同容量或更大磁盘 |
| 无法删除RAID | 有进程使用 | `umount` 后再删除 |

## 四、RAID 与 LVM 组合

```bash
# 常见架构：RAID → LVM → 文件系统

# 1. 创建 RAID
mdadm --create /dev/md0 --level=5 --raid-devices=3 /dev/sdb1 /dev/sdc1 /dev/sdd1

# 2. 创建 LVM
pvcreate /dev/md0
vgcreate vgdata /dev/md0
lvcreate -L 100G -n lvdata vgdata

# 3. 创建文件系统
mkfs.xfs /dev/vgdata/lvdata

# 优势：RAID提供冗余，LVM提供灵活的分区管理
```
