# GlusterFS 分布式文件系统

## 一、GlusterFS 概述

GlusterFS 是一个开源的高性能分布式文件系统，通过软件实现数据可靠性和可用性。

### 1.1 核心特点

- **无元数据服务器**：采用弹性 HASH 算法直接定位数据，避免单点故障
- **扩展性好**：支持在线扩展节点
- **高可用性**：通过副本机制保证数据安全
- **全局统一命名空间**：多节点合并为统一视图
- **标准协议**：支持 NFS、SMB、CIFS 等标准协议访问

### 1.2 核心术语

| 术语 | 说明 |
| :--- | :--- |
| Brick | 存储块（存储服务器的导出目录） |
| Volume | 逻辑卷（一组 Brick 的组合） |
| FUSE | Filesystem in Userspace，内核文件系统用户空间接口 |
| VFS | Virtual File System，虚拟文件系统 |
| Glusterd | 守护进程，管理集群节点 |

---

## 二、工作原理

```
客户端
  ↓
VFS API → FUSE → GlusterFS Client → 网络 → GlusterFS Server → 存储设备
```

1. 客户端数据写入请求到达 VFS
2. 通过 FUSE 传递给 GlusterFS Client
3. Client 使用弹性 HASH 算法计算数据应存放的 Brick
4. 通过网络将数据发送到对应 Brick
5. Brick 将数据写入本地存储

### HASH 算法

GlusterFS 将 2^32 地址空间均匀分配给所有 Brick，根据文件路径计算 HASH 值直接定位存储位置，实现无元数据访问。

## 三、卷类型

### 3.1 分布式卷

- 文件整体存放在一个 Brick
- 无冗余，容量 = 各 Brick 容量之和
- 优点：容量大
- 缺点：单块损坏则数据丢失

```bash
gluster volume create dist-vol \
  server1:/data/brick1 \
  server2:/data/brick2 \
  server3:/data/brick3
```

### 3.2 条带卷（已废弃）

- 文件分块存储到不同 Brick
- 类似 RAID0，无冗余
- 注意：GlusterFS 3.6 后不再支持

### 3.3 复制卷

- 每个 Brick 都有完整副本
- 冗余备份，容量 = 单个 Brick 容量
- 优点：数据安全
- 缺点：磁盘利用率低

```bash
gluster volume create repl-vol replica 3 \
  server1:/data/brick1 \
  server2:/data/brick2 \
  server3:/data/brick3
```

### 3.4 分布式复制卷

- 兼顾分布式和复制卷特点
- Brick 数量必须为副本数的倍数
- 适用于：大容量 + 高可靠场景

```bash
# 6个节点：3副本 × 2 = 6
gluster volume create dist-repl-vol replica 3 \
  server1:/data/brick1 \
  server2:/data/brick1 \
  server3:/data/brick1 \
  server4:/data/brick2 \
  server5:/data/brick2 \
  server6:/data/brick2
```

## 四、集群部署

### 4.1 环境准备（所有节点）

```bash
# 关闭 SELinux 和防火墙
setenforce 0
systemctl stop firewalld
systemctl disable firewalld

# 修改主机名
hostnamectl set-hostname gfs01
vim /etc/hosts
192.168.1.101  gfs01
192.168.1.102  gfs02
192.168.1.103  gfs03

# 添加存储磁盘（不要使用系统盘）
# 分区并格式化
fdisk /dev/sdc
mkfs.xfs -f /dev/sdc1

# 创建挂载点并挂载
mkdir -p /data/brick1
mount /dev/sdc1 /data/brick1

# 添加到 fstab
echo "/dev/sdc1 /data/brick1 xfs defaults 0 0" >> /etc/fstab
```

### 4.2 安装 GlusterFS（所有节点）

```bash
yum install -y centos-release-gluster
yum install -y glusterfs glusterfs-server glusterfs-fuse glusterfs-rdma

systemctl enable --now glusterd
```

### 4.3 信任池配置

```bash
# 在 gfs01 上添加其他节点
gluster peer probe gfs02
gluster peer probe gfs03

# 查看节点状态
gluster peer status

# 从信任池移除节点
gluster peer detach gfs03
```

### 4.4 创建卷

```bash
# 创建分布式卷
gluster volume create dist-vol \
  gfs01:/data/brick1 \
  gfs02:/data/brick1 \
  gfs03:/data/brick1

# 创建复制卷（3副本）
gluster volume create repl-vol replica 3 \
  gfs01:/data/brick1 \
  gfs02:/data/brick1 \
  gfs03:/data/brick1

# 启动卷
gluster volume start repl-vol

# 查看卷信息
gluster volume info repl-vol
gluster volume status
```

## 五、客户端挂载

### 5.1 安装客户端

```bash
yum install -y glusterfs glusterfs-fuse
```

### 5.2 挂载

```bash
# 直接挂载
mount -t glusterfs gfs01:/repl-vol /mnt/glusterfs

# 指定多个节点（提高可靠性）
mount -t glusterfs gfs01:/repl-vol /mnt/glusterfs
mount -t glusterfs gfs02:/repl-vol /mnt/glusterfs

# 查看挂载
df -h | grep gluster
mount | grep gluster
```

### 5.3 自动挂载

```bash
vim /etc/fstab
gfs01:/repl-vol  /mnt/glusterfs  glusterfs  defaults,_netdev  0  0
```

## 六、维护命令

### 6.1 卷管理

```bash
# 启动/停止卷
gluster volume start repl-vol
gluster volume stop repl-vol

# 删除卷（必须先停止）
gluster volume stop repl-vol
gluster volume delete repl-vol

# 添加 Brick（分布式卷扩容）
gluster volume add-brick dist-vol gfs04:/data/brick1

# 重新平衡（扩容后执行）
gluster volume rebalance dist-vol start
gluster volume rebalance dist-vol status
```

### 6.2 配额管理

```bash
# 启用配额
gluster volume quota repl-vol enable

# 设置目录配额
gluster volume quota repl-vol set /data 10GB

# 查看配额
gluster volume quota repl-vol info
```

### 6.3 访问控制

```bash
# 允许访问
gluster volume set repl-vol auth.allow 192.168.1.*

# 拒绝访问
gluster volume set repl-vol auth.reject 10.0.0.*

# 查看设置
gluster volume get repl-vol auth.allow
```

### 6.4 故障测试

```bash
# 关闭一个节点测试
systemctl stop glusterd gfs03

# 复制卷仍然可访问
df -h | grep gluster
ls /mnt/glusterfs

# 查看卷状态
gluster volume status repl-vol
```

## 七、常见问题

| 问题 | 解决 |
| :--- | :--- |
| Brick 目录不存在 | 创建目录并设置权限 `chmod 755 /data/brick1` |
| Brick 已存在卷 | 先从其他卷移除或删除卷 |
| 节点无法加入 | 检查网络、防火墙、时间同步 |
| 扩容后分布不均 | 执行 `gluster volume rebalance` 重新平衡 |
| 客户端挂载失败 | 检查客户端 GlusterFS 版本与服务端兼容 |
