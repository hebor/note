# iSCSI 存储

## 一、iSCSI 概述

iSCSI（Internet Small Computer System Interface）是一种通过 IP 网络传输 SCSI 协议的存储技术，用于创建 IP-SAN（Storage Area Network）。

### 1.1 核心术语

| 术语 | 说明 |
| :--- | :--- |
| Initiator | iSCSI 客户端（发起存储请求的服务器） |
| Target | iSCSI 存储服务端（提供存储资源） |
| IQN | iSCSI Qualified Name，唯一标识名称 |
| LUN | Logical Unit Number，逻辑单元号（相当于逻辑磁盘） |
| Portal | Target 监听地址（IP+端口，默认3260） |
| TPG | Target Portal Group，端口组 |
| CHAP | Challenge-Handshake Authentication Protocol，认证协议 |

### 1.2 Target 实现方式

| 实现 | 说明 |
| :--- | :--- |
| **STGT/tgt** | 简单易用，CentOS 6 默认 |
| **LIO** | Linux 内核原生支持，CentOS 7+ 默认 |
| **SCST** | 企业级，高性能 |

## 二、LIO Target 配置（CentOS 7+）

### 2.1 安装与启动

```bash
yum install -y targetcli targetd
systemctl enable target
systemctl start target
```

### 2.2 创建存储

```bash
targetcli

# 1. 创建块设备 backstore
/> /backstores/block create name=disk1 dev=/dev/sdb1

# 2. 创建 iSCSI target（IQN 格式：iqn.年-月.域名:标识）
/> /iscsi create iqn.2025-01.com.example:storage1

# 3. 创建 LUN（关联 backstore）
/> /iscsi/iqn.2025-01.com.example:storage1/tpg1/luns create /backstores/block/disk1

# 4. 配置 ACL（限制哪些Initiator可以访问）
/> /iscsi/iqn.2025-01.com.example:storage1/tpg1/acls create iqn.2025-01.com.example:initiator1

# 5. 配置监听地址（可选，默认监听所有地址）
/> /iscsi/iqn.2025-01.com.example:storage1/tpg1/portals/ delete 0.0.0.0 3260
/> /iscsi/iqn.2025-01.com.example:storage1/tpg1/portals/create 192.168.1.100 3260

# 6. 保存配置
/> saveconfig

# 7. 退出
/> exit
```

### 2.3 CHAP 双向认证

```bash
targetcli

# 设置 Target 端 CHAP 认证
/> /iscsi/iqn.2025-01.com.example:storage1/tpg1/
/iscsi/...tpg1> set auth authentication=1
/iscsi/...tpg1> set auth user_in=initiator_user
/iscsi/...tpg1> set auth password_in=secret123

# 设置 mutual CHAP（双向认证）
/iscsi/...tpg1> set auth user_out=target_user
/iscsi/...tpg1> set auth password_out=secret456

# 保存
/iscsi/...tpg1> cd /
/ > saveconfig
```

### 2.4 非交互式配置

```bash
# 写入初始化脚本
cat > /etc/target/saveconfig.json << 'EOF'
{
  "backstores": {...},
  "iscsi_targets": {...}
}
EOF

# 或使用 targetcli --notree 清除后重建
```

### 2.5 防火墙配置

```bash
firewall-cmd --add-port=3260/tcp --permanent
firewall-cmd --reload
```

## 三、Initiator 配置（客户端）

### 3.1 Linux Initiator

```bash
# 1. 安装
yum install -y iscsi-initiator-utils

# 2. 设置 InitiatorName
vim /etc/iscsi/initiatorname.iscsi
InitiatorName=iqn.2025-01.com.example:initiator1

# 3. 配置 CHAP 认证（如果 Target 端有设置）
vim /etc/iscsi/iscsid.conf
node.session.auth.authmethod = CHAP
node.session.auth.username = initiator_user
node.session.auth.password = secret123
node.session.auth.username_in = target_user
node.session.auth.password_in = secret456

# 4. 发现 Target
iscsiadm -m discovery -t sendtargets -p 192.168.1.100
# 发现结果：192.168.1.100:3260,1 iqn.2025-01.com.example:storage1

# 5. 登录 Target
iscsiadm -m node -T iqn.2025-01.com.example:storage1 -p 192.168.1.100 --login

# 6. 查看已连接磁盘
fdisk -l | grep -i iscsi
lsblk

# 7. 开机自动登录
iscsiadm -m node -T iqn.2025-01.com.example:storage1 -p 192.168.1.100 -o update -n node.startup -v automatic

# 8. 登出
iscsiadm -m node -T iqn.2025-01.com.example:storage1 -p 192.168.1.100 --logout
```

### 3.2 iscsiadm 命令详解

```bash
# 模式：discovery / node / session / iface / fw

# 发现 Target
iscsiadm -m discovery -t sendtargets -p IP

# 查看节点
iscsiadm -m node

# 查看会话
iscsiadm -m session

# 登录指定 Target
iscsiadm -m node -T IQN -p IP -l

# 登出
iscsiadm -m node -T IQN -p IP -u

# 删除发现记录
iscsiadm -m node -T IQN -p IP -o delete

# 查看日志
journalctl -u iscsid
cat /var/log/messages | grep iscsi
```

### 3.3 Windows Initiator

```
1. 打开"iSCSI发起程序"（控制面板 → 系统和安全 → 管理工具 → iSCSI发起程序）
2. 在"目标"标签页输入 Target IP，点击"快速连接"
3. 如果启用了 CHAP，在"高级"中配置用户名和密码
4. 连接成功后，打开"磁盘管理"初始化磁盘并分区
5. 格式化后即可使用
```

## 四、多路径（Multipath）

当有两条以上路径访问同一个 Target 时，使用 multipathd 实现路径冗余和负载均衡。

```bash
yum install -y device-mapper-multipath

# 配置
mpathconf --enable --with_multipathd y

# 启动
systemctl enable --now multipathd

# 查看多路径状态
multipath -ll

# 多路径配置文件
vim /etc/multipath.conf
defaults {
    user_friendly_names yes
    find_multipaths yes
}

devices {
    device {
        vendor "LIO-ORG"
        product "disk"
        path_grouping_policy multibus
    }
}
```
