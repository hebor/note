# Ansible 自动化运维

## 一、Ansible 概述

Ansible 是一个基于 Python 的自动化配置管理工具，通过 SSH 批量管理主机，**无需在被管理主机安装客户端代理**。

### 1.1 核心特点

- **无 Agent**：SSH 连接即可管理
- **幂等性**：重复执行结果一致
- **YAML 配置**：易读易写
- **模块化**：丰富的模块库
- **推送模式**：主控端主动推送配置

### 1.2 核心组件

| 组件 | 说明 |
| :--- | :--- |
| Inventory | 主机清单（定义被管理主机） |
| Modules | 功能模块（核心执行单元） |
| Plugins | 补充插件（连接、过滤等） |
| Playbooks | 剧本（定义复杂任务） |
| API | 第三方接口 |
| CLI | 命令行工具 |

## 二、安装与配置

### 2.1 安装

```bash
# CentOS/RHEL
yum install -y epel-release
yum install -y ansible

# 验证
ansible --version
```

### 2.2 配置文件优先级

```
ANSIBLE_CONFIG 环境变量
./ansible.cfg          （当前目录）
~/.ansible.cfg         （家目录）
/etc/ansible/ansible.cfg
```

### 2.3 Inventory 主机清单

```bash
# 默认位置：/etc/ansible/hosts
vim /etc/ansible/hosts

# 基础语法
192.168.1.100
web[01:03].example.com    # web01, web02, web03
db-[a:d].example.com      # db-a, db-b, db-c, db-d

# 分组
[webservers]
192.168.1.[10:20]
web01.example.com ansible_port=2222

[dbservers]
192.168.1.[30:40]
db[01:02].example.com

# 分组变量
[webservers:vars]
ansible_user=deploy
ansible_port=22

# 嵌套组
[production:children]
webservers
dbservers

[production:vars]
ansible_user=admin
```

### 2.4 SSH 免密配置

```bash
# 生成密钥
ssh-keygen -t ed25519

# 分发到所有主机（交互式）
ssh-copy-id user@host

# 批量免密
for host in $(cat hosts.txt); do ssh-copy-id -i ~/.ssh/id_ed25519.pub user@$host; done
```

## 三、AD-Hoc 命令

### 3.1 基本格式

```bash
ansible <pattern> -m <module> -a "<arguments>"
# pattern：主机、组、all
# module：模块名
# arguments：模块参数
```

### 3.2 常用模块

```bash
# command（默认模块）
ansible all -m command -a "uptime"
ansible web -a "df -h"
ansible all -a "pwd"

# shell（支持管道）
ansible all -m shell -a "free -m | grep Mem"

# yum
ansible all -m yum -a "name=nginx state=present"
ansible all -m yum -a "name=* state=latest"
ansible all -m yum -a "name=httpd state=absent"

# copy
ansible web -m copy -a "src=/path/to/file dest=/path/"
ansible web -m copy -a "src=./config dest=/etc/config backup=yes"

# file
ansible all -m file -a "path=/data state=directory"
ansible all -m file -a "path=/data state=file owner=nginx group=nginx mode=0644"
ansible all -m file -a "path=/data state=absent"

# service
ansible all -m service -a "name=nginx state=started enabled=yes"
ansible all -m service -a "name=httpd state=restarted"

# user
ansible all -m user -a "name=deploy shell=/bin/bash groups=sudo"
ansible all -m user -a "name=deploy state=absent remove=yes"

# group
ansible all -m group -a "name=deploy state=present"

# cron
ansible all -m cron -a "name='backup' hour='2' minute='0' job='/usr/local/bin/backup.sh'"
ansible all -m cron -a "name='backup' state=absent"

# mount
ansible all -m mount -a "path=/data src=192.168.1.100:/nfs fstype=nfs4 opts=defaults state=mounted"

# get_url
ansible all -m get_url -a "url=http://example.com/file.tar.gz dest=/tmp/ mode=0644"

# lineinfile（文件内容替换）
ansible all -m lineinfile -a "path=/etc/sysctl.conf line='net.ipv4.ip_forward=1'"

# firewalld
ansible all -m firewalld -a "service=http permanent=yes state=enabled"
ansible all -m firewalld -a "port=8080/tcp permanent=yes state=enabled"
```

## 四、Playbook

### 4.1 YAML 基础语法

```yaml
# 键值对
name: value

# 列表
- item1
- item2

# 字典
person:
  name: Alice
  age: 30

# 复杂结构
- name: Alice
  skills:
    - Linux
    - Python
```

### 4.2 Playbook 结构

```yaml
# 基本结构
- hosts: webservers          # 目标主机
  become: yes                # 提权
  become_user: root
  vars:                      # 变量
    nginx_port: 80
  tasks:                     # 任务列表
    - name: Install nginx
      yum:
        name: nginx
        state: present

    - name: Configure nginx
      template:
        src: nginx.conf.j2
        dest: /etc/nginx/nginx.conf
      notify: Restart nginx

    - name: Start nginx
      service:
        name: nginx
        state: started
        enabled: yes

  handlers:                  # 处理器（由notify触发）
    - name: Restart nginx
      service:
        name: nginx
        state: restarted
```

### 4.3 Playbook 示例

#### 配置 NFS 服务

```yaml
---
- hosts: nfsserver
  become: yes
  vars:
    nfs_export: /data
    nfs_clients:
      - 192.168.1.0/24

  tasks:
    - name: Install packages
      yum:
        name:
          - nfs-utils
          - rpcbind
        state: present

    - name: Create group
      group:
        name: www
        state: present

    - name: Create user
      user:
        name: www
        group: www
        create_home: no
        shell: /sbin/nologin

    - name: Create export directory
      file:
        path: "{{ nfs_export }}"
        state: directory
        owner: www
        group: www

    - name: Configure exports
      lineinfile:
        path: /etc/exports
        line: "{{ nfs_export }} {{ item }}(rw,sync,all_squash,anonuid=1000,anongid=1000)"
      loop: "{{ nfs_clients }}"
      notify: Reload nfs

    - name: Start services
      service:
        name: "{{ item }}"
        state: started
        enabled: yes
      loop:
        - rpcbind
        - nfs-server

  handlers:
    - name: Reload nfs
      systemd:
        name: nfs-server
        state: reloaded
```

#### 安装 Kodcloud（LNMP）

```yaml
---
- hosts: webservers
  become: yes

  tasks:
    - name: Install LAMP
      yum:
        name:
          - httpd
          - mariadb-server
          - php
          - php-mysql
          - php-gd
          - php-mbstring
        state: present

    - name: Download kodcloud
      get_url:
        url: https://download.kodcloud.com/update/kodbox.1.34.zip
        dest: /tmp/kodbox.zip
        mode: '0644'

    - name: Extract kodcloud
      unarchive:
        src: /tmp/kodbox.zip
        dest: /var/www/
        remote_src: yes
        creates: /var/www/kodbox

    - name: Set permissions
      file:
        path: /var/www/kodbox
        owner: apache
        group: apache
        recurse: yes

    - name: Configure httpd
      template:
        src: httpd.conf.j2
        dest: /etc/httpd/conf/httpd.conf
      notify: Restart httpd

    - name: Start services
      service:
        name: "{{ item }}"
        state: started
        enabled: yes
      loop:
        - httpd
        - mariadb

  handlers:
    - name: Restart httpd
      service:
        name: httpd
        state: restarted
```

### 4.4 Playbook 常用选项

```bash
# 执行（必须指定 playbook）
ansible-playbook site.yml

# 语法检查
ansible-playbook site.yml --syntax-check

# 模拟执行（不实际修改）
ansible-playbook site.yml -C

# 指定主机
ansible-playbook site.yml -l webserver1

# 查看任务列表
ansible-playbook site.yml --list-tasks

# 列出主机
ansible-playbook site.yml --list-hosts

# 标签执行
ansible-playbook site.yml --tags="nginx,mysql"
ansible-playbook site.yml --skip-tags="debug"

# 步骤执行
ansible-playbook site.yml --step
```

## 五、变量与模板

### 5.1 变量定义

```yaml
# Playbook 中定义
vars:
  nginx_port: 80
  nginx_user: nginx

# Inventory 中定义
[webservers:vars]
nginx_port=80

# 命令行传递
ansible-playbook site.yml -e "nginx_port=8080"
```

```yaml

    listen {{ nginx_port }};
    server_name {{ ansible_hostname }};
    root {{ nginx_root }};
    
    {% for item in nginx_extra_dirs %}
    autoindex on;
    {% endfor %}
}
```

## 六、条件与循环

### 6.1 条件

```yaml
tasks:
  - name: Install Apache on CentOS
    yum:
      name: httpd
      state: present
    when: ansible_facts['os_family'] == "RedHat"

  - name: Install Apache on Debian
    apt:
      name: apache2
      state: present
    when: ansible_facts['os_family'] == "Debian"
```

### 6.2 循环

```yaml
# loop 简单列表
- name: Create users
  user:
    name: "{{ item }}"
    state: present
  loop:
    - user1
    - user2
    - user3

# loop 字典列表
- name: Create directories
  file:
    path: "{{ item.path }}"
    state: directory
    mode: "{{ item.mode }}"
  loop:
    - { path: '/data', mode: '0755' }
    - { path: '/logs', mode: '0755' }
```
