# Linux 进程管理与定时任务

## 一、进程管理

### 1.1 查看进程

#### ps — 进程快照

```bash
ps aux                         # 查看所有进程（含详细信息）
ps -ef                         # 标准格式（显示PPID）
ps -ef | grep nginx            # 查找nginx进程
ps aux --sort=-%cpu           # 按CPU排序（降序）
ps aux --sort=-%mem           # 按内存排序（降序）
```

**常用输出列说明：**
- `USER`：进程用户
- `PID`：**进程ID**
- `%CPU`：CPU占用率
- `%MEM`：内存占用率
- `VSZ`：虚拟内存大小（KB）
- `RSS`：物理内存大小（KB）
- `TTY`：终端（?表示后台）
- `STAT`：进程状态
- `START`：启动时间
- `COMMAND`：命令

**STAT 进程状态：**
| 状态 | 含义 |
| :--- | :--- |
| R | 运行中（Running） |
| S | 睡眠（可中断） |
| D | 不可中断的睡眠（通常等待I/O） |
| T | 暂停/追踪（Stopped） |
| Z | 僵尸进程（Zombie） |
| s | 会话首进程 |
| N | 低优先级 |
| l | 多线程 |

#### top — 动态进程监控

```bash
top                            # 启动top（默认3秒刷新）
top -d 1                       # 1秒刷新
top -p PID                     # 监控指定进程
top -u user01                 # 只显示指定用户的进程
top -b -n 2 > top.log         # 批量模式：执行2次输出到文件

# top 交互命令
# P：按CPU排序（默认）
# M：按内存排序
# N：按PID排序
# T：按时间排序
# k：终止进程
# r：修改nice值（优先级）
# q：退出
# 1：显示所有CPU核心
# f：自定义显示字段
```

**top 输出解析：**
```
top - 14:30:25 up 30 days,  2:15,  2 users,  load average: 0.15, 0.10, 0.08
                        │                              │            │       │
系统当前时间             运行时间                     登录用户数   1分钟      5分钟     15分钟负载
Tasks: 245 total,   1 running, 244 sleeping,   0 stopped,   0 zombie
Cpu(s):  5.3%us,  2.1%sy,  0.0%ni, 92.6%id,  0.0%wa,  0.0%hi,  0.0%si,  0.0st
          │        │       │         │           │          │         │       │
       用户占用    系统    Nice      空闲      I/O等待    硬件中断  软件中断   虚拟机窃取
```

#### pstree — 进程树

```bash
pstree                         # 显示进程树
pstree -p                      # 显示PID
pstree -u                      # 显示用户
pstree -ap user01             # 显示user01的完整进程树
```

#### pgrep — 查找进程

```bash
pgrep nginx                    # 查找nginx的PID
pgrep -u root nginx            # 查找root用户运行的nginx
pgrep -f "python.*script"     # 匹配命令行
```

### 1.2 进程控制

#### 挂起与恢复

```bash
# Ctrl+Z：挂起当前进程到后台
# jobs：查看后台任务
# fg %n：将任务n调回前台
# bg %n：将任务n在后台恢复运行
```

#### nohup / & — 后台运行

```bash
nohup command &                 # 不挂断地运行命令（忽略挂断信号）
nohup ./script.sh > output.log 2>&1 &

# &：后台运行（退出终端会终止）
# nohup：不挂断运行（忽略SIGHUP信号）
# screen/tmux：推荐替代方案
```

#### kill — 终止进程

```bash
kill PID                       # 正常终止进程
kill -9 PID                    # 强制杀死（SIGKILL）
kill -15 PID                   # 优雅终止（SIGTERM，默认）
kill -l                        # 列出所有信号

# 常用信号
# 1  SIGHUP   挂起，重新读取配置（如reload）
# 9  SIGKILL  强制终止
# 15 SIGTERM 优雅终止（默认）
# 18 SIGCONT 继续（与STOP相反）
# 19 SIGSTOP 暂停
# 20 SIGTSTP 暂停（Ctrl+Z）

# 批量终止
kill -9 $(pgrep nginx)        # 杀死所有nginx进程
pkill nginx                    # pkill直接按名字杀
killall nginx                  # 杀死所有nginx进程（按名字）
```

### 1.3 进程优先级

```bash
# nice值范围：-20（最高优先级）~ 19（最低优先级）
# 普通用户只能调低（0~19），root可调高（负数）

nice -n 10 command             # 启动时设置低优先级
renice -n 5 -p PID             # 调整运行中的进程优先级
renice -n 10 -u user01         # 调整用户所有进程的优先级
```

## 二、定时任务

### 2.1 cron / crontab

#### crontab 语法

```
*  *  *  *  *  command
│  │  │  │  │
│  │  │  │  └── 星期（0-7，0和7都是周日）
│  │  │  └──── 月份（1-12）
│  │  └─────── 日（1-31）
│  └────────── 时（0-23）
└───────────── 分（0-59）
```

#### 特殊字符

| 符号 | 含义 |
| :--- | :--- |
| `*` | 任意值 |
| `,` | 列表值（1,3,5） |
| `-` | 范围值（1-5） |
| `/` | 步长值（*/5表示每5个单位） |

#### crontab 命令

```bash
crontab -e                     # 编辑当前用户的定时任务
crontab -l                     # 查看当前用户的定时任务
crontab -r                     # 删除当前用户所有定时任务
crontab -i                     # 删除前确认
crontab -u user01 -e           # 编辑指定用户的定时任务（root）
```

#### 示例

```bash
# 每分钟执行
* * * * * /usr/local/bin/backup.sh

# 每小时第5分钟执行
5 * * * * /usr/local/bin/backup.sh

# 每天凌晨2点执行
0 2 * * * /usr/local/bin/backup.sh

# 每周一凌晨3点执行
0 3 * * 1 /usr/local/bin/backup.sh

# 每月1日凌晨4点执行
0 4 1 * * /usr/local/bin/backup.sh

# 每年的6月1日0点执行
0 0 1 6 * /usr/local/bin/backup.sh

# 每5分钟执行
*/5 * * * * /usr/local/bin/backup.sh

# 工作日每天上午9点执行
0 9 * * 1-5 /usr/local/bin/backup.sh

# 每天9点到18点每30分钟执行
*/30 9-18 * * * /usr/local/bin/backup.sh
```

### 2.2 系统定时任务

系统级定时任务目录：

| 目录 | 执行频率 | 说明 |
| :--- | :--- | :--- |
| `/etc/cron.hourly/` | 每小时 | scripts目录下脚本每小时执行一次 |
| `/etc/cron.daily/` | 每天 | 每天凌晨4点左右执行 |
| `/etc/cron.weekly/` | 每周 | 每周日凌晨执行 |
| `/etc/cron.monthly/` | 每月 | 每月1日凌晨执行 |

```bash
# 将脚本放入对应目录即可
cp myscript.sh /etc/cron.daily/
chmod +x /etc/cron.daily/myscript.sh
```

### 2.3 crontab 权限管理

```bash
# 白名单（允许使用crontab的用户）
touch /etc/cron.allow

# 黑名单（禁止使用crontab的用户）
touch /etc/cron.deny

# 规则：
# - 存在cron.allow时，仅白名单用户可用（优先级高）
# - 仅存在cron.deny时，黑名单以外的用户可用
# - 都不存在时，仅root可用
```

### 2.4 at — 一次性定时任务

```bash
# 一次性任务（仅执行一次）
at 23:00                          # 今天23:00执行
at 23:00 2025-12-31               # 指定日期执行
at now +5 minutes                 # 5分钟后执行
at now +1 hour                    # 1小时后执行
at 23:00 + 2 days                # 2天后的23:00

# 进入交互模式
at 23:00
at> /usr/local/bin/backup.sh
at> <EOT>                        # Ctrl+D结束
job 1 at Mon Dec 31 23:00:00 2025

# 查看待执行任务
atq                               # 等同于 at -l
at -l

# 删除任务
atrm 1                           # 删除1号任务
```

### 2.5 编写定时任务规范

```bash
# 1. 先测试命令是否能正常执行
# 2. 编写任务时使用绝对路径
# 3. 添加注释说明
# 4. 避免不必要的输出（重定向到/dev/null）
# 5. 复杂操作写入脚本

# 推荐格式：
# 每天凌晨2点执行数据库备份
0 2 * * * /usr/local/bin/db_backup.sh >/dev/null 2>&1
```

## 三、日志管理

### 3.1 rsyslog

rsyslog 是 CentOS/RHEL 的日志服务，核心配置文件：`/etc/rsyslog.conf`

#### 配置文件格式

```
设施.级别    动作
例：
mail.info    /var/log/maillog
authpriv.*   /var/log/secure
*.info       @@192.168.1.100:514    # TCP发送到远程
```

**常用设施（Facility）：**
| 设施 | 说明 |
| :--- | :--- |
| auth/authpriv | 认证相关（login, su, ssh） |
| cron | 定时任务 |
| daemon | 守护进程 |
| kern | 内核 |
| mail | 邮件 |
| user | 用户程序 |
| local0-local7 | 本地程序自定义 |
| `*` | 所有设施 |

**日志级别（Level）：**
| 级别 | 说明 |
| :--- | :--- |
| emerg | 系统不可用 |
| alert | 必须立即处理 |
| crit | 严重 |
| err | 错误 |
| warn | 警告 |
| notice | 注意 |
| info | 信息 |
| debug | 调试 |
| `*` / none | 所有/无 |

### 3.2 常见日志文件

| 文件 | 说明 |
| :--- | :--- |
| `/var/log/messages` | 系统主日志（大多数服务日志） |
| `/var/log/secure` | 认证/安全日志（SSH登录、sudo） |
| `/var/log/maillog` | 邮件日志 |
| `/var/log/cron` | 定时任务日志 |
| `/var/log/boot.log` | 启动日志 |
| `/var/log/dmesg` | 硬件驱动日志 |
| `/var/log/yum.log` | YUM安装日志 |
| `/var/log/audit/audit.log` | SELinux审计日志 |
| `/var/log/httpd/` 或 `/var/log/nginx/` | Web服务日志 |
| `~/.bash_history` | 命令历史 |

### 3.3 journalctl — systemd 日志

```bash
journalctl                        # 查看所有日志
journalctl -n 50                  # 查看最近50行
journalctl -f                     # 实时跟踪（tail -f）
journalctl --since "1 hour ago"  # 查看1小时内日志
journalctl --since "2025-01-01" --until "2025-01-02"
journalctl -u nginx.service       # 查看指定服务日志
journalctl -u nginx.service -n 20
journalctl -p err                 # 仅错误级别以上
journalctl --disk-usage           # 查看日志磁盘占用
journalctl --vacuum-size=500M     # 限制日志大小
```

### 3.4 logrotate — 日志轮转

主配置文件：`/etc/logrotate.conf`
用户配置目录：`/etc/logrotate.d/`

```bash
vim /etc/logrotate.d/nginx
/var/log/nginx/*.log {
    daily                    # 每天轮转
    missingok               # 丢失不报错
    rotate 14               # 保留14个文件
    compress               # 压缩旧日志
    delaycompress           # 延迟压缩（保留最近一个不压缩）
    notifempty             # 空文件不轮转
    create 0640 www-data www-data   # 轮转后创建新文件
    sharedscripts           # 所有日志轮转后只执行一次脚本
    postrotate
        [ -f /var/run/nginx.pid ] && kill -USR1 `cat /var/run/nginx.pid`
    endscript
}

# 手动执行（测试）
logrotate -f /etc/logrotate.conf
logrotate -d /etc/logrotate.d/nginx   # 模拟执行（不实际轮转）
```

| 级别 | 数值 | 说明 |

| err | 3 | 错误 |
| warn | 4 | 警告 |
