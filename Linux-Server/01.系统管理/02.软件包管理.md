# Linux 软件包管理

## 一、RPM 包管理

### 1.1 RPM 概述

RPM（RedHat Package Manager）由 Red Hat 开发，用于管理 Linux 软件包。RPM 包名格式：

```
软件名-版本信息.操作系统.硬件架构.rpm
例如：nginx-1.20.1-1.el7.x86_64.rpm
```

Linux系统会建立一个集中的数据库，用于记录软件包安装/卸载等变化信息，并分析软件包依赖关系；在windows系统中是依赖注册表来实现这个功能的。

RPM包的常规安装路径：

| 文件类别             | 默认安装位置                     |
| -------------------- | -------------------------------- |
| 普通执行程序         | /usr/bin/、/bin/                 |
| 服务器程序、管理工具 | /usr/sbin/、/sbin/               |
| 配置文件             | /etc/、/etc/软件名/              |
| 日志文件             | /var/log/、/var/log/软件名/      |
| 程序文档、man手册页  | /usr/share/doc/、/usr/share/man/ |

### 1.2 RPM 安装与查询

```bash
# 安装
rpm -ivh package.rpm              # -i安装 -v显示详情 -h显示进度条
rpm -ivh --nodeps package.rpm     # 忽略依赖安装（不推荐）
rpm -ivh --force package.rpm      # 强制安装

# 查询
rpm -qa                           # 列出所有已安装的包
rpm -qa | grep nginx              # 查找nginx包
rpm -qf /usr/sbin/nginx           # 查询文件属于哪个包
rpm -ql nginx                     # 列出包的所有文件
rpm -qi nginx                     # 查看包信息
rpm -qc nginx                     # 查看包配置文件
rpm -qd nginx                     # 查看包文档文件
rpm -q --scripts nginx            # 查看包安装/卸载脚本
rpm -qp package.rpm               # 查询未安装的包文件（-qp=query package）
```

### 1.3 RPM 升级与卸载

```bash
# 升级
rpm -Uvh package.rpm              # 升级（没装过则安装）
rpm -Fvh package.rpm              # 强制升级（没装过则不安装）

# 卸载
rpm -e nginx                      # 卸载（包名，不是文件名）
rpm -e --nodeps nginx            # 忽略依赖卸载
rpm -e --allmatches nginx        # 卸载所有匹配版本
```

### 1.4 RPM 签名验证

```bash
# 导入签名
rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7

# 验证签名
rpm --checksig package.rpm
# 输出：package.rpm: rsa sha1 (MD5) pgp md5 OK

# 验证文件完整性
rpm -Va                            # 验证所有已安装的文件
# 输出格式：S.M.C.G.U.D（文件大小/权限/类型/所有者/组/修改时间）
```

## 二、YUM/DNF 包管理

### 2.1 YUM 概述

YUM（Yellowdog Updater Modified）基于 RPM 的包管理器，自动解决依赖关系。

### 2.2 基础命令

```bash
# 查询
yum list                          # 列出所有包
yum list installed                # 列出已安装的包
yum list nginx                    # 查看特定包
yum search nginx                  # 搜索包
yum provides /usr/sbin/nginx      # 查找命令属于哪个包
yum info nginx                    # 查看包信息

# 安装/升级/卸载
yum install nginx                 # 安装（自动确认）
yum install -y nginx              # 自动确认安装
yum localinstall package.rpm      # 本地安装（自动处理依赖）
yum update nginx                  # 升级
yum update                         # 升级所有包
yum remove nginx                  # 卸载（自动卸载依赖）
yum erase nginx                   # 卸载（更彻底）

# 缓存管理
yum makecache                     # 生成缓存
yum clean all                     # 清除所有缓存
yum clean metadata               # 清除元数据缓存
```

### 2.3 YUM 组管理

```bash
yum grouplist                     # 列出软件组
yum groupinstall "Development Tools"   # 安装开发工具
yum groupinfo "Development Tools"     # 查看组信息
yum groupremove "Development Tools"   # 卸载组
```

### 2.4 YUM 历史

```bash
yum history                       # 查看操作历史
yum history info 5                # 查看第5号操作的详情
yum history undo 5                # 撤销第5号操作
yum history redo 5               # 重做第5号操作
```

## 三、本地 YUM 仓库搭建

### 3.1 创建本地 YUM 源

当服务器无法联网时，可使用本地 ISO 镜像作为 YUM 源：

```bash
# 1. 挂载系统镜像
mount /dev/cdrom /mnt

# 2. 创建本地源配置文件
vim /etc/yum.repos.d/local.repo
[local]
name=Local Repository
baseurl=file:///mnt
enabled=1
gpgcheck=0          # 关闭签名验证

# 3. 验证
yum list
```

epel源中存放的软件是*测试不够全面但是无害，所以无法放入base源中的软件*

### 3.2 使用 ISO 镜像文件

```bash
# 1. 将ISO镜像复制到系统
cp /path/to/CentOS-7-x86_64-DVD-2009.iso /opt/

# 2. 挂载ISO文件
mount -o loop /opt/CentOS-7-x86_64-DVD-2009.iso /mnt

# 3. 配置同上
```

### 3.3 搭建局域网 YUM 源

```bash
# 服务端（安装createrepo工具）
yum install -y createrepo httpd
createrepo /var/www/html/localrepo/

# 将RPM包放入/var/www/html/localrepo/
# 启动httpd
systemctl enable --now httpd

# 客户端配置
vim /etc/yum.repos.d/lan.repo
[lan]
name=LAN Repository
baseurl=http://server_ip/localrepo/
enabled=1
gpgcheck=0
```

## 四、系统服务管理

### 4.1 systemctl 基础命令

```bash
# 启动/停止/重启
systemctl start nginx
systemctl stop nginx
systemctl restart nginx           # 重启
systemctl reload nginx           # 重载配置（不中断服务）

# 查看状态
systemctl status nginx
systemctl is-active nginx        # 查看是否运行
systemctl is-enabled nginx       # 查看是否开机启动

# 开机启动
systemctl enable nginx           # 开机启动
systemctl disable nginx          # 禁用开机启动
systemctl enable --now nginx    # 启动+开机启动
systemctl disable --now nginx   # 停止+禁用开机启动

# 查看
systemctl list-units --type=service --all   # 列出所有服务
systemctl list-dependencies nginx           # 查看服务依赖
systemctl cat nginx                          # 查看服务配置文件
```

### 4.2 运行级别（target）

| SystemV runlevel | systemd target | 说明 |
| :--- | :--- | :--- |
| 0 | runlevel0.target, poweroff.target | 关机 |
| 1 | runlevel1.target, rescue.target | 单用户救援模式 |
| 2 | runlevel2.target, multi-user.target | 多用户（无NFS） |
| 3 | runlevel3.target, multi-user.target | 多用户（命令行） |
| 4 | runlevel4.target, multi-user.target | 多用户（保留） |
| 5 | runlevel5.target, graphical.target | 图形界面 |
| 6 | runlevel6.target, reboot.target | 重启 |

```bash
# 切换运行级别
systemctl isolate multi-user.target    # 切换到命令行
systemctl isolate graphical.target      # 切换到图形界面

# 设置默认级别
systemctl set-default multi-user.target   # 命令行
systemctl set-default graphical.target     # 图形界面

# 查看默认级别
systemctl get-default

# CentOS 7的运行级别文件

```

### 4.3 服务配置文件

systemd 服务配置文件位于：

| 目录 | 说明 |
| :--- | :--- |
| `/usr/lib/systemd/system/` | 软件包提供的服务文件 |
| `/run/systemd/system/` | 运行时创建的服务（不持久） |
| `/etc/systemd/system/` | 系统管理员创建的服务（优先） |

```bash
# 示例：创建自定义服务
vim /etc/systemd/system/myservice.service
[Unit]
Description=My Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/myservice
Restart=on-failure
User=root

[Install]
WantedBy=multi-user.target

# 重载systemd配置
systemctl daemon-reload
systemctl enable --now myservice
```
