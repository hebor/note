# Linux 用户与权限管理

## 一、用户与用户组

### 1.1 基本概念

- **用户（User）**：Linux是多用户操作系统，每个用户有唯一的 UID
- **用户组（Group）**：方便对多个用户进行统一的权限管理
- **基本组**：用户创建时自动分配的组，创建后不可更改
- **附加组**：用户加入的其他组

### 1.2 UID 分配规则

| UID 范围 | 用途 |
| :--- | :--- |
| 0 | root 超级管理员 |
| 1~999 | 系统用户（伪用户、服务账号） |
| 1000+ | 普通用户（CentOS 7） |
| 500+ | 普通用户（CentOS 6） |

### 1.3 相关配置文件

| 文件 | 说明 |
| :--- | :--- |
| `/etc/passwd` | 用户账户信息 |
| `/etc/shadow` | 用户密码（加密） |
| `/etc/group` | 用户组信息 |
| `/etc/gshadow` | 用户组密码 |

## 二、用户管理命令

### 2.1 useradd — 创建用户

```bash
useradd user01                    # 创建普通用户
useradd -u 1500 user02           # 指定UID
useradd -d /home/custom user03    # 指定家目录
useradd -G wheel,sudo user04     # 添加到附加组
useradd -s /sbin/nologin user05   # 指定登录Shell
useradd -e "2025-12-31" user06    # 指定账户过期日期
useradd -M user07                 # 不创建家目录
useradd -r sysuser                # 创建系统用户（UID<1000）
```

### 2.2 usermod — 修改用户

```bash
usermod -l newname oldname        # 改名
usermod -u 2000 user01            # 修改UID
usermod -d /new/home user01       # 修改家目录（需手动创建并复制文件）
usermod -m -d /new/home user01   # 移动家目录内容
usermod -s /bin/bash user01       # 修改Shell
usermod -aG group1 user01        # 追加附加组（-a必须与-G一起用）
usermod -L user01                 # 锁定账户（禁用密码登录）
usermod -U user01                 # 解锁账户
```

### 2.3 passwd — 设置密码

```bash
passwd                     # 修改当前用户密码
passwd user01              # 修改指定用户密码（root执行）
echo "password" | passwd --stdin user01   # 非交互式设置密码
passwd -l user01           # 锁定账户（比-L更安全）
passwd -u user01           # 解锁账户
passwd -d user01           # 清除密码（无密码登录）
passwd -e user01           # 强制下次登录改密码
passwd -n 7 user01         # 最短使用天数
passwd -x 90 user01        # 最长使用天数
passwd -w 7 user01         # 提前多少天警告
```

### 2.4 chpasswd — 批量设置密码

```bash
# 格式：用户名:密码（每行一个）
echo "user01:pass01" > users.txt
echo "user02:pass02" >> users.txt
chpasswd < users.txt
```

### 2.5 su — 切换用户

```bash
su user01           # 切换用户（保留当前环境变量）
su - user01         # 完全切换（加载目标用户环境变量）
su - root           # 切换到root
su -c "command"    # 以其他用户身份执行命令
```

> **注意**：`su -` 与 `su` 的区别在于是否加载目标用户的 profile 环境变量

### 2.6 userdel — 删除用户

```bash
userdel user01          # 删除用户，保留家目录
userdel -r user01       # 删除用户及其家目录、邮箱
userdel -f user01       # 强制删除（即使正在登录）
```

## 三、用户组管理

```bash
groupadd group01           # 创建组
groupadd -g 1500 group02   # 指定GID
groupadd -r sysgroup       # 创建系统组

gpasswd group01           # 设置组密码
gpasswd -a user01 group01 # 添加用户到组
gpasswd -d user01 group01 # 从组移除用户
gpasswd -M user01,user02,user03 group01  # 批量设置组成员
gpasswd -A user01 group01 # 设置组管理员

groupmod -n newname oldname  # 修改组名
groupmod -g 2000 group01    # 修改GID

groupdel group01             # 删除组（不能是用户的基本组）
```

## 四、Sudo 权限配置

### 4.1 visudo — 安全编辑 sudoers 文件

```bash
visudo          # 编辑 /etc/sudoers（自带语法检查）
```

### 4.2 基础配置格式

```
用户名  主机=(目标用户:目标用户组)  命令
```

### 4.3 配置示例

```bash
# 允许user01以root身份执行所有命令
user01  ALL=(ALL)       /usr/bin/systemctl, /usr/bin/yum

# 允许user02无密码使用systemctl
user02  ALL=(ALL)       NOPASSWD: /usr/bin/systemctl restart nginx

# 允许wheel组成员无密码sudo
%wheel  ALL=(ALL)       NOPASSWD: ALL

# 限制user03只能执行特定命令
user03  ALL=(ALL)       /usr/sbin/useradd, /usr/sbin/userdel

# 主机别名示例
Host_Alias  WEBSERVERS = web01,web02,web03
user01      WEBSERVERS=(ALL)  /usr/bin/systemctl restart httpd
```

### 4.4 sudo 日志

sudo 默认不记录日志，需要手动开启：

```bash
# 在 /etc/sudoers 中添加
Defaults  logfile=/var/log/sudo
```

### 4.5 sudo 相关命令

```bash
sudo -l              # 查看当前用户的sudo权限
sudo -u user01 cmd   # 以指定用户身份执行命令
sudo -k              # 清除缓存的密码（需重新输入）
sudo -i              # 切换到root（加载root环境）
```

## 五、文件权限管理

### 5.1 权限的概念

Linux 文件权限分为三组：所有者（Owner）、所属组（Group）、其他人（Other）

```
rwx rwx rwx
├── ├── └──
│   │    └── Other（其他人）权限
│    └── Group（所属组）权限
└── Owner（所有者）权限
```

权限含义：

| 权限 | 文件 | 目录 |
| :--- | :--- | :--- |
| `r` (4) | 可以读取文件内容 | 可以列出目录内容（文件名） |
| `w` (2) | 可以修改文件内容 | 可以在目录中创建/删除/重命名文件 |
| `x` (1) | 可以执行文件 | 可以进入目录（cd） |

### 5.2 chmod — 修改权限

```bash
# 符号方式
chmod u+x file              # 所有者增加执行权限
chmod g-rw file             # 所属组移除读写权限
chmod o=rw file             # 其他人设为读写
chmod a+x file             # 所有用户增加执行权限（a = ugo）
chmod u=rwx,g=rx,o=r file  # 精确设置

# 数字方式（最常用）
chmod 755 file              # rwxr-xr-x
chmod 644 file             # rw-r--r--
chmod 700 file             # rwx------
chmod 600 file             # rw-------
chmod 777 file             # rwxrwxrwx（慎用！）

# 递归修改
chmod -R 755 /data/project   # 递归修改目录及内容
chmod -R u+X /data          # 大写X：仅目录加执行权限，文件保持不变
```

### 5.3 chown — 修改所有者和所属组

```bash
chown user01 file                # 修改所有者
chown :group01 file              # 修改所属组
chown user01:group01 file        # 同时修改所有者和所属组
chown -R user01:group01 /data    # 递归修改
```

### 5.4 chgrp — 修改所属组（简化版）

```bash
chgrp group01 file              # 修改所属组
```

## 六、特殊权限

### 6.1 SUID（Set User ID）

- 作用于可执行文件
- 执行者临时获得文件所有者的权限
- 标识：`s`（在所有者x位上）

```bash
# 典型案例：/usr/bin/passwd
ls -l /usr/bin/passwd
# -rwsr-xr-x. 1 root root 27856 Apr  1  2020 /usr/bin/passwd
#                                    ^ s 表示有SUID

chmod u+s /usr/bin/command      # 添加SUID
chmod u-s /usr/bin/command      # 移除SUID
chmod 4755 /usr/bin/command     # 数字方式：4表示SUID
```

### 6.2 SGID（Set Group ID）

- 作用于可执行文件：执行者临时获得文件所属组的权限
- 作用于目录：目录下新建的文件自动继承目录的所属组
- 标识：`s`（在所属组x位上）

```bash
chmod g+s /project               # 添加SGID
chmod 2755 /project              # 数字方式：2表示SGID
```

### 6.3 Sticky Bit（粘滞位）

- 作用于目录
- 目录中的文件只能被所有者或root删除
- 标识：`t`（在其他用户x位上）
- 典型应用：`/tmp` 目录

```bash
ls -ld /tmp
# drwxrwxrwt. 163 root root 4096 /tmp
#                                     ^ t

chmod +t /shared                  # 添加粘滞位
chmod 1777 /shared                # 数字方式：1表示粘滞位
```

### 6.4 特殊权限速查

| 权限 | 数字 | 作用于 | 效果 | 标识位 |
| :--- | :--- | :--- | :--- | :--- |
| SUID | 4 | 文件 | 临时获取所有者权限 | s（所有者x位） |
| SGID | 2 | 文件/目录 | 文件：临时获取所属组权限；目录：文件继承目录组 | s（所属组x位） |
| Sticky Bit | 1 | 目录 | 文件只能被所有者和root删除 | t（其他x位） |

## 七、ACL 访问控制列表

### 7.1 基础命令

```bash
# 查看ACL权限
getfacl /data/file

# 设置ACL权限
setfacl -m u:user01:rw /data/file      # 单独设置用户权限
setfacl -m g:group01:rx /data/file     # 单独设置组权限
setfacl -m o::r /data/file             # 设置其他人权限
setfacl -m m::rwx /data/file           # 设置最大有效权限（mask）

# 递归设置
setfacl -R -m u:user01:rw /data        # 注意：-R要在-m前

# 删除ACL
setfacl -x u:user01 /data/file         # 删除指定用户的ACL
setfacl -x g:group01 /data/file        # 删除指定组的ACL
setfacl -b /data/file                  # 删除文件的所有ACL

# 默认ACL（仅对目录设置，子文件自动继承）
setfacl -m d:u:user01:rx /data         # 目录设置默认ACL
```

### 7.2 ACL 权限计算

```
Effective Permission = Min(ACL权限, Mask权限)
```

```bash
# 查看mask
getfacl /data/file
# mask::rwx        ← mask限制了实际生效权限

# 修改mask
setfacl -m m::r /data/file    # 即使u:user01有rwx，实际也只有r
```

### 7.3 ACL 与 chmod 的关系

- chmod 修改的是 **mask**，会间接影响所有 ACL 权限
- 修改所有者/所属组权限时，会自动更新 mask
- 建议：使用 `setfacl -m m::rwx` 确保 mask 不会限制 ACL 权限

## 八、权限验证示例

```bash
# 查看文件完整权限信息
ls -l /etc/passwd
# -rw-r--r--. 1 root root 2346 Apr  1  2020 /etc/passwd
# │││││││
# ││││││└── 1.扩展属性（.表示有SELinux上下文）
# │││││└──── 2.链接数
# ││││└───── 3.所有者
# │││└────── 4.所属组
# ││└─────── 5.文件大小
# │└──────── 6.最后修改时间
# └───────── 7.文件名

# 权限判断逻辑
1. 所有者匹配 → 用所有者权限
2. 否则，匹配所属组 → 用所属组权限  
3. 否则 → 用其他人权限
4. root用户可以无视权限做任何事
```

## 九、权限故障排查

```bash
# 常见问题
# 1. 普通用户无法执行sudo → 检查/etc/sudoers配置
# 2. 用户无法写入目录 → 检查目录权限和父目录权限
# 3. SSH密钥登录失败 → 检查.ssh目录权限(700)和authorized_keys权限(600)
# 4. 文件能读但目录不能cd → 目录缺少x权限

# 排查命令
id username              # 查看用户UID、GID、所属组
groups username          # 查看用户所属所有组
whoami                   # 显示当前用户名
stat filename            # 查看文件详细属性
```
