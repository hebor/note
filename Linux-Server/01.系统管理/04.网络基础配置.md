# Linux网络

## 一、基础管理

### 1.1 主机名

1. 临时修改主机名

   ```bash
   [root@localhost ~]# hostname pc80.example.com    # 立刻生效
   ```

2. 永久修改主机名

   ```bash
   # 修改主机名配置文件
   [root@localhost ~]# echo "pc80.example.com" > /etc/hostname
   
   # 命令修改主机名
   [root@localhost ~]# hostnamectl set-hostname pc80.example.com
   ```

   修改主机名配置文件的方式需要系统重启生效，`hostnamectl`命令可以使主机名修改立刻生效，重启shell进程即可

### 1.2 网卡重命名

1. 修改引导文件

   `/etc/default/grub`是由内核读取的一个引导文件，通过这个引导文件可以制定内核识别网卡的规则，通过修改内核识别网卡的规则，将所有网卡统一命名为ethx类型。在深入学习理解Linix内核之前，这两个参数只需要记下即可

   ```bash
   [root@hebor ~]# vim /etc/default/grub
   GRUB_CMDLINE_LINUX="crashkernel=auto rd.lvm.lv=centos/root rd.lvm.lv=centos/swap rhgb quiet net.ifnames=0 biosdevname=0"    # 尾部补充两个参数
   ```

2. 动态生态GRUB2引导配置文件

   ```bash
   [root@hebor ~]# grub2-mkconfig -o /boot/grub2/grub.cfg
   ```

3. 重启系统

   ```bash
   [root@hebor ~]# reboot
   ```

#### 1.2.1 首次安装系统修改网卡名

首次安装Centos7时，在选择安装界面通过 Tab 键调整初始安装配置，在配置信息末尾添加两个关键词配置`net.ifnames=0 biosdevname=0`

KDUMP：为了防止因为系统崩溃导致内存数据丢失，Kdump 负责将内存中的数据快速写入磁盘保存

### 1.3 配置IP

1. 临时修改IP

   ```bash
   # ip命令
   [root@hebor ~]# ip address show    # 查看IP地址
   ip address add 80.80.80.80/24 dev eth0    # 为eth0网卡添加一个临时地址
   ```

2. 永久修改IP

   通过直接修改配置文件或nmcli命令都可以实现永久性修改IP信息，使用nmcli命令时需要保障NetworkManager服务处于启用状态。nmcli命令的优势在于会自动生成配置文件，在命令行使用nmcli命令时参数有误会直接报错，且不会生成错误的配置文件；nmcli命令会为每个网卡创建一个只有nmcli能够识别的“别名”，nmcli对网络的管理都是通过对“别名”的管理实现的，下文中统一将此“别名”称为“链接名”

   ```bash
   # nmcli命令
   [root@hebor ~]# nmcli connection show    # 查看所有链接名与网卡的绑定关系
   [root@hebor ~]# nmcli connection delete ens33    # 删除链接名
   [root@hebor ~]# nmcli connection add type ethernet ifname eth0 con-name eth0 ipv4.method manual ipv4.addresses 192.168.31.80/24 ipv4.gateway 192.168.31.1 ipv4.dns 192.168.31.1 autoconnect yes
   	type：设备类型
   	con-name：链接名
   	ifname：网卡名
   	ipv4.method：IP获取方式，manual代表手动设置
   	ipv4.addresses：IPv4地址
   	ipv4.gateway：网关地址
   	ipv4.dns：DNS服务器地址
   	autoconnect：开机自动启用
   [root@hebor ~]# nmcli connection up eth0    # 使用链接名激活网络
   
   # 网卡配置文件
   
   ```

### 1.4 配置DNS

DNS配置文件是`/etc/resolv.conf`，修改配置文件后立即生效

```bash
[root@hebor ~]# echo "nameserver 223.5.5.5" >> /etc/resolv.conf
[root@hebor ~]# cat /etc/resolv.conf
```

## 二、远程管理

### 2.1 免密登录

1. 创建密钥对

   ```bash
   [root@pc80 ~]# ssh-keygen
   Generating public/private rsa key pair.
   Enter file in which to save the key (/root/.ssh/id_rsa):    # 密钥对保存路径，缺省保存在用户家目录下，不建议修改路径
   Created directory '/root/.ssh'.
   Enter passphrase (empty for no passphrase):    # 为密钥对设置密码，缺省为空密码
   Enter same passphrase again:                   # 确认密码，不设置密码
   ```

2. 向目标主机传递公钥

   ```bash
   [root@pc80 ~]# ssh-copy-id root@192.168.0.81
   ```

3. 重要文件

   ```bash
   # 源主机
   [root@pc80 ~]# cat ~/.ssh/known_hosts    # 此文件用于记录源主机已经远程管理过的机器
   
   # 目标远程主机
   [root@pc81 ~]# cat ~/.ssh/authorized_keys    # 保存公钥的配置文件，此配置文件用于保存的其他源主机的公钥信息
   ```

   免密登录本质上是采用密钥对的方式进行远程管理，一旦公钥部署完成，即便目标远程主机上的用户密码发生变更，也不会影响到登录，只有当目标远程主机上的保存公钥的配置文件被删除，才会影响到免密登录

# 日志

日志用于记录操作系统、应用程序在运行过程中发生的各种事件，通过日志内容可以查看及排除运行故障，同时日志也是信息安全控制的重要依据，日志会记录用户的各种操作行为。CentOS 7系统的日志由rsyslog服务统一记录、管理，rsyslog服务定义了写入日志的文本格式、文件存放路径等

**常见的系统日志**

| 日志文件          | 主要用途                         |
| ----------------- | -------------------------------- |
| /var/log/messages | 记录内核信息、各种服务的公共信息 |
| /var/log/dmesg    | 记录系统启动过程的各种信息       |
| /var/log/cron     | 记录与cron计划任务相关的信息     |
| /var/log/maillog  | 记录邮件收发相关的信息           |
| /var/log/secure   | 记录与访问限制相关的安全信息     |

**用户日志**

用户日志也有专门的配置文件进行记录，但Linux认为用户日志数据比较敏感，用户日志的配置文件无法直接查看其内容，用户日志信息由登录程序负责采用二进制格式记录、管理，用于记录登录用户的时间、来源、执行的命令等信息，虽然无法直接观察用户日志信息的配置文件，但可以通过命令查看日志信息

| 日志文件         | 主要用途                         | 对应命令      |
| ---------------- | -------------------------------- | ------------- |
| /var/log/lastlog | 记录最近的用户登录事件           |               |
| /var/log/wtmp    | 记录成功的用户登录/注销事件      | last          |
| /var/log/btmp    | 记录失败的用户登录事件           | lastb         |
| /var/run/utmp    | 记录当前登录的每个用户的相关信息 | users、who、w |

users、who、w 命令都是用于查看已登录的用户信息，只是三个命令的详细度不同

### 1.1 使用journalctl工具

journalctl是CentOS 7版本推荐使用的日志搜集工具，提取由systemd-journal服务搜集的日志信息，主要包括内核/系统日志、服务日志，它比较适合用于查看服务的报错日志

```bash
journalctl
	-u：指定服务名称
	-n：显示消息条数
```



## 二、日志消息的优先级

Linux内核定义的事件紧急程度分为 0~7 共8种优先级别，数值越小表示其对应事件的紧急程度越高、越重要

| 数值 | 标记            | 说明                       |
| ---- | --------------- | -------------------------- |
| 0    | EMERG（紧急）   | 会导致主机系统不可用的情况 |
| 1    | ALERT（警告）   | 必须马上采取措施解决的问题 |
| 2    | CRIT（严重）    | 比较严重的情况             |
| 3    | ERR（错误）     | 运行出现错误               |
| 4    | WARNING（提醒） | 可能会影响系统功能的事件   |
| 5    | NOTICE（注意）  | 不会影响系统，但值得注意   |
| 6    | INFO（信息）    | 一般信息                   |
| 7    | DEBUG（调试）   | 程序或系统调试信息等       |

## 二、网络接口配置

### 2.1 ifcfg-ethX 方式（CentOS 7）

```bash
vim /etc/sysconfig/network-scripts/ifcfg-eth0

TYPE=Ethernet
BOOTPROTO=none               # 可选 none/static/dhcp
DEFROUTE=yes                 # 开启默认路由
NAME=eth0                    # 逻辑设备名
DEVICE=eth0                  # 物理设备名
ONBOOT=yes                   # 开机启动

# 静态IP配置
IPADDR=192.168.1.100
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=223.5.5.5
DNS2=119.29.29.29

# IPv6配置
IPV6INIT=yes
IPV6ADDR=2001:db8::100/64
IPV6_DEFAULTGW=2001:db8::1

# 重启网络使配置生效
systemctl restart network
```

### 2.2 nmcli 方式

```bash
# 查看连接
nmcli connection show
nmcli connection show eth0

# 查看设备
nmcli device status

# 启动/停止连接
nmcli connection up eth0
nmcli connection down eth0

# 添加静态IP连接
nmcli connection add type ethernet ifname eth0 con-name static-eth0
nmcli connection modify static-eth0 ipv4.addresses 192.168.1.100/24
nmcli connection modify static-eth0 ipv4.gateway 192.168.1.1
nmcli connection modify static-eth0 ipv4.dns "223.5.5.5,119.29.29.29"
nmcli connection modify static-eth0 ipv4.method manual
nmcli connection up static-eth0

# 修改DHCP
nmcli connection modify eth0 ipv4.method auto
```

### 2.3 网卡重命名

```bash
# 1. 禁用默认命名规则（CentOS 7）
vim /etc/default/grub
# GRUB_CMDLINE_LINUX="rhgb quiet" 后添加：
net.ifnames=0 biosdevname=0

# 2. 重新生成GRUB配置
grub2-mkconfig -o /boot/grub2/grub.cfg

# 3. 重命名网卡配置文件
mv /etc/sysconfig/network-scripts/ifcfg-eno16777736 /etc/sysconfig/network-scripts/ifcfg-eth0

# 4. 修改配置内容
sed -i 's/eno16777736/eth0/g' /etc/sysconfig/network-scripts/ifcfg-eth0

# 5. 重启
reboot
```

### 2.4 首次安装系统修改网卡名

首次安装Centos7时，在选择安装界面通过 Tab 键调整初始安装配置，在配置信息末尾添加两个关键词配置`net.ifnames=0 biosdevname=0`，此两个选项分别表示将网卡名和设备名修改为`eth0`

## 三、DNS 配置

### 3.1 DNS 客户端配置

```bash
vim /etc/resolv.conf    # 网卡配置文件的DNS配置优先级高于此配置文件
nameserver 223.5.5.5        # 阿里DNS
nameserver 119.29.29.29      # 腾讯DNS
nameserver 8.8.8.8           # Google DNS

# 指定搜索域
search example.com localdomain
```

> 注意：`/etc/resolv.conf` 由 NetworkManager 管理，手动修改重启后可能丢失，建议通过 ifcfg 或 nmcli 配置。

### 3.2 常用公共DNS

### 3.3 DNS 测试命令

```bash
# 查询DNS解析
nslookup www.example.com
dig www.example.com
dig +trace www.example.com        # 完整追踪DNS解析过程
host www.example.com

# 测试DNS连通性

```

## 四、网络诊断工具

### 4.1 连通性测试

```bash
ping -c 4 192.168.1.1              # 发送4个ICMP包
ping -i 0.5 8.8.8.8                # 每0.5秒ping一次
ping -s 1472 192.168.1.1           # 指定数据包大小
```

### 4.2 路由追踪

```bash
traceroute www.baidu.com            # 追踪路由（UDP）
traceroute -I www.baidu.com        # 使用ICMP
traceroute -T www.baidu.com       # 使用TCP
tracert www.baidu.com              # Windows命令

mtr www.baidu.com                  # 实时路由追踪（结合ping+traceroute）
mtr -r www.baidu.com               # 一次性报告
```

### 4.3 端口与连接

```bash
# 查看端口
netstat -tulnp                     # 监听端口
netstat -anp | grep ESTABLISHED    # 已建立连接
netstat -s                         # 统计各协议信息

# ss 命令（netstat的现代替代）
ss -tulnp                          # 查看监听端口
ss -tunap                         # 查看所有连接
ss -s                             # 统计摘要
ss -tnp | grep :80                # 查找连接80端口的进程

# 参数说明
# -t: TCP  -u: UDP  -l: 监听  -n: 数字显示  -p: 进程  -a: 所有
```

### 4.4 网络抓包

```bash
tcpdump -i eth0                    # 抓取eth0所有包
tcpdump -i eth0 -c 100            # 抓取100个包后退出
tcpdump -i eth0 host 192.168.1.1 # 过滤主机
tcpdump -i eth0 port 80           # 过滤端口
tcpdump -i eth0 tcp               # 只抓TCP
tcpdump -i eth0 -w capture.pcap   # 保存到文件
tcpdump -r capture.pcap           # 读取抓包文件

# 常用表达式
tcpdump -i eth0 'port 22 and host 192.168.1.100'
tcpdump -i eth0 'tcp[tcpflags] & tcp-syn != 0'
```

### 4.5 带宽测试

```bash
# iperf3（需两台机器）
# 服务端：
iperf3 -s

# 客户端：
iperf3 -c server_ip -t 10         # 测试10秒
iperf3 -c server_ip -P 4          # 4线程并发
```

## 五、网络综合故障排查

```bash
# 排查顺序：物理连接 → IP配置 → 网关 → DNS

# 1. 查看IP配置
ip addr show
ifconfig

# 2. 查看路由表
ip route
route -n

# 3. 测试网关连通性
ping -c 2 192.168.1.1

# 4. 测试DNS解析
nslookup www.baidu.com

# 5. 测试端口连通性
telnet 192.168.1.1 22
nc -zv 192.168.1.1 22
curl -v https://example.com

# 6. 查看网络接口状态
ethtool eth0
ethtool -S eth0

# 7. 查看网络统计
netstat -i
ip -s link

# 常见问题：
# - 网卡未UP → ip link set eth0 up
# - 网关不通 → 检查网关配置和物理连接
# - DNS解析失败 → 检查/etc/resolv.conf
# - 端口不通 → 检查防火墙和服务状态
```
