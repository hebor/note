# Linux 网络基础配置

## 一、主机名管理

### 1.1 查看与设置

```bash
# 查看主机名
hostname
hostnamectl
uname -n

# 临时设置（重启失效）
hostname web01

# 永久设置（CentOS 7+）
hostnamectl set-hostname web01

# 配置文件
vim /etc/hostname
```

### 1.2 本地域名解析

```bash
vim /etc/hosts
127.0.0.1   localhost localhost.localdomain
::1         localhost localhost.localdomain
192.168.1.100   web01 web01.example.com
```

## 二、网络接口配置

### 2.1 ifcfg-ethX 方式（CentOS 7）

```bash
vim /etc/sysconfig/network-scripts/ifcfg-eth0

TYPE=Ethernet
BOOTPROTO=none               # 可选 none/static/dhcp
DEFROUTE=yes                 # 开启默认路由
NAME=eth0                    # 逻辑设备名
DEVICE=eth0                  # 物理设备名
ONBOOT=yes                   # 开机启动

# 静态IP配置
IPADDR=192.168.1.100
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=223.5.5.5
DNS2=119.29.29.29

# IPv6配置
IPV6INIT=yes
IPV6ADDR=2001:db8::100/64
IPV6_DEFAULTGW=2001:db8::1

# 重启网络使配置生效
systemctl restart network
```

### 2.2 nmcli 方式

```bash
# 查看连接
nmcli connection show
nmcli connection show eth0

# 查看设备
nmcli device status

# 启动/停止连接
nmcli connection up eth0
nmcli connection down eth0

# 添加静态IP连接
nmcli connection add type ethernet ifname eth0 con-name static-eth0
nmcli connection modify static-eth0 ipv4.addresses 192.168.1.100/24
nmcli connection modify static-eth0 ipv4.gateway 192.168.1.1
nmcli connection modify static-eth0 ipv4.dns "223.5.5.5,119.29.29.29"
nmcli connection modify static-eth0 ipv4.method manual
nmcli connection up static-eth0

# 修改DHCP
nmcli connection modify eth0 ipv4.method auto
```

### 2.3 网卡重命名

```bash
# 1. 禁用默认命名规则（CentOS 7）
vim /etc/default/grub
# GRUB_CMDLINE_LINUX="rhgb quiet" 后添加：
net.ifnames=0 biosdevname=0

# 2. 重新生成GRUB配置
grub2-mkconfig -o /boot/grub2/grub.cfg

# 3. 重命名网卡配置文件
mv /etc/sysconfig/network-scripts/ifcfg-eno16777736 /etc/sysconfig/network-scripts/ifcfg-eth0

# 4. 修改配置内容
sed -i 's/eno16777736/eth0/g' /etc/sysconfig/network-scripts/ifcfg-eth0

# 5. 重启
reboot
```

### 2.4 首次安装系统修改网卡名

首次安装Centos7时，在选择安装界面通过 Tab 键调整初始安装配置，在配置信息末尾添加两个关键词配置`net.ifnames=0 biosdevname=0`，此两个选项分别表示将网卡名和设备名修改为`eth0`

## 三、DNS 配置

### 3.1 DNS 客户端配置

```bash
vim /etc/resolv.conf    # 网卡配置文件的DNS配置优先级高于此配置文件
nameserver 223.5.5.5        # 阿里DNS
nameserver 119.29.29.29      # 腾讯DNS
nameserver 8.8.8.8           # Google DNS

# 指定搜索域
search example.com localdomain
```

> 注意：`/etc/resolv.conf` 由 NetworkManager 管理，手动修改重启后可能丢失，建议通过 ifcfg 或 nmcli 配置。

### 3.2 常用公共DNS

| DNS服务商 | IP地址 |
| :--- | :--- |
| 阿里DNS | 223.5.5.5 / 223.6.6.6 |
| 腾讯DNS | 119.29.29.29 / 182.254.116.116 |
| Google DNS | 8.8.8.8 / 8.8.4.4 |
| Cloudflare | 1.1.1.1 / 1.0.0.1 |
| 114 DNS | 114.114.114.114 / 114.114.115.115 |

### 3.3 DNS 测试命令

```bash
# 查询DNS解析
nslookup www.example.com
dig www.example.com
dig +trace www.example.com        # 完整追踪DNS解析过程
host www.example.com

# 测试DNS连通性
ping -c 4 www.baidu.com
curl -I https://www.baidu.com
```

### 3.4 主机名解析优先级

```
/etc/hosts      → 本地解析（最高优先级）
/etc/resolv.conf → DNS服务器
```

## 四、网络诊断工具

### 4.1 连通性测试

```bash
ping -c 4 192.168.1.1              # 发送4个ICMP包
ping -i 0.5 8.8.8.8                # 每0.5秒ping一次
ping -s 1472 192.168.1.1           # 指定数据包大小
```

### 4.2 路由追踪

```bash
traceroute www.baidu.com            # 追踪路由（UDP）
traceroute -I www.baidu.com        # 使用ICMP
traceroute -T www.baidu.com       # 使用TCP
tracert www.baidu.com              # Windows命令

mtr www.baidu.com                  # 实时路由追踪（结合ping+traceroute）
mtr -r www.baidu.com               # 一次性报告
```

### 4.3 端口与连接

```bash
# 查看端口
netstat -tulnp                     # 监听端口
netstat -anp | grep ESTABLISHED    # 已建立连接
netstat -s                         # 统计各协议信息

# ss 命令（netstat的现代替代）
ss -tulnp                          # 查看监听端口
ss -tunap                         # 查看所有连接
ss -s                             # 统计摘要
ss -tnp | grep :80                # 查找连接80端口的进程

# 参数说明
# -t: TCP  -u: UDP  -l: 监听  -n: 数字显示  -p: 进程  -a: 所有
```

### 4.4 网络抓包

```bash
tcpdump -i eth0                    # 抓取eth0所有包
tcpdump -i eth0 -c 100            # 抓取100个包后退出
tcpdump -i eth0 host 192.168.1.1 # 过滤主机
tcpdump -i eth0 port 80           # 过滤端口
tcpdump -i eth0 tcp               # 只抓TCP
tcpdump -i eth0 -w capture.pcap   # 保存到文件
tcpdump -r capture.pcap           # 读取抓包文件

# 常用表达式
tcpdump -i eth0 'port 22 and host 192.168.1.100'
tcpdump -i eth0 'tcp[tcpflags] & tcp-syn != 0'
```

### 4.5 带宽测试

```bash
# iperf3（需两台机器）
# 服务端：
iperf3 -s

# 客户端：
iperf3 -c server_ip -t 10         # 测试10秒
iperf3 -c server_ip -P 4          # 4线程并发
```

## 五、网络综合故障排查

```bash
# 排查顺序：物理连接 → IP配置 → 网关 → DNS

# 1. 查看IP配置
ip addr show
ifconfig

# 2. 查看路由表
ip route
route -n

# 3. 测试网关连通性
ping -c 2 192.168.1.1

# 4. 测试DNS解析
nslookup www.baidu.com

# 5. 测试端口连通性
telnet 192.168.1.1 22
nc -zv 192.168.1.1 22
curl -v https://example.com

# 6. 查看网络接口状态
ethtool eth0
ethtool -S eth0

# 7. 查看网络统计
netstat -i
ip -s link

# 常见问题：
# - 网卡未UP → ip link set eth0 up
# - 网关不通 → 检查网关配置和物理连接
# - DNS解析失败 → 检查/etc/resolv.conf
# - 端口不通 → 检查防火墙和服务状态
```

## 六、网络相关文件汇总

| 文件路径 | 说明 |
| :--- | :--- |
| `/etc/sysconfig/network` | 全局网络配置（主机名、网关） |
| `/etc/sysconfig/network-scripts/ifcfg-*` | 网卡配置文件 |
| `/etc/hostname` | 主机名 |
| `/etc/resolv.conf` | DNS客户端配置 |
| `/etc/hosts` | 本地静态解析 |
| `/etc/services` | 端口与服务的映射表 |
| `/proc/sys/net/` | 内核网络参数（sysctl） |
