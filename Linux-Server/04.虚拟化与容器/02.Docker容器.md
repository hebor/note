# Docker 容器

## 一、Docker 概述

Docker 是 Linux 容器的增强版，基于 Linux 内核的 namespace 和 cgroups 机制实现资源隔离和限制。

### 1.1 Docker vs 传统虚拟化

| 特性 | Docker 容器 | 虚拟机 |
| :--- | :--- | :--- |
| 启动时间 | 秒级 | 分钟级 |
| 性能 | 接近原生 | 有虚拟化损耗 |
| 资源占用 | 小（MB级） | 大（GB级） |
| 隔离性 | 进程级隔离 | 完整硬件隔离 |
| 迁移性 | 一次构建，到处运行 | 需要完整镜像迁移 |
| Guest OS | 不需要 | 需要独立 Guest OS |

### 1.2 核心概念

- **镜像（Image）**：只读模板，包含应用程序和依赖
- **容器（Container）**：镜像的运行实例
- **仓库（Registry）**：存储和分发镜像（Docker Hub、Harbor）
- **Dockerfile**：构建镜像的配置文件

## 二、namespace 资源隔离

Linux namespace 提供 6 种资源隔离：

| namespace | 作用 |
| :--- | :--- |
| UTS | 独立主机名和域名 |
| Mount | 独立挂载树视图 |
| IPC | 进程间通信隔离 |
| PID | 独立进程树（容器内PID从1开始） |
| User | 独立用户/用户组映射 |
| Network | 独立网络栈（IP、端口、路由等） |

## 三、Docker 安装

### 3.1 CentOS 7+

```bash
# 安装依赖
yum install -y yum-utils device-mapper-persistent-data lvm2

# 添加 Docker 仓库
yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

# 安装
yum install -y docker-ce docker-ce-cli containerd.io

# 启动
systemctl enable --now docker

# 验证
docker version
docker run hello-world
```

### 3.2 Docker 镜像加速

```bash
# 创建配置文件
mkdir -p /etc/docker
vim /etc/docker/daemon.json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com"
  ],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "100m"
  }
}

# 重启 Docker
systemctl restart docker
```

## 四、镜像管理

### 4.1 基础命令

```bash
# 搜索镜像
docker search nginx

# 拉取镜像
docker pull nginx:latest
docker pull nginx:1.20-alpine

# 查看本地镜像
docker images
docker image ls

# 删除镜像
docker rmi nginx:latest

# 构建镜像（Dockerfile）
docker build -t myapp:v1 .

# 镜像标签
docker tag myapp:v1 myrepo.com/myapp:v1

# 推送镜像
docker push myrepo.com/myapp:v1
```

### 4.2 Dockerfile 示例

```dockerfile
FROM centos:7
LABEL maintainer="admin@example.com"

# 设置环境变量
ENV APP_HOME=/app
WORKDIR $APP_HOME

# 复制文件
COPY ./dist/ $APP_HOME/

# 安装依赖
RUN yum install -y nginx && \
    yum clean all

# 暴露端口
EXPOSE 80 443

# 健康检查
HEALTHCHECK --interval=30s --timeout=3s CMD curl -f http://localhost/ || exit 1

# 启动命令
CMD ["nginx", "-g", "daemon off;"]
```

### 4.3 Dockerfile 常用指令

| 指令 | 说明 |
| :--- | :--- |
| FROM | 基础镜像 |
| LABEL | 元数据 |
| ENV | 环境变量 |
| WORKDIR | 工作目录 |
| COPY | 复制文件 |
| ADD | 复制+解压缩/URL |
| RUN | 执行命令 |
| EXPOSE | 声明端口 |
| CMD | 启动命令（可被覆盖） |
| ENTRYPOINT | 启动命令（不可被覆盖） |
| HEALTHCHECK | 健康检查 |
| ARG | 构建参数 |

## 五、容器管理

### 5.1 创建与启动

```bash
# 交互式创建并运行
docker run -it --name mycontainer centos:7 /bin/bash

# 后台运行
docker run -d --name myweb -p 8080:80 nginx

# 常用选项
# -i: 交互式 -t: 分配终端
# -d: 后台运行 --rm: 停止后删除
# -p host:container: 端口映射
# -v host:container: 目录挂载
# -e VAR=value: 环境变量
# --name: 容器名称
# --network: 网络模式
```

### 5.2 容器操作

```bash
# 查看容器
docker ps                   # 运行中的
docker ps -a               # 所有
docker ps -l               # 最近创建的

# 启动/停止/重启
docker start mycontainer
docker stop mycontainer
docker restart mycontainer

# 进入容器
docker exec -it mycontainer /bin/bash

# 查看日志
docker logs -f mycontainer          # 实时跟踪
docker logs --tail 100 mycontainer   # 最近100行

# 查看容器信息
docker inspect mycontainer

# 查看资源使用
docker stats mycontainer

# 复制文件
docker cp host_file mycontainer:/path/
docker cp mycontainer:/path/file .

# 提交为镜像
docker commit mycontainer myimage:v1
```

### 5.3 容器网络

```bash
# 查看网络
docker network ls

# 创建网络
docker network create --driver bridge mynet

# 容器连接到网络
docker run -d --network mynet --name app myapp

# 连接已存在的容器
docker network connect mynet mycontainer
docker network disconnect mynet mycontainer

# 网络模式
# bridge: 默认桥接网络
# host: 共享宿主机网络栈
# none: 无网络
# overlay: 跨主机Docker Swarm网络
```

### 5.4 数据持久化（数据卷）

```bash
# 创建数据卷
docker volume create mydata

# 查看数据卷
docker volume ls
docker volume inspect mydata

# 挂载数据卷
docker run -d -v mydata:/data --name web nginx
docker run -d -v /host/data:/container/data --name web nginx

# 备份数据卷
docker run --rm -v mydata:/data -v $(pwd):/backup alpine tar cvf /backup/backup.tar /data

# 删除未使用的数据卷
docker volume prune
```

## 六、Docker Compose

### 6.1 docker-compose.yml 示例

```yaml
version: '3.8'

services:
  web:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./html:/usr/share/nginx/html
    networks:
      - frontend
    depends_on:
      - api
    restart: unless-stopped

  api:
    build: ./api
    environment:
      - DB_HOST=db
      - REDIS_HOST=redis
    networks:
      - backend
    depends_on:
      - db
      - redis

  db:
    image: mysql:5.7
    environment:
      MYSQL_ROOT_PASSWORD: secret
      MYSQL_DATABASE: app
    volumes:
      - dbdata:/var/lib/mysql
    networks:
      - backend
    restart: unless-stopped

  redis:
    image: redis:alpine
    networks:
      - backend
    restart: unless-stopped

networks:
  frontend:
  backend:

volumes:
  dbdata:
```

### 6.2 常用命令

```bash
# 启动
docker-compose up -d

# 停止
docker-compose down

# 查看日志
docker-compose logs -f

# 扩展服务
docker-compose up -d --scale web=3

# 重新构建
docker-compose up -d --build

# 查看状态
docker-compose ps
```

## 七、私有仓库

### 7.1 部署 Registry

```bash
# 运行 Registry
docker run -d --name registry -p 5000:5000 --restart=always \
  -v /data/registry:/var/lib/registry \
  registry:2

# 推送镜像到私有仓库
docker tag nginx:latest localhost:5000/mynginx:v1
docker push localhost:5000/mynginx:v1

# 从私有仓库拉取
docker pull localhost:5000/mynginx:v1

# 允许 HTTP（非生产环境）
vim /etc/docker/daemon.json
{
  "insecure-registries": ["192.168.1.100:5000"]
}
systemctl restart docker
```
