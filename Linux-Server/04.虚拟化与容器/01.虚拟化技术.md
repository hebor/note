# 虚拟化技术

## 一、虚拟化概述

### 1.1 虚拟化类型

| 类型 | 说明 | 代表技术 |
| :--- | :--- | :--- |
| **主机级虚拟化** | 提供完整虚拟硬件平台，需装Guest OS | KVM, VMware ESXi, VirtualBox |
| **容器级虚拟化** | 共享宿主机内核，轻量级隔离 | Docker, Podman, LXC |
| **裸金属虚拟化（I型）** | Hypervisor直接安装硬件上 | VMware ESXi, Xen |
| **寄居虚拟化（II型）** | Hypervisor运行在Host OS上 | VirtualBox, KVM |

### 1.2 主机级虚拟化 vs 容器级虚拟化

```
主机级虚拟化：
┌─────────────────────────────────┐
│  虚拟机1(Guest OS)  │  虚拟机2  │
│  App │ App │ App  │  App      │
│  Libs│ Libs│ Libs │  Libs     │
│  Linux Kernel       │  Linux   │
└──────────┬──────────┴──────────┘
           ↓
┌─────────────────────────────────┐
│        Hypervisor (KVM)         │
└──────────┬─────────────────────┘
           ↓
┌─────────────────────────────────┐
│        Host OS (Linux)          │
└──────────┬─────────────────────┘
           ↓
┌─────────────────────────────────┐
│           Hardware              │
└─────────────────────────────────┘

容器级虚拟化：
┌─────────────────────────────────┐
│  容器1     │  容器2  │  容器3   │
│  App │ App │ App    │  App      │
│  Libs│ Libs│ Libs   │  Libs     │
└──────────┬──────────┴──────────┘
           ↓
┌─────────────────────────────────┐
│     Docker Engine / containerd  │
└──────────┬─────────────────────┘
           ↓
┌─────────────────────────────────┐
│        Host Kernel (Linux)      │
└──────────┬─────────────────────┘
           ↓
┌─────────────────────────────────┐
│           Hardware              │
└─────────────────────────────────┘
```

## 二、KVM 虚拟化

### 2.1 KVM 概述

KVM（Kernel-based Virtual Machine）是集成在 Linux 内核的开源虚拟化模块（自 2.6.20），需要 CPU 硬件支持（Intel VT-x / AMD-V）。

### 2.2 环境准备

```bash
# 1. 检查 CPU 支持虚拟化
grep -E '(vmx|svm)' /proc/cpuinfo
# Intel CPU：vmx
# AMD CPU：svm

# 2. 加载 KVM 模块
modprobe kvm
modprobe kvm_intel      # Intel CPU
# 或
modprobe kvm_amd        # AMD CPU

# 3. 安装工具
yum install -y qemu-kvm qemu-system-x86 libvirt-daemon-system libvirt-clients bridge-utils virt-install virt-manager

# 4. 启动 libvirtd
systemctl enable --now libvirtd

# 5. 将普通用户加入 kvm/libvirt 组
usermod -aG kvm,libvirt username
```

### 2.3 创建虚拟机

#### 命令行创建（完全文本模式）

```bash
# 创建磁盘
qemu-img create -f qcow2 /var/lib/libvirt/images/vm01.qcow2 20G

# 创建虚拟机
virt-install \
  --name=vm01 \
  --vcpus=2 \
  --memory=2048 \
  --disk path=/var/lib/libvirt/images/vm01.qcow2,format=qcow2 \
  --location=/var/lib/libvirt/images/CentOS-7-x86_64-DVD.iso \
  --network bridge=br0 \
  --graphics none \
  --extra-args="console=ttyS0" \
  --noautoconsole
```

#### 完全文本模式创建（无需VNC）

```bash
# 使用 --location 指定ISO --extra-args 指定内核参数
virt-install \
  --name=vm02 \
  --vcpus=2 \
  --memory=4096 \
  --disk path=/var/lib/libvirt/images/vm02.qcow2,format=qcow2 \
  --location=/var/lib/libvirt/images/CentOS-7-x86_64-DVD.iso \
  --network bridge=br0 \
  --graphics none \
  --extra-args="console=ttyS0,115200n8 serial"
```

### 2.4 qemu-img 磁盘格式

| 格式 | 说明 |
| :--- | :--- |
| **qcow2** | 稀疏格式，支持快照，性能好（推荐） |
| **raw** | 原始镜像，性能最好但占用空间 |
| **qed** | 兼容 qcow2，功能较少 |

```bash
# 创建磁盘
qemu-img create -f qcow2 /path/to/disk.qcow2 50G

# 创建预分配元数据的 qcow2（更快但磁盘已分配）
qemu-img create -f qcow2 -o preallocation=metadata /path/to/disk.qcow2 50G

# 调整磁盘大小
qemu-img resize /path/to/disk.qcow2 +20G

# 转换格式
qemu-img convert -f raw -O qcow2 raw.img qcow2.img
```

### 2.5 虚拟机管理

```bash
# 列出虚拟机
virsh list                  # 运行中
virsh list --all            # 所有

# 启动/停止/重启
virsh start vm01
virsh shutdown vm01        # 优雅关机
virsh destroy vm01          # 强制停止
virsh reboot vm01

# 删除虚拟机
virsh undefine vm01         # 删除配置
virsh undefine --domain vm01 --remove-all-storage  # 删除配置和磁盘

# 控制台访问
virsh console vm01          # 连接虚拟机控制台
# 退出控制台：Ctrl+]

# 编辑配置
virsh edit vm01

# 克隆
virt-clone --original vm01 --name vm02 --file /path/to/vm02.qcow2
```

### 2.6 网络配置

```bash
# 查看网络
virsh net-list --all
virsh net-dhcp-leases default

# NAT模式（默认virbr0）
virsh net-start default
virsh net-autostart default

# 创建桥接网络（用于外部访问）
cat > /etc/sysconfig/network-scripts/ifcfg-br0 << 'EOF'
DEVICE=br0
TYPE=Bridge
ONBOOT=yes
BOOTPROTO=static
IPADDR=192.168.1.100
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=223.5.5.5
EOF

# 编辑虚拟机网卡配置使用桥接
virsh edit vm01
# <interface type='bridge'>
#   <source bridge='br0'/>
# </interface>
```

### 2.7 快照管理

```bash
# 创建快照
virsh snapshot-create-as --domain vm01 --name snap01 --description "Initial snapshot"

# 列出快照
virsh snapshot-list vm01

# 查看快照信息
virsh snapshot-info vm01 --snapshotname snap01

# 恢复快照
virsh snapshot-revert vm01 snap01

# 删除快照
virsh snapshot-delete vm01 snap01
```
