# Linux 基础命令

## 一、文件与目录操作

### 1.1 列出目录内容 — ls

```bash
ls -la /var/log
    -a：列出/var/log所有文件（含隐藏文件）
	-A：与 -a 参数实现同样功能，两者区别在于 -A 不会显示隐藏文件中的两个特殊目录 ./、../，这更有利于shell脚本的编写
ls -ltr
	-t：按修改时间排序，最新的在前
	-r：reverse，反转
ls -lhi /etc/
	-h：人性化显示
	-i：查看文档的inode信息
ls -FR /home/hebor/
    -F：条目结束指示符，向条目追加指示符(其中一个*/=>@|)。目录名后加正斜线(/)、文件名后加星号(*)，这更加便于管理员在标准输出识别目录
    -R：递归展示
```

### 1.2 切换目录 — cd

```bash
cd /etc/sysconfig        # 切换到绝对路径
cd ..                    # 切换到上级目录
cd ~                     # 切换到当前用户家目录
cd -                     # 切换到上一次所在目录
```

### 1.3 查看文件内容 — cat / tac

```bash
cat -n ~/.bashrc /etc/passwd
	-n：显示行号
	-b：只给有文本的行加上行号
	
tac /var/log/messages     # 反向显示（最后一行在前）
```

`cat - concatenate files and print on the standard output`，`cat`命令本身的作用就是连结文件并打印到标准输出，只不过`cat`命令不连结多个文件时，也可以用于单独查看某一个文件的内容

### 1.4 分页查看 — more / less

```bash
more /var/log/messages    # 空格翻页，q退出

less /var/log/messages    # 支持上下键翻页，/搜索
```

### 1.5 查看文件头/尾 — head / tail

```bash
head /etc/passwd          # 默认查看文件前10行
	-n 20：指定查看的行数
	 
tail /var/log/messages    # 默认查看文件后10行
	-n 20：指定查看的行数
	-f：持续查看指定文件。持续查看的文件被删除后，重建一个绝对路径相同的文件，不会继续监控
	-F：持续查看指定文件。持续查看的文件被删除后会有信息提示，重建一个绝对路径相同的文件，会持续监控
```

### 1.6 文本搜索 — grep

```bash
grep "error" /var/log/messages    # 搜索含error的行
	-n：显示行号
	-v：对过滤条件取反（排除）
	-i：忽略过滤条件字符的大小写
	-c：统计匹配条件的行的总数
	-B 2：Before，连同前面2行一起过滤显示
	-A 2：After，连通后面2行一起过滤显示
	-C 2：Context，连通上下文2行一起过滤显示
grep -r "192.168" /etc/           # 递归搜索目录
grep -E "root|adm" /etc/passwd    # 扩展正则：匹配root或adm
grep ^root /etc/passwd          # 过滤以root开头的行
grep root$ /etc/passwd          # 过滤以root结尾的行
grep -c "^$" /etc/services      # 过滤匹配条件的行的总数
```

### 1.7 文件操作三剑客 — cp / mv / rm

```bash
cp -r /etc/sysconfig/ ./test/    # 递归复制
	-p：保持属性不变
	-l：硬链接
	-s：软链接
	-f：强制覆盖
cp -u oldfile newfile	         # 常用于备份工作
	-u: update，源文档与目标文档存在差异时才复制
	-d：如果目标文件是链接文件，则仅复制该链接文件属性，而不是复制该链接文件指向的源文件

mv oldname newname               # 重命名/移动
	-u：update，若目标文档已存在，且源文档较新时才更新

rm -rf /tmp/test                 # 强制递归删除
```

使用cp命令时在目录名称的尾部加上了一个正斜线“/”，这有助于明确目的。而且在复制单个文件时，如果没有使用正斜线，目标目录又不存在，此时复制某个文件到test目录下，会直接变成创建一个名为test的文件

cp命令支持一次复制多个文件或目录，在多个参数的情况下，只有最后一个参数会被视作目标，其他参数都会被视作源数据

### 1.8 创建目录和文件 — mkdir / touch

```bash
mkdir /data/            # 创建目录
	-p：递归创建目录

touch file.txt          # 创建文件
touch file{1..5}.txt    # 批量创建文件
```

### 1.9 查看文件详细信息 — stat / file

```bash
stat /etc/passwd        # 查看文件的属性信息
# Access: 访问时间（读取文件内容）
# Modify: 修改时间（内容变化）
# Change: 改变时间（元数据如权限、大小变化）

file /usr/bin/cp        # 获取文件类型
```

## 二、系统信息查看命令

### 2.1 系统信息 — uname / hostname

```bash
uname             # 默认查看内核名称
	-a：显示内核所有信息
	-r：输出内核版本号

hostname           # 显示主机名
hostname web01     # 临时设置主机名（重启失效）
hostnamectl set-hostname web01  # 永久设置主机名
```

### 2.2 负载 — uptime

```bash
uptime
# 16:35:48 up 12 days,  3:22,  2 users,  load average: 0.15, 0.10, 0.08
# 系统当前时间 | 运行天数 | 登录用户数 | 1/5/15分钟平均负载
```

负载指的是在单位时间内系统分配给CPU处理得进程数量，进程数越多负载越高，机器压力越大

- 对于负载信息，负载大小数值取决于CPU核心数，负载的数值不能超过CPU的核心数
- 例如8核心，则负载达到7时就应该给予关注，负载与核心数相等时可能造成宕机
- CPU负载越大发热量越高，当散热无法满足CPU的需求时，可能会引发过热保护，直接宕机

### 2.3 系统时间 — date

```bash
date                          # 显示当前日期时间
date -s "2025-01-01 12:00:00" # 设置系统时间
date -d "-3 day"              # 显示指定的日期时间
date +%Y-%m-%d                # 格式化输出：2025-01-01
date +%H:%M:%S                # 格式化输出：12:00:00
date +%s                      # 时间戳
```

## 三、管道与重定向

### 3.1 管道 — | / xargs

```bash
ls /etc/ | grep "conf"    # 过滤/etc/下的.conf文件

find ./test/ -name "*test*" | xargs rm -f    # 删除./test/目录下的所有test开头的文件
	-n 2：指定每次传递给后面命令的参数个数
	-I {}：指定一个占位符，将输入的数据替换到指定位置
	-0：以null字符作为分隔符，用于处理文件名中包含空格或特殊字符的情况
find . -name "*.txt" | xargs -I {} cp {} /backup/
```

管道符与`xargs`命令的工作原理与应用场景有本质区别，但两者都是日常运维和脚本中最常用的工具：

1. 管道符用于将前一个命令的标准输出，作为后一个命令的标准输入，传递的是数据流（只有程序能处理）
2. `xargs`命令用于将标准输入转换为命令行参数，然后传递给后面的命令执行，传递的是命令行参数

管道符的局限性就在于不是所有的命令都能够接受标准输入，例如`rm`、`cp`、`mv`、`echo`等，这类命令需要的是命令行参数。

### 3.2 重定向 — >

```bash
cat /etc/passwd > ./test/file     # 标准输出重定向（覆盖）
cat /etc/passwd >> ./test/file    # 标准输出重定向（追加）
la 2> ./test/file                 # 标准错误重定向
ls &> ./test/file                 # 标准输出和错误都重定向
cat < /etc/passwd                 # 从文件读取输入
```

## 四、压缩与归档

### 4.1 归档工具 — tar

大多情况下归档和压缩都是为了更好的对零散的文件进行整理和共享，在专业领域归档和压缩分别代表着两个不同的动作，归档指的是讲多个零散的文件整理为一个文件，文件总体的大小基本不变；压缩指的是按照某种算法减小文件所占用的空间大小，恢复时按照对应的逆向算法解压缩

在Linux下常见的压缩格式有三种：gzip、bzip2、xz，三种压缩格式分别对应三种后缀名`.gz`、`.bz2`、`.xz`，Linux下的所有文件命名并没有后缀名要求，但通过tar指令打包的文件，为了便于理解仍建议使用后缀

```bash
# 压缩
tar -czf backup.tar.gz /data        # tar + gzip（最常用）
	-c：创建压缩文件
	-f：指定压缩文件名称
	-j：bzip2压缩，压缩率更高
	-J：xz压缩，压缩率最高
# 解压
tar -xzf backup.tar.gz -C /dest/    # 解压到指定目录
	-x：解包
	-C：解包到指定目录
# 查看
tar -tf backup.tar.gz               # 不解压查看内容列表
	-t：查看归档文件内容
```

使用tar指令归档文件时，不建议将压缩包直接存放在需要归档的目录下，可能会产生内存溢出问题，例如，执行`tar -zcf /opt/test.tar.gz /opt`指令的过程中，在归档`/opt/`目录的时候，该目录下产生了新的数据`test.tar.gz`，`/opt/`目录下的数据产生变化后需要继续归档，继续归档又会在`/opt/`目录下产生新的数据，一个循环。<font style="color: red">tar指令不能针对一直在变化的数据进行打包</font>

使用tar指令解包时不需要使用`-z`、`-j`、`-J`制定解压格式，`-x`选项会自动调用相关的压缩工具，先进行解压再解包

### 4.2 压缩工具 - zip

tar命令与zip命令的区别在于，tar命令虽然也能实现压缩功能，但是tar命令主要是在linux系统上使用，zip命令可跨平台。实际上，对于现在的windows系统而言，tar包同样可以正常解压。

```bash
zip -r backup.zip /etc/passwd /home
    -r：被压缩的数据中只要含有目录，都需要使用此选项
unzip backup.zip -d /mnt/
    -d：解压文件到指定目录
```

## 五、网络命令

### 5.1 网络配置 — ifconfig / ip

```bash
ifconfig                    # 查看所有处于激活状态的网卡信息
	-a：查看所有网卡信息，包括未激活网卡
ifconfig eth0               # 查看指定网卡
ifconfig eth0 up/down       # 启用/禁用eth0网卡
ifconfig eth0 192.168.0.1 netmask 255.255.255.0    # 临时配置网卡IP
ifconfig eth0 hw ether 00:11:22:33:44:55           #修改MAC地址
arp -a                      #查看ARP缓存

ip addr show                # 查看所有网卡状态
ip addr show eth0           # 查看eth0网卡状态
ip addr add/del 192.168.0.1/24 dev eth0    # 给eth0网卡添加/删除一个IP
ip -s link show eth0        # 查看网卡eth0的详细流量统计信息
ip link set eth0 up/down    # 启用/禁用eth0网卡
ip link set dev eth0 address 00:11:22:33:44:55     # 修改MAC地址
ip route show               # 查看路由
ip route add/del default via 192.168.1.1       # 添加/删除默认网关
ip route add 10.0.0.0/24 via 192.168.1.254 dev eth0    #添加静态路由
ip neigh show               # 查看ARP缓存
```

`ifconfig`工具需要安装`net-tools`软件包，`ip`命令`CentOS`系统默认自带

### 5.2 网络检测 — ping

```bash
ping 192.168.1.1    # 网络联通性检测
	-c 4：发送4个检测包
	-i 0.5：每0.5秒ping一次
```

### 5.3 网络监控 — netstat / ss

```bash
netstat -tunpl    # 查看当前主机会话连接
    -t：仅展示tcp协议的连接
    -u：仅显示udp协议的连接
    -n：将地址从字母组合转化未ip，将协议转化为端口显示
    -l：过滤“staate”列值为LISTEN的连接
    -p：表示显示发起连接的进程pid和进程名称
    -a：显示所有状态的连接（包括监听和非监听）
netstat -an | grep ESTABLISHED    # 查看已建立连接

ss -tulnp         # 更快速的端口查看
```

网络监控工具`netstat`和`ss`，在高并发场景下，`ss`命令比`netstat`命令性能更高，两者核心参数基本完全一致

### 5.4 网络抓包 — tcpdump

```bash
tcpdump    # 默认查看监控第一个网卡的流量
	-i eth0：指定网卡接口，或监控所有网卡流量 -i any
	-nn：不解析主机名和端口名
	-c：指定抓取的数据包的数量
	-w：将抓包数据保存到文件
	-v / -vv / -vvv：增加详细信息的输出程度
	
tcpdump -i eth0 -nn host 192.168.0.42        # 抓取特定IP的数据（包含入站和出站）
tcpdump -i eth0 -nn src host 192.168.0.42    # 抓指定源IP的数据
tcpdump -i eth0 -nn dst host 192.168.0.42    # 抓指定目标IP的数据
tcpdump -i eth0 -nn port 443                 # 抓特定端口的流量
```

`tcpdump`工具虽然也能看数据包，但大多数场景下基本上只用于抓包，然后用WireShark查看抓包文件。一些场景下，可以通过WireShark过滤五元组来筛选数据，但在数据量较大的情况下，要快速定位到一些特征数据，需要用些其他方法。

以日志转发场景为例，通过BurpSuite访问目标后，将HTTP请求在重放器中手动添加一个自定义参数（例如`X-My-Marker: UNIOUE_STRING_888`），捕获数据包后用WireShark打开，通过过滤式`udp.payload contains "UNIOUE_STRING_888"`过滤请求，或者选中一个请求报文，以”追踪流“的方式查看报文内容，再对自定义参数进行过滤，可以快速定位到特征请求。

需要注意，这个场景中前端使用HTTP请求，并通过自定义HTTP请求头的方式产生特征数据，后端使用syslog转发日志，抓包的数据实际上是syslog转发的日志数据，所以在WireShark中用的过滤式是`udp.payload`，如果WireShark中的抓包数据是HTTP请求的数据，那么过滤式要改成`http.request.line`，随实际情况变化。

### 5.5 网络下载 — curl / wget

```bash
curl www.baidu.com   # 获取目标URL的响应体，自动隐藏响应头

	-i：获取HTTP响应头、响应体，并输出

```

curl是一个利用URL规则的命令行工具，可用于文件传输和测试网站，是CentOS默认自带的工具

## 六、磁盘与内存

### 6.1 磁盘管理 — df / du

```bash
df    # 查看磁盘使用情况
	-h：人性化展示
	-i：显示inode使用情况，而非块存储用量
	-T：显示文件系统类型

du    # 估算文件和目录的磁盘使用量，默认会递归计算当前目录下的所有文件
	-h：人性化展示
	-s：只显示总计，不显示子目录详情
	-d / --max-depth：指定显示目录的深度
	-a：显示所有文件的大小，不仅仅是目录
du -sh /etc/     # 查看/etc/目录的大小
du -sh /etc/*    # 查看/etc/目录下1级目录大小
```

`df`和`du`是两个常用的磁盘管理命令，两者侧重点不同：`df`用于查看磁盘空间的剩余情况、`du`用于查看具体文件占用了多少磁盘空间

### 6.2 内存管理 — free

```bash
free -h    # 人性化展示内存用量
	-s 1：持续动态刷新，每1秒刷新一次
	-c 3：指定刷新次数，配合 -s 参数使用
#         total        used        free      shared  buff/cache   available
# Mem:     7822        1024         456          64        5340        6142
# Swap:    2047           0        2047
```

参数解析：

- total：物理内存总量（扣除内核保留部分）
- used：已使用内存（包含用于缓存的量）
- free：完全未使用的内存
- shared：共享内存，被多个进程共同使用，主要用于tmpfs（临时文件系统）和IPC（进程间通信通道）
- buff：块设备缓冲区，加速磁盘写入
- cache：文件缓存，加速文件读取
- available：可用内存量，它估算出“应用程序还可以申请到多少内存”，约等于free + 可回收的 buff/cache

`used`展示的内存量非常容易造成误解，Linux系统会尽可能利用闲置的内存做缓存，`buff/cache`这部分内存是可以随时回收的，应用申请内存时，系统会优先释放这部分空间。所以实际的内存使用量可以用`used = total - free - buff/cache - shared`进行计算

Linux的特性之一，是可以把内存当磁盘使用，例如：`/dev/shm`、`/run`、`/sys/fs/cgroup` 等目录通常都是`tmpfs`挂载的。在这些目录里写文件，其实就是写在内存里。这部分空间就会被统计在 `shared` 中。

不同进程之间为了快速交换数据，会申请一块大家都能访问的内存区域（IPC进程间通信通道），在数据库服务、高性能计算程序常会用到

### 6.3 磁盘挂载 — mount/umount

```bash
mount    # 查看当前挂载情况
	-l：显示当前已挂载的文件系统，此参数会额外输出卷标（如果有卷标）
	-t：指定文件系统格式。常见文件系统格式包含ext4、xfs、nfs、iso9660、ntfs等
	-o：指定挂载选项。这部分参数较多，不详细列举，仅做声明
	-a：挂载 /etc/fstab 配置文件中定义的所有文件系统
mount /dev/sdb1 /data          # 将 /dev/sdb1 挂载到 /data 目录
mount -o remount,rw /          # 以读写方式重新挂载根目录（修改权限）

umount /data                   # 卸载
```

大部分场景下`mount`命令会直接挂载磁盘，不使用`-t`参数的情况下，系统会自动检测目标磁盘的文件系统格式；`-a`选项最多的应用场景就是用于检测`/etc/fstab`配置文件是否存在语法错误，`/etc/fstab`配置文件存在语法错误时，重启系统会导致系统无法正常启动

## 七、查找命令

### 7.1 精确查找 — find

```bash
# 时间参数查找
find / -mtime 0        # 查找 从此刻开始到24小时前 的所有修改过内容的文件
    # 时间参数有3个：-atime、-ctime与-mtime，以mtime为例
    # -mtime n：列出n天之前的24小时内被更改过内容的文件
    # -mtime +n：列出n天之前（不含n天本身）被更改过内容的文件
    # -mtime -n：列出n天内（含n天本身）被更改过内容的文件
    # -newer file：列出逼file还要新的文件
find /var -mtime +30 -type f          # 查找30天前修改的文件
find / -mtime 3        # 查找 3天前的此刻到24小时前 的所有修改过内容的文件
	# -amin n：访问时间，分钟单位，mmin与cmin以此类推
find /etc/ -newer /etc/passwd    # 列出文件日期比passwd新的文件

# 文件属性查找
find /home -user hebor        # 查找属主是hebor的文件
    -uid n：按UID查找
    -gid n：按GID查找
    -user name：按属主查找文件
    -group name：按属组查找文件
    -nouser：属主不存在 /etc/passwd
    -nogroup：属组不存在 /etc/group
    -inum number：查找inode相同的文件
find / -nouser

# 文件权限类型查找
find /etc/ -perm -0755 -type f -name network    # 查找权限等于或大于0755且名称为network的文件
    -perm：此选项关于权限参数有3种写法，分别代表不同意思；`-perm 0755`表示查找权限完全相同的文件、`-perm -0755`表示查找权限等于或大于此值的文件、`-perm /0755`表示查找包含任一权限的文件，例如权限中存在7或者5的文件都会被检索
    -type：可用的类型主要包含：文件(f)、目录(d)、设备(b)或(c)、软连接(l)、socket(s)
    -size
    -name
find / -perm /7000    # 查找权限包含s或t的文件
find /etc/ -type f -name "ifcfg*"    # 查找一个以ifcfg开头的文件类型
find /etc/ -type f -size +10k -size -10M    # 大于10k小于10M的文件；按照文件大小查找文件：+ 表示大于,- 表示小于
    -a: 逻辑运算与,此示例中可使用,但没有必要
    -o: 逻辑运算或
    # 默认find命令查找数据,多个相同条件之间就是逻辑与运算,使用size选项必须带有数据大小单位

# 补充
find /etc/ -type f -size +10k -size -10M -maxdepth 1    # 指定文件查找深度
    # find默认使用递归查找方式,使用 -maxdepth 选项将find查找锁定在 /etc/ 下的文件
    # 系统建议 -maxdepth 选项应该考前放
    # 使用-size选项时，不要使用-1G、-1M、-1K，find命令有可能不识别。+号不受影响

tree -L 1 -d /etc/    # 同样有深度选项的命令还有tree
    -L: Level
    -d: 只显示目录信息

find ~/shell/ -type f -iname "*.log"    # 不区分大小写查找
    -iname: 不区分大小写
    # find命令默认不忽略大小写

find /usr/bin/ /usr/sbin/ -perm /7000 -exec ls -l {} \;
    -exec command：command为其他命令，-exec后面可以接额外命令用于处理搜寻到的结果
    # -exec 不支持别名，所以只能使用ls -l，而不能使用ll
    # {}表示find查找的内容结果，从-exec到\;是关键字，代表find额外动作的开始(-exec)到结束(\;)
    # (-exec)到(\;)中间的就是额外命令
```

### 7.2 快速定位 — locate / whereis / which

```bash
updatedb	# 更新系统信息到mlocate.db数据库中
locate which 	# 快速定位文件位置，定位文件或命令都可以
	-i：忽略大小写差异
	-l：仅列出查询结果内的几行

which python              # 查找命令的绝对路径
	-a：列出PATH中找到的所有匹配项，默认只显示第一个

whereis cp		# 查找命令、源码、手册页位置
	-b：仅查找binary格式的文件
	-m：仅查找能够使用man手册的文件
```

CentOS 7版本`locate`命令是根据`/var/lib/mlocate/mlocate.db`数据库中记录的系统信息进行文件查找的，如果数据库中未保存任何系统信息，`locate`指令执行会报错；新建的文件也不会立马保存到`mlocate.db`中，需要再次执行`updatedb`命令将更新写入`mlocate.db`后再进行查找

新版本修改了软件包名称和数据库存储路径，新版本软件包名称是`plocate`、数据库存储路径是`/var/lib/plocate/plocate.db`

`which`侧重于在当前用户的`PATH`环境变量中查找系统正在使用的可执行文件；`whereis`侧重于全面查找目标相关的所有文件，包含二进制、源码、文档等；locate可用于全局模糊搜索，`whereis / which`两者都无法实现此功能

### 8.2 序列输出 — seq / sort

```bash
seq -w 10            # 打印数字序列，也可以替换为字符
	-w：表示在列前添0，补全宽度
seq 10 > seq.txt     # 将序列输出到指定文件

sort -rnk 1 seq.txt    # 倒序打印输出数字，
    -r：reverse，反选
    -n：比较整体字符串数值。告诉sort命令将数字识别成数字而不是字符，并按值排序
    -k：选定某一列进行比较。此示例中选项值为1，表示比较第一列的数值
    -t：指定分隔符
du -sh /etc/* | sort -rhk 1    # 以人类易识别的方式排序，-n 参数只能识别字符串数值，无法识别单位
sort -t ':' -k 3 -n /etc/passwd     # 按uid号排序passwd文件内容
```

`sort`命令的`-k`参数比较特殊，如果不使用 -n参数，则表示比较第1列的第1个数值大小，这将导致1和10会排在一起，仅因为10的第一个数值也是1，sort 命令未将10识别成一个整体

### 8.3 去重/统计 — uniq / wc

```bash
uniq file.txt    # 去重
	-c：在每行行首显示该行出现的次数
	-d：只显示重复过的行
	-u：只显示唯一行
	-i：忽略大小写比对
sort file.txt | uniq -c   # 完整去重统计

wc /etc/passwd    # 统计目标文件字符信息
	-l：统计行数
	-w：统计单词数
	-c：统计字节数
#  23    44  1161 /etc/passwd    
# 行数 单词数 字节数     目标文件
```

`uniq`用于处理文本文件中的重复行，但它只能检测并处理“相邻”的重复行，所以`uniq`一般会配合`sort`使用

### 9.3 别名

在CentOS 7系统中，别名`alias`是优化命令行操作的重要工具，其核心作用是为复杂或频繁使用的命令设置简写。别名的设置具有很高的个人自定义化性质，在定义别名时切记不可与关键词冲突，例如将`pwd`定义为别名

#### 别名的定义

1. 临时定义别名
	直接在终端中输入`alias 别名='原始命令'`即可生效，但仅限当前会话可用，重启机器或重启会话都会导致临时别名失效
	```bash
	alias                  # 查看已设置的别名
	alias mem='free -h'    # 定义新的别名
	unalias mem            # 取消已设置的别名
	```

2. 永久定义别名
	- 用户级：编辑`~/.bashrc`或`~/.bash_profile`，添加别名配置到文件后，执行`source ~/.bashrc`使别名立刻生效
	- 全局配置：编辑`/etc/bashrc`或`/etc/bash_profile`，需要管理员权限

#### 特殊场景处理

1. 绕过别名执行原始命令
	缺省情况下，别名的优先级是高于原始命令的，当别名覆盖了系统命令时，可通过反斜杠`\`（又称转义字符）或绝对路径来调用原始命令
	```bash
	\cd        #使用转义字符
	/bin/cd    #使用绝对路径
	```

2. 脚本中启用别名
	缺省情况下，非交互式Shell不展开别名，需要在非交互式Shell中使用别名时，需要在脚本开头启用别名扩展
	```bash
	shopt -s expand_aliases
	```

## 十、字符集管理

字符集是指将一些国家的特殊语言有效的转换为机器码的过程

```bash
locale -a	# 输出所有语言环境
	        # 不带-a选项时，仅输出当前字符集支持的语言环境

# 通用临时配置字符集
echo $LANG		# en_US.utf8：前半部分表示字符集对应的语言，后半部分表示字符编码
export LANG=en_US.GBK	# 临时修改字符集
echo "export LANG=en_US.GBK" >> /etc/profile	# 环境变量永久修改字符集

# CentOS 7配置文件永久修改字符集
more /etc/locale.conf
LANG=en_US.utf8

# 命令修改字符集
yum install langpacks-en glibc-langpack-en -y    # 如果直接修改英文字符集出错，可能是缺少英语语言包
localectl set-locale LANG=en_US.UTF-8            # 修改字符集
source /etc/locale.conf                          # 使变更即可生效，或重新登陆也可生效
```
