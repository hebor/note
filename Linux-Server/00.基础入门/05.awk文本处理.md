# awk 文本处理

## 一、awk 概述

`gawk - pattern scanning and processing language`，awk全名gawk，awk是Linux强大的文本分析工具，支持模式匹配、变量、函数、条件判断和循环。

### 1.1 工作流程

1. 按行读取文件信息
2. 判断是否符合匹配条件
3. 匹配条件时，按执行动作处理（awk是没有默认输出的，如果没有执行动作print，则不会打印输出）
4. 不匹配条件时，继续读取下一行重复上述过程，直至文件结尾

```
逐行读取 → 模式匹配 → 执行动作
     ↓          ↓          ↓
  文本    正则/条件    打印/计算
```

### 1.2 基本语法

```bash
命令语法：awk [参数信息 -F -v]' '模式信息{动作信息}' 文件信息
awk -F ':' '{print $1}' /etc/passwd

# 常用选项
awk -F 'delimiter'          # 指定字段分隔符
awk -v var=value            # 定义变量
awk -f script.awk           # 执行脚本文件
awk -v OFS='-' '{print $1,$2}'   # 设置输出分隔符
```

## 二、字段操作

### 2.1 字段引用

| 变量 | 说明 |
| :--- | :--- |
| `$0` | 整行 |
| `$1~$n` | 第 n 个字段 |
| `NF` | 字段总数（Number of Fields） |
| `NR` | 当前行号（Number of Records） |
| `FNR` | 当前文件行号 |
| `FS` | 输入字段分隔符（默认空格/Tab） |
| `OFS` | 输出字段分隔符 |
| `ORS` | 输出记录分隔符 |

### 2.2 示例

1. 创建测试文件

```bash
cat > awk_test.txt << EOF
Zhang Dandan 41117397 :250:100:175
Zhang Xiaoyu 390320151 :155:90:201
Meng Waiwai 70271111 :250:80:75
Wu Feixue 80042789 :250:60:50
Liu Bingbing 41117483 :250:100:175
Wang Xiaoai 3515064655 :50:168:200
Zi Gege 1986787350 :250:168:200
Li Youjiu 918391635 :175:75:300
Lao Nanhai 918391635 :250:100:175
EOF
```

2. 简单示例

```bash
# 示例：显示Xiaoyu的姓和ID
awk '/Xiaoyu/{print $1, $3}' awk_test.txt
    # 未使用-F指定分隔符信息时，awk默认使用空格作为分隔列，且多个空格信息默认看作一个整体
    # awk默认将逗号识别成空格符号，如果需要将其识别为逗号，需要用引号包裹逗号
awk 'NR==2{print $1,$3}' awk_test.txt    # 另一种方式实现相同效果

# 示例：显示所有Zhang姓，并显示第二次捐款金额及名称
awk -F "[ :]+" '/Zhang/{print $2,$5}' awk_test.txt
    # 使用awk输出列信息时总是从左往右数，awk默认也可以从右往左数，需要用到参数$NF（Number Field）
awk -F "[ :]+" '/Zhang/{print $2,$(NF-1)}' awk_test.txt    # 另一种实现方式
    # 默认情况下NF代表最后一行，如果要取倒数第2行，则用NF-1即可，很明显awk的字符运算优先级高于算数运算，所有NF-1需要括号

# 示例：显示所有以41开头的ID号的人的全名和ID号
awk '$3~/^41/{print $1,$2,$3}' awk_test.txt | column -t
    # 默认情况下正则符^和$在awk中的作用与sed一样，都表示匹配一行的行首和行尾字符，但在awk中，这两个符号可以更加精准的匹配到某一列的行首字符和行尾字符
    # 例如此例中，'$3~/^41/'表示匹配第3列以41开头的内容，其中~用于连接两者的意义
awk '$3!~/^41/{print $1,$2,$3}' awk_test.txt | column -t    # 取反示例

# 示例：显示所有ID号最后一位数字时1或5的人的全名
awk '$3~/1$|5$/{print $1,$2}' awk_test.txt | column -t
awk '$3~/(1|5)$/{print $1,$2}' awk_test.txt    # 简化通用的$符
awk '$3~/[15]$/{print $1,$2}' awk_test.txt

# 示例：显示Xiaoyu的捐款，每个值前面都已$开头
gawk '/Xiaoyu/{gsub(/:/,"$",$4);print $1,$2,$4}' awk_test.txt
    # awk替换操作语法：'{gsub(/要替换的信息/,"替换成什么",要替换第几列信息)}'
    # echo oldboy | awk '{gsub(/oldboy/,"oleboy",$1);print $1}'    # 替换示例，gsub在awk中也是一个指令，所以gsub与print需要使用;号分隔

# 输出分隔符
awk -F ':' 'OFS=" | " {print $1, $3, $7}' /etc/passwd
```

## 三、模式匹配

### 3.1 模式类型

| 模式 | 说明 | 示例 |
| :--- | :--- | :--- |
| `/regex/` | 正则表达式 | `/root/` |
| `表达式` | 比较表达式 | `$3 > 100` |
| `BEGIN/END` | 开始/结束块 | `BEGIN{}` |
| `逻辑组合` | 与或非 | `$3>0 && $4>0` |

### 3.2 正则模式

```bash
awk '/root/' /etc/passwd     # 匹配包含root的行
awk '/^root/' /etc/passwd    # 以root开头的行
awk -F: '$3 ~ /^[0-9]+$/' /etc/passwd     # 第3个字段是数字
awk -F: '$3 !~ /^[0-9]+$/' /etc/passwd    # 第3个字段不是数字（跳过系统用户）
awk -F: '/root|admin/' /etc/passwd            # 使用扩展正则（ERE）
```

### 3.3 比较模式

```bash
awk -F: '$3 > 1000 {print $1, $3}' /etc/passwd     # UID大于1000的用户
awk -F: '$3 == 0 {print $1}' /etc/passwd           # UID等于0（root）
awk -F: '$7 == "/bin/bash" {print $1}' /etc/passwd # 第7字段是bash
awk '$1 == "root"' /etc/passwd                     # 字符串比较
awk 'NR>2{print $0}' /etc/passwd                   # 从第3行开始匹配条件.$0表示显示所有列信息
awk 'NR == 1, NR == 2 {print $0}' /etc/passwd      # 具体范围显示
```

### 3.4 BEGIN / END

- BEGIN模式：在文件处理前，执行相应操作；多用于测试、计算和修改内置变量
- END模式：在文件处理后，执行相应操作；多用于计算、显示计算结果

```bash
# 在过滤的文本内容前后都补充一行内容
awk 'BEGIN {print "hello"} NR > 2 {print $0} END {print "world"}' awk_test.txt | column -t

# BEGIN：在处理第一行之前执行
awk -F: 'BEGIN {print "用户名 UID Shell"} {print $1, $3, $7} END {print "---结束---"}' /etc/passwd | column -t

# 处理数据前初始化
awk -F: 'BEGIN {sum=0} {sum+=$3} END {print sum}' /etc/passwd

# 格式化输出
awk -F '[ :]+' 'BEGIN {printf "%-10s %-5s\n", "Name", "Age"} {printf "%-10s %-5s\n", $1, $2}' awk_test.txt
```

#### 关于BEGIN的执行逻辑

```shell
awk '/^$/BEGIN{i=i+1; print $i}' /etc/services
```

语法错误，BEGIN模式是在文件处理前执行相应操作，语法上的重点在于文件处理前，将BEGIN关键词放在过滤符`/^$/`后面时，awk执行过滤时就表示已经读取了文件内容，读取文件内容后再执行BEGIN违背了BEGIN的语法规则

### 3.5 内置变量

awk常用的内置变量：

- NR：行号信息
- NF：尾列
- FS：field separator，指定分隔符号，在awk中FS可以通过-F选项代替
- OFS：out field separator，输出字段分隔符，默认值是一个空格

```bash
awk -F ":" '{print $1}' awk_test.txt            # 使用-F选项声明分隔符。等同于FS字段
awk 'BEGIN {FS=":"} {print $1}' awk_test.txt    # 使用BEGIN实现上例同样效果
awk -v FS=":" '{print $1}' awk_test.txt         # 实现上例同样效果

# -v选项表示执行awk命令前，创建一个变量并赋值，awk命令可以直接调用此变量
awk -v test=42 'END{print test}' awk_test.txt    
    # 上例中如果不使用END关键字，则文件内容被读取多少行，就会输出多少次变量
```

## 四、运算与统计

### 4.1 数值计算

在awk中调用变量信息时，直接调用变量名不需要加`$`符；在awk中输出字符信息时必须带上双引号，否则会被识别为变量名

```bash
# 求和
awk '/^$/{i+=1} END {print i}' /etc/services    # 计算/etc/services文件中的空行
    # i变量未设置默认值时，默认等于0
    # awk的语法还可以写成：'/^$/{i++; print i}'、'/^$/{i=i+1; print i}' 等
awk '/^$/{i++; print $i}' /etc/services         # 在awk中调用变量信息时，直接调用变量名不需要加$符

awk '{sum+=$3; count++} END {print sum/count}' awk_test.txt           # 平均值
awk 'BEGIN{max=0} {if($3>max) max=$3} END{print max}' awk_test.txt    # 最大值/最小值
awk 'END{print NR}' /etc/services                                     # 统计行数
awk '{count++} END{print count}' /etc/services                        # 与上例实现同样效果
awk -F: '$3>1000 {sum += $3} END {print sum}' /etc/passwd             # 条件求和
seq 10 | awk '{i += $0} END {print i}'                                # 求和
```

### 4.2 字符串操作

```bash
awk '{print length($0)}' awk_test.txt              # 计算每一行的字符串长度
awk '{name=$1" - "$2; print name}' awk_test.txt    # 字符串拼接

# 字符串函数
awk '{
print length($0)
print toupper($1)
print tolower($2)
print substr($2, 1, 3)
}' awk_test.txt
```

## 五、数组

### 5.1 基本使用

需要注意，在awk中可以指定数字或字符作为键，看起来就像是PHP的数值数组和关联数组，但在awk中，这两种定义方式在底层没有任何区别，都是“关联数组”。这两个数组涉及到awk的默认值机制，如果没有定义`arr[2]`直接`print arr[2]`，输出为空（因为未赋值）；`freq[$1]++`这种写法，如果`$1`是首次出现，awk会自动创建这个键，并默认它的值为0，然后再执行`++`变成1。

在`END {...}`板块中，for循环在未使用解包的语法下，默认只循环取键、不取值，所以for循环的作用就是把数组中的所有键取出来。另外，for循环的输出是无序的。

```bash
# 定义数组
awk 'BEGIN{
  arr[0]="apple"
  arr[1]="banana"
  print arr[0], arr[1]
}'

# 数组遍历
awk -F: '{freq[$1]++} END {for(user in freq) print user, freq[user]}' /etc/passwd

# 排序输出
awk '{freq[$1]++} END {
for(word in freq) print freq[word], word
}' awk_test.txt | sort -rn | head -10
```

### 5.2 统计案例

1. 创建测试环境

   ```bash
   cat > awk_test2.txt << EOF
   http://www.etiantian.org/index.html
   http://www.etiantian.org/1.html
   http://post.etiantian.org/index.html
   http://mp3.etiantian.org/index.html
   http://www.etiantian.org/3.html

   ```

2. 示例

   ```bash
   # 统计www域名出现次数
   awk -F '[/.]+' '{domain[$2]++} END{print "www",domain["www"]}' awk_test2.txt
   
   # 统计所有域名的出现次数
   awk -F '[/.]+' '{domain[$2]++} END{for (name in domain) print name, domain[name]}' awk_test2.txt
   
   # 统计每个用户的进程数
   ps aux | awk 'NR>1 {user[$1]++} END{for(u in user) print u, user[u]}'
   
   # 统计每个IP的访问次数
   awk '{ip[$1]++} END {for (i in ip) print i, ip[i]}' /var/log/nginx/access.log | sort -k2 -rn

   awk -F: '{shell[$7]++} END{for(s in shell) print s, shell[s]}' /etc/passwd

   awk -F "(from)|(port)" '/Failed password/{array[$2]++} END{for (ip in array) print ip,array[ip]}' /var/log/secure
   awk '/Failed password/{array[$(NF-3)]++} END{for (ip in array) print ip,array[ip]}' /var/log/secure
   ```

## 六、流程控制

### 6.1 条件判断

```bash
awk -F: '{
if ($3 == 0){
		print $1, ": super user"
	} else if ($3 > 0 && $3 < 1000){
		print $1, ": system user"
	} else {
		print $1, ": user"
	}
}' /etc/passwd

# 三元运算符
awk '{print ($3 > 1000 ? "user" : "system user")}' /etc/passwd
```

### 6.2 循环

```bash
# for循环
awk 'BEGIN{
	for (i=1; i<=5; i++){
		sum += i
	}
	print sum
}'

# 遍历数组
awk -F: '{freq[$1]++} END {for(user in freq) print user, freq[user]}' /etc/passwd

# while循环
awk 'BEGIN{
	i=1
	while(i<5){
		print(i)
		i++
	}
}'
```

## 七、日志统计实战

### 7.1 Nginx 访问日志统计

```bash
# 访问量TOP10 IP
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -10

# 统计HTTP状态码
awk '{print $9}' /var/log/nginx/access.log | sort | uniq -c | sort -rn

# 统计404请求
awk '$9 == 404 {print $7}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -5

# 统计带宽（默认情况下该字段是$body_bytes_sent，记录响应体大小Byte）
awk '{bytes[$1]+=$10} END{for(ip in bytes) print bytes[ip], ip}' /var/log/nginx/access.log | sort -rn

# 统计每小时的访问量
awk '{print substr($4,14,2)}' access.log | sort | uniq -c

# 统计最慢的10个请求（默认情况下该字段是$http_x_forwarded_for）
awk '{print $NF, $7}' access.log | sort -rn | head -10
```

### 7.2 系统日志统计

```bash
# 统计SSH登录失败次数
grep "Failed password" /var/log/secure | awk '{print $11}' | sort | uniq -c | sort -rn

# 统计每个用户的sudo使用次数
grep "sudo" /var/log/secure | awk '{print $1, $2, $3, $5}' | sort | uniq -c

# 统计磁盘使用情况（df输出）
df -h | awk 'NR>1 {gsub(/%/,"",$5); if($5>80) print $1, $5"%"}'

# 统计内存使用
free -m | awk 'NR==2{print "使用:"$3"MB, 剩余:"$4"MB, 使用率:"$3*100/$2"%"}'
```
