# Linux 正则表达式

## 一、基本概念

### 1.1 系统符号 vs 正则符号

| 类型   | 示例                   | 说明                 |
| :--- | :------------------- | :----------------- |
| 系统符号 | `*` `?` `[]` `{}`    | Shell 通配符，Shell 解析 |
| 正则符号 | `*` `.` `^` `$` `[]` | 正则引擎解析，精确匹配        |
| 正则量词 | `+` `?` `{}`         | 扩展正则               |
| 正则分组 | `()` `\|`            | 扩展正则               |

系统符号内包含了通配符，多数通配符使用的符号与正则表达式的符号是一样的，看起来非常容易混淆，两者的关键区别在于：**通配符是Shell用于匹配文件名的；正则表达式是文本处理工具（如grep、sed、awk）用于匹配文件内容的**

## 二、系统符号

### 2.1 常用符号

| 符号       | 说明        | 示例                               |
| -------- | --------- | -------------------------------- |
| `$`      | 变量名       | `echo $PATH`，打印变量值               |
| `#`      | 注释        | `# echo "test"`，此命令不会执行          |
| `!`      | 取反/唤起历史命令 | `!ls`，执行最近一次的历史命令中的`ls`指令        |
| `\|`     | 管道符       | 上一命令的标准输出，作为下一命令的标准输入            |
| `>`      | 重定向       | 控制输入来源和输出去向                      |
| `.`、`..` | 路径符       | 两者都表示路径，`.`表示当前目录、`..`表示上一级目录    |
| `-`      | 环境变量      | `-`表示系统环境变量`$OLDPWD`，用于切换到上一次路径下 |
| `~`      | 用户家目录     | `cd ~`，快速切换到用户家目录                |

### 2.2 示例

取反功能在大部分地方都可以通用

```bash
find /dev/ -type f ! -name "*.txt"    # 取反

xargs < passwd         # 语法与tr命令相似
xargs -n2 < passwd     # 以2行内容为1组显示，简而言之就是将原文档的每2行信息整合成1行显示

find ${pwd} -type f -name "*.txt" | xargs rm     # 删除通过find命令查找的文件
     # 此命令中，如果不使用xargs而是直接rm，那么rm命令不会生效
     # xargs命令不识别别名信息，所以rm指令不需要带参数f

find ${pwd} -type f -name "*.txt" -exec rm -f {} \;    # 实现与上例一样的效果
find ${pwd} -type f -name "*.txt" -delete    # 使用find本身的选项删除查找结果
```

有时候使用`${}`或` `` `反引号引用命令结果时会莫名报错，可能是因为别名的问题，可以再使用反斜杠再试试，例如`${\which rm}`

```bash
# 此命令的本意是将find查找的结果备份到/backup/目录中
find /home/hebor/ -type f -name "*.txt" | xargs cp -a /backup/
# 但后半条指令实际的执行效果如下：
[xargs] cp -a /backup/ FileName1.txt FileName2.txt
# 以2个文件简单示例，可以看出xargs将查找的结果放到cp指令的尾部后，cp指令的意义就被改变了

# 通过-I选项替换上一指令结果的位置，实现备份
find /home/hebor/ -type f -name "*.txt" | xargs -I {} cp -a {} /backup/      

# 通过cp命令的-t选项指定目标目录可实现同样的效果
find /home/hebor/ -type f -name "*.txt" | xargs cp -a -t /backup/   
```

## 三、基础正则（BRE）

### 3.1 常用符号

| 符号 | 说明 | 示例 |
| :--- | :--- | :--- |
| `^` | 行首 | `^root` 匹配以 root 开头的行 |
| `$` | 行尾 | `root$` 匹配以 root 结尾的行 |
| `.` | 任意单个字符 | `r..t` 匹配 r开头t结尾的4字符 |
| `*` | 前一个字符0次或多次 | `a*` 匹配0个或多个a |
| `[]` | 字符集合 | `[abc]` 匹配 a/b/c 任一个 |
| `[^]` | 排除字符集 | `[^abc]` 不含 a/b/c |
| `\{n,m\}` | 前一个字符出现n到m次 | `a\{2,4\}` 出现2到4次a |

### 3.2 示例

创建实验文件

```notepad
I am oldboy teacher!
I teach linux.

I like badminton ball ,billiard ball and chinese chess!
my blog is http://oldboy.blog.51cto.com
our site is http://www.etiantian.org
my qq num is 49000448

not 4900000448
my god ,i am not oldbey,but OLDBOY!
```

基础正则表达式符号解析

```bash
grep "^m" test.txt        # 过滤以m字符开头的内容

grep "m$" test.txt        # 过滤以m字符结尾的内容
grep "^$" test.txt        # 过滤文件空行信息

grep "^m.*m$" test.txt    # 过滤以m开头并以m结尾的行；.和*联合使用表示匹配所有内容
grep "90*" test.txt       # 过滤文本中包含多个或0个 0字符 的行
grep "0*" test.txt        # grep会匹配所有文本内容，0字符出现0次的行会被匹配

grep "\.$" test.txt       # 将有特殊意义的符号转义为普通字符
echo -e "first paragrpph\nsecond paragraph"    # 换行符

grep "[ol]" test.txt      # 匹配o字符或l字符的行，"[]"括号中的每一个字符都是逻辑或关系
grep "[0-9]" test.txt     # 匹配所有数字，括号中的数字也可替换成字符a-z，表示匹配所有字符
grep '[[:digit:]]' /etc/passwd    # 实现与上例一样的效果
grep "^[mI]" test.txt     # 过滤以m或I开头的行
grep '[^abc]' /etc/passwd # 排除特定字符

grep 'r..t' /etc/passwd   # 匹配r开头、t结尾、共4个字符的行

# 匹配日志IP
grep '[0-9]\{1,3\}\.[0-9]\{1,3\}\.[0-9]\{1,3\}\.[0-9]\{1,3\}' access.log
```

### 3.3 正则符号特性

正则符号匹配字符信息时，拥有贪婪特性

```bash
grep "^I l.*b" test.txt      # 贪婪特性
grep "^I l.*n b" test.txt    # 避免贪婪属性
```

例如，`^I l.*b`本意是截取测试文本中的字符串`I like badminton b`，贪婪特性会持续匹配以b结尾的单词，直到本行文本中的最后一个b字符，实际匹配内容是`I like badminton ball ,billiard b`，因此，为了更精准的匹配，匹配条件应该尽可能的具备唯一性

## 四、扩展正则（ERE）

使用 `grep -E` 或 `egrep`：

### 4.1 常用符号

| 符号 | 说明 | 示例 |
| :--- | :--- | :--- |
| `+` | 前一个字符1次或多次 | `a+` 匹配1个或多个a |
| `?` | 前一个字符0次或1次 | `a?` 匹配0个或1个a |
| `()` | 分组 | `(ab)+` 匹配ab连在一起 |
| `{}` | 前一个字符出现n到m次 | `a{2,4}` 出现2到4次a |
| `\|` | 或 | `root\|admin` |

### 4.1 示例

创建实验文件

```notepad
zhao  110105199003065412
qian  120107198006077652
sun   310107198006077652
li    120109198006077652
zhou  897107198006077652
feng  text
wu    12010719800607765X
chu   content
zheng 311007198006077652
wang  120107198006077652
```

扩展正则表达式符号解析

```bash
grep -E "o|l" test.txt    # 实现与 [ol] 一样的效果
grep -Ev "^#|^$" test.txt # 排除空行和注释

egrep "0+" test.txt       # 匹配0字符出现1次以上的行
egrep "[0-9]+" id.txt -o  # 匹配数字出现多次的行，“+”号会将匹配的信息作为整体输出
	-o：仅输出文本内容中具体被匹配的字符
grep "[0-9]" id.txt -o    # 对比上例效果

egrep "oldboy|oldbey" test.txt    # 匹配，可以连续多次进行|匹配
egrep "(oldboy)" test.txt # 过滤oldboy字符串

egrep "0{1,3}" test.txt   # 限制一行中最多只匹配3个0，多余的字符换行匹配
egrep "0+" test.txt       # 结果上来看与上例并无区别，可以通过-o选项查看区别
egrep "0{3}" test.txt     # 只匹配0字符连续出现n次的行

egrep "0?" test.txt -o    # 匹配0字符出现0次或1次的行


ifconfig | grep -E '([0-9]{1,3}\.){3}[0-9]{1,3}'    # 提取IP地址
grep -E '1[3-9][0-9]{9}' phone.txt    # 匹配手机号
grep -E '[a-Z0-9._%+-]+@[a-Z0-9.-]+\.[a-Z]{2,}' email.txt    # 匹配邮箱
grep -E 'https?://[a-Z0-9.-]+' urls.txt    # 匹配http/https URL
echo "ab abab ababab" | grep -E '(ab)+'    # 分组
```

> **小技巧**

- 扩展正则符`+`会常与`[]`符配合使用，用于匹配多个不同的连续字符
- `()`表示将匹配的信息作为一个整体进行查询，与`[]`符对比，`()`符针对括号内的字符串不再拆分匹配每一个单独的字符，而是字符串整体匹配
- `{}`指定前一个字符连续匹配次数。`{n,m}`是标准语法，匹配n~m次；四种用法：`{n,m}、{n}、{n,}、{,m}`

> **关于()符在sed命令中的特殊作用**

在sed命令中`()`符用于后项引用前项。sed命令替换信息操作中，将不变的信息用`()`符声明

```shell
echo 123456 | sed "s#123456#<123456>#g"		# 想实现的效果
echo 123456 | sed "s#......#<123456>#g"		# 首次优化。将数字用6个 . 符号替代
echo 123456 | sed "s#.*#<123456>#g"		# 二次优化。将6个 . 符号用基础正则符优化
echo 123456 | sed -r "s#(.*)#<\1>#g"	# 优化结果。(.*)表示将6个数字视做一个整体（前项），"\1"表示前项，在"\1"两侧加上"<>"号等同于在前项两侧加上尖括号
echo 123456 | sed -r "s#(..)(..)(..)#<\1><\2><\3>#g"	# 将前项分开处理。后项的数字分别代表前项的第几个括号内容
echo 123456 | sed -r "s#(.{2})#<\1>#g"  # 上例简化
```

## 五、grep 命令参数补充

```bash
# 正则模式
grep "pattern" file                # 基本正则（BRE）
grep -E "pattern" file             # 扩展正则（ERE）
grep -G "pattern" file             # 基本正则（默认）
grep -P "pattern" file             # Perl正则（PCRE，更强大）

# 精确匹配
grep -w "word" file                # 单词边界匹配
grep -x "exactly" file             # 整行完全匹配
```

> **补充：检查文件尾部的空格**

通常文本开头是否有空格很好判断，但尾部不便查看，有2种方式显示尾部结尾信息

1. 通过底行命令模式设置`set list`
2. 通过cat指令的-A选项查看`cat -A filename`

## 六、实践

1、 提取 IP 地址（分别通过sed、awk、grep三种方式实现需求）

```bash
# 1. 定位信息所在行
ip address show eth0 | sed -n "3p"    # 打印第3行
ip address show eth0 | awk 'NR==3'    # NR表示Number Row；一个=号是赋值，必须使用==号
ip address show eth0 | grep "inet "   # inet后面的空格必须有，否则会过滤出ipv6信息

# 2. 截取指定信息
ip addr show eth0 | sed -n "3p" | sed -r "s#(.*inet )([0-9.]*)(/.*)#\2#g"    # sed 实现需求，此例中也可以只声明一个前项
ip addr show eth0 | sed -n "3p" | sed -r "s#.*inet |/.*##g"    # 二次精简
ip addr show eth0 | sed -nr '3s#.*inet |/.*##gp'               # sed 优化结果

ip addr show eth0 | awk "NR==3" | awk '{print $2}'             # awk实现需求，默认awk截取列信息时按空格截取
ip addr show eth0 | awk "NR==3" | awk -F "[ /]" '{print $6}'   # 使用-F选项配合ERE将/符也视作awk的分隔符
ip addr show eth0 | awk -F "[ /]+" 'NR==3 {print $3}'          # awk 优化结果

ip addr show eth0 | grep "inet " | egrep "[0-9\.]+" -o | head -n 1    # 通过-o选项输出IP

# 方法2
ifconfig | grep -E '([0-9]{1,3}\.){3}[0-9]{1,3}'               # 获取IP格式的数据
ifconfig | grep -E '([0-9]{1,3}\.){3}([0-9]{1,3})' -o | egrep -v '^127|^255|255$'    # 排除环回地址和掩码

# 方法3
grep -Eo '((25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\.){3}(25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)' access.log    # 精确匹配IP地址格式
```

awk截取信息时，默认没有使用`-F`指定分隔符信息时，默认采用空格切分列，但是一行字符开头的多个空格会忽略不记

使用正则表达式过滤文本内容时没有固定的写法，不用的场景可以有多种写法实现目标。例如，在egrep示例中，`[0-9\.]+`只是一种取巧的写法，更加准确的匹配IP的写法可以是`([0-9]{1,3}\.){3}[0-9]{1,3}`，但`[0-9\.]+`在这个场景下就是可以精简的实现目标，甚至还可以是`[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+`、`([0-9]+\.){3}[0-9]+`、`([0-9]+\.?){4}`或者其他更多类型的写法

2、 提取文件权限

```bash
stat /etc/hosts | sed -n '4p' | sed -r 's#.*s: \(|/-.*##g'

stat /etc/hosts | awk 'NR==4' | awk -F "[ (/]" '{print $3}'
stat /etc/hosts | awk -F "[(/]" 'NR==4 {print $2}'
```

> **获取信息的第4种方式（思路）**

在Linux系统下，一些命令本身就能够直接获取目标信息。例如获取权限、获取IP

```shell
stat -c %a /etc/hosts    # 提取文件权限

hostname                 # 查看主机名
hostname -i              # -i选项表示获取与本机hostname对应的IP
hostname -I              # -I选项表示获取本机的所有IP
```

一些重要的系统信息，会有相应的命令或参数直接显示

## 七、正则速查表

```notepad
┌─────────────────────────────────────────────────────────┐
│  字符类                                                 │
│  .        任意单个字符                                  │
│  \d       数字 [0-9]（grep -P）                         │

│  \s       空白字符（空格/tab/换行）                       │
│  [abc]    a、b 或 c                                     │
│  [^abc]   除 a、b、c 外的字符                           │
│  [a-z]    a 到 z                                        │
├─────────────────────────────────────────────────────────┤
│  位置                                                   │
│  ^        行首                                          │
│  $        行尾                                          │
│  \b       单词边界                                       │
├─────────────────────────────────────────────────────────┤
│  数量（基本）                                            │
│  *        0次或多次                                      │
│  \{n\}    正好 n 次                                     │
│  \{n,\}   n 次或更多                                     │
│  \{n,m\}  n 到 m 次                                      │
├─────────────────────────────────────────────────────────┤
│  数量（扩展）+ -E                                        │
│  +        1次或多次                                      │
│  ?        0次或1次                                       │
│  {n}      正好 n 次                                     │
│  {n,}     n 次或更多                                     │
│  {n,m}    n 到 m 次                                     │
├─────────────────────────────────────────────────────────┤
│  分组与或                                               │
│  (ab)     分组                                          │
│  a|b       a 或 b                                       │
└─────────────────────────────────────────────────────────┘
```
