## 一、sed 概述

sed（Stream Editor）是 Linux 流编辑器，用于对文本进行替换、删除、插入等操作。

### 1.1 工作流程

1. 一次从输入中读取一行数据，输入可以是从文件中读取或从终端读取
2. 依据输入的字符匹配数据
3. 按照输入的命令修改数据
4. 将修改后的数据输出到STDOUT

```notepad
读取  →  匹配    →   执行   → 输出
  │       │          │
  ↓       ↓          ↓
 文本 → 逐行处理 → 显示/修改
```

sed从文件中读取文本时，每换一行就会重新走一遍工作流程；默认情况下，sed每从输入中读取一行数据，不论是否满足匹配条件都会将其输出到屏幕，`-n`选项则是只输出满足条件的行

### 1.2 基本语法

```bash
sed [options] 'command' [file]
sed [options] -f scriptfile [file]

sed -n '/hebor/p' passwd                   # 搜索内容并过滤打印，-n 取消默认输出，p 表示打印输出
sed -n 's#OldString#NewString#g' passwd    # 内容替换测试
    -n：取消自动输出（只有p才显示）
    -i：直接修改文件
    -e：多点编辑
    -r：使用扩展正则
    -i.bak：修改前备份（原文件.bak）
```

## 二、地址定位

### 2.1 定位方式

| 格式 | 说明 | 示例 |
| :--- | :--- | :--- |
| `n` | 第 n 行 | `sed -n '5p' file` |
| `n,m` | n 到 m 行 | `sed -n '1,5p' file` |
| `n,$` | n 到末尾 | `sed -n '5,$p' file` |
| `/pattern/` | 匹配的行 | `sed -n '/root/p' file` |
| `n,/pattern/` | n行到匹配行 | `sed -n '1,/root/p' file` |
| `n~m` | 从n开始每m行 | `sed -n '1~2p' file`（奇数行） |

### 2.2 多行操作

```bash
sed -n '5,10p' passwd    # 第5到第10行
sed -n '1,$p' passwd     # 第1行到最后
sed -n '$p' passwd       # 最后一行
sed -n '1~2p' passwd     # 奇数行
sed -n '2~2p' passwd     # 偶数行
```

## 三、sed 命令

### 3.1 查找（p — print）

```bash
# 1. 按行号查询
sed '' /etc/passwd            # 打印所有行（默认行为）
sed -n "3p" /etc/passwd       # 查找单行信息
sed -n "3,5p" /etc/passwd     # 查看连续的多行信息
sed -n '3p;5p' /etc/passwd    # 查询不连续的多行信息
sed -n '1~2p' /etc/passwd     # 从第1行开始间隔为2查询信息

# 2. 按字符信息查询
sed -n '/hebor/p' /etc/passwd     # 查询存在字符串hebor的行
sed -n '/hebor/,/test/p' /etc/passwd    # 查询hebor到test之间的多行信息
    # 如果后一个字符串test没有匹配到，则会显示oldboy后的所有行
    # 如果后一个字符串test在文件内容中存在多个，sed会一直匹配到最后一个
sed -n '/^hebor/p' /etc/passwd    # 查询以hebor开头的行
sed -n '/^$/p' /etc/passwd        # 打印空行
```

### 3.2 删除（d — delete）

```bash
sed '3d' /etc/passwd          # 删除第3行
sed '1,5d' /etc/passwd        # 删除第1到5行
sed '/^$/d' /etc/passwd       # 删除空行
sed '/^#/d' /etc/passwd       # 删除以#开头的注释行
sed '/hebor/d' /etc/passwd    # 删除包含hebor的行
sed '$d' /etc/passwd          # 删除最后一行

sed -i.bak '3d' person.txt    # 修改文件内容的同时生成原文件的.bak备份
    # 实际上sed命令在不添加-i选项时，所有操作都是临时操作，不会对源文件做出任何改变
```

### 3.3 替换（s — substitute）

```bash
# 基本语法
sed 's/old/new/' file
# 替换每行第一个匹配

# 全局替换（替换所有匹配）
sed 's/old/new/g' file

# 指定行号替换
sed '1s/old/new/' file      # 只替换第1行
sed '1,5s/old/new/g' file  # 替换1-5行

# 指定匹配次数（每行第几个匹配才替换）
sed 's/old/new/2' file     # 只替换每行第2个匹配

# 分隔符可以换成其他字符
sed 's#old#new#g' file     # 用#作为分隔符
sed 's/old\/new/g' file    # 转义分隔符
```

### 3.4 追加/插入（a/i/c）

```bash
# a：在行后追加
sed '/root/a after_root' file      # 在匹配行后添加
sed '5a after_line5' file          # 在第5行后添加

# i：在行前插入
sed '/root/i before_root' file     # 在匹配行前插入
sed '5i before_line5' file         # 在第5行前插入

# c：整行替换
sed '/root/c replaced_line' file   # 匹配行整行替换
sed '5c replaced_line5' file       # 第5行整行替换
```

### 3.5 读写（r/w）

```bash
# r：读取文件插入
sed '/PATTERN/r otherfile.txt' file  # 在匹配行后插入文件

# w：写入文件
sed '/root/w /tmp/roots.txt' file     # 包含root的行写入文件
```

### 3.6 反向（y — 字符转换）

```bash
# y：字符一对一替换
sed 'y/abc/ABC/' file      # a→A, b→B, c→C
sed 'y/1234/ABCD/' file
```

## 四、扩展应用

### 4.1 多点编辑（-e）

```bash
sed -e '1d' -e '/root/d' -e 's/old/new/g' file
```

### 4.2 组合命令

```bash
# 分号分隔
sed '1d; /root/d; s/old/new/g' file

# 花括号分组
sed '/root/{
  s/old/new/
  s/foo/bar/
}' file
```

### 4.3 高级替换

```bash
# 正则分组替换
echo "192.168.1.100" | sed -r 's/([0-9]+)\.([0-9]+)\.([0-9]+)\.([0-9]+)/\4.\3.\2.\1/'
# 结果：100.1.168.192

# 使用 & 引用匹配内容
sed 's/[0-9]\+/IP:&/g' file    # 数字前加IP:
sed 's/old/"&"/g' file         # 加上引号

# 删除重复行
sed 'G' file | sed '/^\s*$/d' | sort | uniq
```

### 4.4 批量重命名

```bash
# 将所有 .txt 改为 .bak
ls *.txt | sed 's/\(.*\)\.txt/mv & \1.bak/e'

# 更安全的做法
for f in *.txt; do
  mv "$f" "$(echo $f | sed 's/\.txt$/.bak/')"
done
```

## 五、常用案例

### 5.1 配置文件修改

```bash
# 替换配置文件中的IP
sed -i 's/192.168.1.100/192.168.1.200/g' config.conf

# 注释掉匹配行
sed -i '/PORT=/s/^/#/' config.conf

# 取消注释
sed -i '/#PORT=/s/^#//' config.conf

# 在某行后添加内容
sed -i '/\[mysqld\]/a max_connections=1000' my.cnf
```

### 5.2 日志处理

```bash
# 提取错误日志
sed -n '/ERROR/p' /var/log/messages

# 删除空行
sed -i '/^$/d' file

# 去除多余空格
sed -i 's/[[:space:]]*$//' file

# 转换Unix换行符
sed -i 's/\r$//' file
```

### 5.3 文本提取

```bash
# 提取IP
ifconfig | sed -n '/inet /p' | sed 's/inet.*://' | awk '{print $1}'

# 提取URL
grep -oE 'https?://[^/]+' file | sort | uniq

# 提取数字
echo "abc123def456" | sed 's/[a-z]//g'
```
