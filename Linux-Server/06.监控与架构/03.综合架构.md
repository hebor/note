# 综合架构与运维

## 一、堡垒机概述

### 1.1 跳板机 vs 堡垒机

| 特性 | 跳板机 | 堡垒机 |
| :--- | :--- | :--- |
| 认证 | 单一密码 | 多因素认证 |
| 审计 | 简单日志 | 完整会话录像 |
| 权限 | 粗粒度 | 细粒度 |
| 账号 | 共享账号 | 一人一号 |
| 管理 | 无 | 集中管理 |

### 1.2 JumpServer 堡垒机

JumpServer 是开源堡垒机，具备 4A 能力：

- **Authentication**：身份认证
- **Account**：账号管理
- **Authorization**：授权控制
- **Audit**：审计记录

**核心组件：**
- JumpServer Core（用户/资产/权限管理）
- Luna（Web Terminal）
- KoKo（SSH Terminal）
- Lion（审计/RDP）
- Celery（异步任务）
- Nginx（反向代理）

## 二、负载均衡

### 2.1 常见负载均衡方案

| 方案 | 说明 |
| :--- | :--- |
| **Nginx** | HTTP/HTTPS 七层负载均衡 |
| **HAProxy** | TCP/HTTP 四层/七层负载均衡 |
| **LVS** | Linux Virtual Server，四层负载均衡 |
| **云负载均衡** | 云服务商提供的 LB 服务 |

### 2.2 Nginx 负载均衡

```bash
# upstream 配置
upstream backend {
    ip_hash;                        # Session保持
    server 192.168.1.101:80 weight=5;
    server 192.168.1.102:80 weight=3;
    server 192.168.1.103:80 backup;  # 热备
}

server {
    listen 80;
    server_name www.example.com;

    location / {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 2.3 HAProxy 配置

```bash
# /etc/haproxy/haproxy.cfg
frontend http_front
    bind *:80
    default_backend web_servers

backend web_servers
    balance roundrobin            # 轮询
    # balance source              # 源IP会话保持
    server web1 192.168.1.101:80 check inter 2000 rise 2 fall 3
    server web2 192.168.1.102:80 check inter 2000 rise 2 fall 3
    server web3 192.168.1.103:80 check inter 2000 rise 2 fall 3
```

    interface eth0
    virtual_router_id 51

    advert_int 1

## 六、备份策略

### 6.1 备份类型

| 类型 | 说明 | RTO | RPO |
| :--- | :--- | :--- | :--- |
| 全量备份 | 备份所有数据 | 慢 | 大 |
| 增量备份 | 只备份变化数据 | 快 | 小 |
| 差异备份 | 相对上一次全量备份的变化 | 中 | 中 |

### 6.2 备份原则

```
3-2-1 原则：
- 3 份数据副本
- 2 种不同介质
- 1 份异地备份
```

### 6.3 备份脚本示例

```bash
#!/bin/bash
# MySQL 全量备份脚本

BKPDIR="/backup/mysql"
DATE=$(date +%Y%m%d)
RETENTION=7

# 创建备份目录
mkdir -p $BKPDIR/$DATE

# MySQL 密码
MYSQL_PWD="password"

# 执行备份
mysqldump -uroot -p$MYSQL_PWD --all-databases --single-transaction \
  --master-data=2 --flush-logs | gzip > $BKPDIR/$DATE/full_backup.sql.gz

# 计算 MD5
md5sum $BKPDIR/$DATE/full_backup.sql.gz > $BKPDIR/$DATE/backup.md5

# 清理过期备份
find $BKPDIR -type d -mtime +$RETENTION -exec rm -rf {} \;

# 日志
echo "[$(date)] MySQL backup completed" >> /var/log/backup.log
```

## 七、常见运维场景

### 7.1 CPU 飙高排查

```bash
# 1. 查看负载
uptime
top

# 2. 找出高CPU进程
ps aux --sort=-%cpu | head -10

# 3. 查看进程详情
top -p PID

# 4. 查看线程
ps -p PID -L -o pid,tid,%cpu

# 5. 追踪调用
strace -p PID
```

### 7.2 内存不足排查

```bash
# 1. 查看内存
free -h

# 2. 查看进程内存占用
ps aux --sort=-%mem | head -10

# 3. 查看OOM Killer日志
dmesg | grep -i "out of memory"
journalctl | grep -i oom

# 4. 查看 slab
slabtop
```

### 7.3 磁盘满排查

```bash
# 1. 查看磁盘使用
df -h

# 2. 查找大文件
du -sh /* | sort -rh | head -10
du -h /var/* | sort -rh | tail -10

# 3. 查找大文件
find / -type f -size +100M -exec ls -lh {} \;

# 4. 清理日志
journalctl --vacuum-size=500M
truncate -s 0 /var/log/xxx.log
```
