# Zabbix 监控

## 一、Zabbix 概述

Zabbix 是一个企业级开源监控解决方案，支持监控网络设备、服务器、应用程序等。

### 1.1 组件架构

| 组件 | 说明 |
| :--- | :--- |
| Zabbix Server | 核心服务，负责数据收集和处理 |
| Zabbix Agent | 部署在被监控主机，采集本地数据 |
| Zabbix Web | Web界面配置和管理 |
| Zabbix Proxy | 分布式代理，减轻Server压力 |
| Database | 数据存储（MySQL/PostgreSQL） |

### 1.2 监控方式

| 模式 | 说明 |
| :--- | :--- |
| Agent (Passive) | Server主动轮询Agent（默认） |
| Agent (Active) | Agent主动上报数据（适合大规模） |
| SNMP | 监控网络设备 |
| IPMI | 监控硬件（风扇、温度等） |
| JMX | 监控Java应用 |

## 二、二进制安装 Zabbix

### 2.1 环境准备

```bash
# 安装 MySQL
yum install -y mysql-server
systemctl enable --now mysqld

# 创建数据库
mysql
CREATE DATABASE zabbix CHARACTER SET utf8 COLLATE utf8_bin;
CREATE USER 'zabbix'@'localhost' IDENTIFIED BY 'zabbix_password';
GRANT ALL PRIVILEGES ON zabbix.* TO 'zabbix'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 2.2 安装 Zabbix

```bash
# 安装 Zabbix 仓库（以 Zabbix 6.0 LTS 为例）
rpm -Uvh https://repo.zabbix.com/zabbix/6.0/rhel/7/x86_64/zabbix-release-6.0-1.el7.noarch.rpm

# 启用 SCL
yum install -y centos-release-scl
yum install -y zabbix-server-mysql zabbix-web-mysql-scl zabbix-apache-conf-scl zabbix-agent

# 导入数据库
zcat /usr/share/zabbix-sql-scripts/mysql/server.sql.gz | mysql -uzabbix -p zabbix

# 配置 Zabbix Server
vim /etc/zabbix/zabbix_server.conf
DBHost=localhost
DBName=zabbix
DBUser=zabbix
DBPassword=zabbix_password

# 配置 PHP（Zabbix Web）
vim /etc/opt/rh/rh-php72/php-fpm/zabbix.conf
php_value[date.timezone] = Asia/Shanghai

# 启动服务
systemctl enable zabbix-server zabbix-agent httpd php72-php-fpm
systemctl start zabbix-server

# 访问 Web 界面
# http://server_ip/zabbix
# 默认账号：Admin / zabbix
```

## 三、Zabbix Agent 部署

### 3.1 安装 Agent

```bash
# 被监控端安装
rpm -Uvh https://repo.zabbix.com/zabbix/6.0/rhel/7/x86_64/zabbix-release-6.0-1.el7.noarch.rpm
yum install -y zabbix-agent

# 配置
vim /etc/zabbix/zabbix_agentd.conf
Server=192.168.1.100          # Zabbix Server IP
ServerActive=192.168.1.100    # 主动模式Server
Hostname=host01               # 主机名（必须与Web配置一致）

# 启动
systemctl enable --now zabbix-agent
```

### 3.2 主动模式 vs 被动模式

```bash
# 被动模式（Passive）：Server 轮询 Agent
# Agent监听端口：10050
# Server 发送 → Agent 接收 → Agent 响应 → Server 处理

# 主动模式（Active）：Agent 主动上报
# Server 配置：
StartAgents=0                 # 关闭被动模式
ServerActive=192.168.1.100    # 主动上报地址
```

## 四、自定义监控项

### 4.1 UserParameter

```bash
# 1. 创建自定义脚本
vim /etc/zabbix/zabbix_agentd.d/nginx_status.sh
#!/bin/bash
nginx_status_url="http://127.0.0.1/status"
case $1 in
    active)
        curl -s $nginx_status_url | awk '/Active/ {print $3}' ;;
    accepts)
        curl -s $nginx_status_url | awk '/^s*Accepts/ {print $2}' ;;
    waiting)
        curl -s $nginx_status_url | awk '/Waiting/ {print $3}' ;;
    *)
        echo 0 ;;
esac

chmod +x /etc/zabbix/zabbix_agentd.d/nginx_status.sh

# 2. 配置 UserParameter
vim /etc/zabbix/zabbix_agentd.d/nginx.conf
UserParameter=nginx.active,/etc/zabbix/zabbix_agentd.d/nginx_status.sh active
UserParameter=nginx.accepts,/etc/zabbix/zabbix_agentd.d/nginx_status.sh accepts
UserParameter=nginx.waiting,/etc/zabbix/zabbix_agentd.d/nginx_status.sh waiting

# 3. 重启 Agent
systemctl restart zabbix-agent

# 4. 测试
zabbix_get -s 127.0.0.1 -k nginx.active
```

### 4.2 常用 zabbix_get 命令

```bash
# 安装
yum install -y zabbix-get

# 测试
zabbix_get -s host01 -k system.cpu.load
zabbix_get -s host01 -k net.tcp.port[,80]
zabbix_get -s host01 -k nginx.active
```

## 五、应用监控

### 5.1 Nginx 监控

```bash
# 1. 开启 Nginx status
vim /etc/nginx/conf.d/status.conf
server {
    listen 80;
    server_name localhost;
    location /nginx_status {
        stub_status on;
        access_log off;
        allow 127.0.0.1;
        deny all;
    }
}

nginx -t && systemctl reload nginx

# 2. 配置 Zabbix Agent（见 4.1）
```

### 5.2 Redis 监控

```bash
# Redis 本身支持 INFO 命令
# Zabbix Agent 配置
vim /etc/zabbix/zabbix_agentd.d/redis.conf
UserParameter=redis.info[*],redis-cli -h $1 -p $2 INFO | grep $3 | cut -d: -f2
```

### 5.3 MySQL 监控

```bash
# 使用 Percona Monitoring Plugins 或 zabbix-agent 自动发现

# 手动配置
vim /etc/zabbix/zabbix_agentd.d/mysql.conf
UserParameter=mysql.status[*],mysql -e 'SHOW GLOBAL STATUS WHERE Variable_name="$1";' | awk '{print $$2}'
UserParameter=mysql.heartbeat,mysql -e 'SELECT UNIX_TIMESTAMP() - UNIX_TIMESTAMP(MAX(ts)) FROM heartbeat;' 2>/dev/null || echo 0
```

## 六、Web 监测

### 6.1 配置 Web 监测

Web监测可模拟浏览器访问，监测页面可用性和响应时间：

```
配置 → Web监测 → 创建监测
  → 场景：定义监测名称和监控频率
  → 步骤：定义HTTP请求序列（登录 → 浏览 → 登出）
  → 触发器：响应时间超过阈值告警
```

### 6.2 curl 验证示例

```bash
# 模拟登录并验证
curl -c cookies.txt -d "username=admin&password=123456" http://example.com/login
curl -b cookies.txt http://example.com/dashboard
```

## 七、自动化监控

### 7.1 网络发现

```bash
# Zabbix Server 自动发现局域网主机
配置 → 自动发现 → 创建规则
  → IP范围：192.168.1.1-254
  → 检查：Zabbix Agent ping
  → 间隔：1小时
  → 动作：自动注册发现的Host
```

### 7.2 自动注册

```bash
# 被监控端配置
vim /etc/zabbix/zabbix_agentd.conf
ServerActive=192.168.1.100
Hostname=host-{{ ansible_facts.hostname }}
HostMetadata=linux webserver

# Server 配置动作
配置 → 动作 → 自动注册
  → 条件：HostMetadata 包含 linux
  → 操作：添加主机、链接模板
```

## 八、告警配置

### 8.1 邮件告警

```bash
# 配置介质（管理 → 媒介类型 → Email）
# SMTP服务器：smtp.example.com
# SMTP端口：465
# SSL/TLS
# 认证：用户名/密码
```

### 8.2 触发器表达式

```bash
# 常用表达式
{host:key.last()}                    # 最新值
{host:key.max(#5)}                   # 5个周期最大值
{host:key.avg(#5)}                   # 5个周期平均值

# 示例：CPU使用率超过80%持续5分钟
{host:system.cpu.util.last()} > 80

# 示例：磁盘空间低于10%
{host:vfs.fs.size[/,pfree].last()} < 10

# 示例：服务宕机
{host:net.tcp.port[tcp,80].last()} = 0
```
